CellChat

Ligand–receptor 발현을 mass action 법칙 기반 확률 모델로 바꿔 cell group 사이의 통신 확률을 계산하고, permutation으로 유의성을 판단한 뒤 signaling pathway 단위로 해석하는 CCC 도구 (R).

#single-cell#cell-cell-communication#ligand-receptor#tool

쉽게 말하면

"Sender의 ligand가 많고 receiver의 receptor가 많을수록 대화할 확률이 높다. 단, 무한정 올라가지는 않는다(포화)." 이 생화학 원리를 single-cell 데이터에 맞게 계산합니다.

자세히

0. 입력

  • 발현 행렬 (genes × cells): library size 정규화 + log 변환된 데이터. Raw count면 normalizeData로 먼저 정규화.
  • Cell metadata: cell group label
  • (공간 데이터면) 좌표

1. 전처리

  • CellChatDB 선택 (human/mouse). 단순 1:1 쌍이 아니라 multi-subunit complex와 cofactor(agonist, antagonist)를 포함한다.
  • identifyOverExpressedGenes, identifyOverExpressedInteractions: 각 group에서 과발현된 ligand와 receptor만 남겨 계산량을 줄인다.

2. Group 대표 발현값

Sparse하고 noisy한 single-cell에서 group 대표값을 어떻게 정하느냐가 결과를 크게 바꾼다.

  • triMean (기본): 이상치에 강함. 적지만 확실한 상호작용을 잡음
  • truncatedMean (trim = 0.1 등): 하위 일부를 잘라 평균. 약한 신호에 대한 민감도 ↑

3. 통신 확률

  • Ligand와 receptor 발현이 높을수록 확률 ↑ (law of mass action)
  • 생체 반응의 포화를 Hill function으로 반영
  • Agonist, antagonist, co-receptor 효과를 곱해 조정

4. 유의성

Cell group label을 무작위로 섞어 확률을 다시 계산하는 permutation test. p < 0.05인 상호작용만 남긴다.

5. Pathway 단위로 묶기

L–R 쌍을 WNT, CCL, MHC-II 같은 signaling pathway로 묶어 "어떤 경로가 활성화됐나"로 해석한다.

6. 네트워크 분석 (social network analysis)

  • 각 cell group의 역할: sender, receiver, mediator, influencer (centrality 지표)
  • 여러 pathway에 걸친 outgoing/incoming 패턴 (NMF 기반)
  • Pathway 사이의 기능적·구조적 유사도로 묶기

7. 그룹 비교 (예: 질병 vs 대조)

층위 질문 방법
전체 통신이 전반적으로 많아졌나 총 interaction 수와 강도 비교 (compareInteractions)
Cell 쌍 어느 cell 쌍의 통신이 변했나 differential interaction heatmap, circle plot
Pathway 어떤 경로가 켜지거나 꺼졌나 rankNet (information flow)
L–R 쌍 어떤 쌍이 바뀌었나 bubble plot, DEG 기반 L–R 식별

Sample(환자) 단위 변동을 고려하려면 sample별로 CellChat을 돌린 뒤 결과를 sample 단위로 비교하거나, Tensor-cell2cell과 함께 쓴다.

공간 데이터 (v2)

물리적 거리가 멀면 확률을 0으로 둔다. 작은 분자 확산 거리인 약 250 µm를 기본 기준으로 쓴다.

Evidence boundaries

2024 Dunlap - RA Synovium Clonal Associations와 2025 Bolton - JIA Synovial Atlas의 inferred communication은 RNA expression 기반이다. Interaction 수·score·pathway 정보량을 직접 측정한 ligand secretion, receptor occupancy, downstream signaling으로 대체해서 읽지 않는다. Spatial proximity나 functional assay는 별도 evidence로 구분한다.
