Monte Carlo Tree Search (MCTS)

가능한 선택지를 tree로 펼쳐 놓고, 유망한 가지는 더 깊이, 덜 시도한 가지도 가끔 탐색하면서 좋은 해를 찾는 search algorithm.

#algorithm#search#optimization#molecular-design

쉽게 말하면

바둑에서 다음 수를 고를 때 모든 경우를 다 계산할 수는 없으니, 좋아 보이는 수를 중심으로 여러 번 시뮬레이션해 보고 결과가 좋았던 쪽을 더 파고드는 방법입니다. AlphaGo로 유명해졌습니다.

Molecule design에서는 "molecule에 어떤 수정을 할까"가 바둑의 "어디에 둘까"에 해당합니다.

자세히

4단계 반복 (일반 지식)

  1. Selection: root에서 시작해 점수가 좋으면서도 덜 탐색된 child를 골라 내려간다. 보통 UCB/UCT 공식으로 exploitation(좋았던 곳)과 exploration(안 가 본 곳)의 균형을 맞춘다.
  2. Expansion: 도착한 node에서 새 child를 하나 추가한다.
  3. Simulation (rollout): 거기서부터 끝까지 빠르게 진행해 결과를 평가한다.
  4. Backpropagation: 결과를 지나온 경로의 node들에 반영한다.

Molecular design에 쓸 때 (일반 지식)

  • Node = molecule, edge = 수정 동작(atom/fragment 추가, 치환, 제거 등)
  • Reward = 원하는 property 점수 (예: 활성 예측, drug-likeness, 합성 가능성)
  • 여러 property를 함께 다루면 multi-objective가 된다.
  • Deep generative model보다 단순하고, 시작 molecule 주변을 체계적으로 탐색하기 좋아 Hit-to-Lead Optimization에 잘 맞는다.

왜 중요한가

  • 탐색 공간이 너무 커서 전부 계산할 수 없는 문제에서 효율적으로 좋은 답을 찾는다.
  • Hit을 출발점으로 analog를 설계하는 computational optimization의 대표적인 도구 중 하나다.

논문별 활용

  • 2026 Xing - GPS: MolSearch가 MCTS 기반 2-stage multi-objective hit-to-lead optimization algorithm이다. PB56874852에서 출발해 Z-RGES를 개선하면서 medicinal chemistry property를 유지하는 analog를 설계했다. 제안된 analog의 ΔZ-RGES는 −3.2 ~ −0.82였고, 이를 바탕으로 합성한 MSU45302가 sub-μM IC50을 보였다 (Figure 4F–G).

관련 개념

  • Hit-to-Lead Optimization: MCTS가 쓰이는 단계
  • Molecular Fingerprint: 후보 molecule을 평가할 때 쓰는 표현
