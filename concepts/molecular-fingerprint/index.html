Molecular Fingerprint

Molecule의 structure를 0과 1로 이루어진 고정 길이 vector로 바꾼 표현. Computer가 molecule을 비교하고 학습할 수 있게 해 준다.

#chemistry#molecular-representation#cheminformatics

쉽게 말하면

Molecule을 "이런 부분 구조가 있다(1) / 없다(0)" 체크리스트로 바꾼 것입니다. 체크리스트가 비슷하면 구조가 비슷한 molecule입니다.

Molecule → [0 1 0 0 1 1 0 ... 1]   (예: 1024 또는 2048 bit)

자세히

종류 (일반 지식)

  • ECFP (Extended-Connectivity Fingerprint), Morgan fingerprint: 각 atom 주변을 반경을 넓혀 가며 본 부분 구조를 hashing해 bit로 표시.
    • 숫자는 diameter를 뜻한다. ECFP4 = 반경 2, ECFP6 = 반경 3. 클수록 더 큰 부분 구조까지 반영.
  • MACCS keys: 미리 정해 둔 166개 부분 구조의 유무.
  • 그 밖에 atom pair, topological fingerprint 등.

유사도 계산 (일반 지식)

  • 두 fingerprint의 Tanimoto similarity = 공통 1의 수 / 둘 중 하나라도 1인 수. 0~1 사이.
  • Virtual Screening에서 "알려진 active compound와 비슷한 것 찾기"(ligand-based screening)의 기본 도구다.

Learned representation과 비교

  • Graph neural network(GNN)나 transformer로 molecule embedding을 학습하는 방법도 있다.
  • 그러나 data가 적거나 noise가 많으면 단순한 fingerprint가 여전히 강력한 baseline이다.

왜 중요한가

  • ML model에 molecule을 넣는 가장 간단하고 빠른 방법이다.
  • 수백만 개 library compound를 빠르게 비교하고 clustering할 수 있다.
  • 한계: 3D 구조나 conformation 정보가 없고, hashing 때문에 서로 다른 부분 구조가 같은 bit에 겹칠 수 있다(bit collision). (일반 지식)

논문별 활용

  • 2026 Xing - GPS: GPS의 compound input이 structural fingerprint다 (Figure 1A). GNN이나 transformer 기반 embedding이 fingerprint보다 낫지 않았다 (Tables S2–S4). Figure 2G에서는 ECFP6로 본 chemical space에서 compound가 같은 target끼리 모였지만, 예측 expression으로 보면 같은 pathway끼리 모였다. ZINC library가 training compound와 다른 chemical space를 덮는지도 fingerprint 기반 t-SNE로 확인 (Figure 2K).

관련 개념

  • ECFP: atom 주변 환경으로 만드는 circular fingerprint의 생성 원리와 사용법
  • Virtual Screening: fingerprint similarity로 후보를 찾는 ligand-based 방식
  • Compound Library: fingerprint로 바꿔 다루는 대상
  • Hit-to-Lead Optimization: analog 탐색에 structural similarity를 쓴다
