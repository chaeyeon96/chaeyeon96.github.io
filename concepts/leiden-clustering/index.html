Leiden Clustering

KNN Graph 위에서 modularity(또는 CPM)를 최대화하도록 cell을 community로 나누는 알고리즘. Seurat, Scanpy의 표준 clustering이다.

#single-cell#clustering#graph#community-detection

쉽게 말하면

KNN graph가 "누가 누구와 친한가"의 지도라면, Leiden은 그 지도를 보고 "어디까지가 한 동네인가"를 선 긋는 단계입니다. K-means처럼 그룹 수를 미리 정하지 않고, graph 구조에서 자연스럽게 생긴 동네를 찾습니다.

자세히

Louvain과의 차이

  • Louvain: 빠르지만, 실제로는 서로 연결이 끊긴 cell들이 한 cluster에 억지로 묶이는(disconnected community) 문제가 있다.
  • Leiden: 속도는 비슷하게 유지하면서 refinement 단계를 추가해 이 문제를 고쳤다. 더 견고하고 생물학적으로 균일한 cluster가 나온다.

알고리즘 4단계

  1. Local moving: 처음에는 모든 cell이 각자 cluster. Cell을 하나씩 골라 이웃의 cluster로 옮겨 보고, 전체 modularity가 가장 많이 오르는 쪽으로 이동. 더 이상 안 오를 때까지 반복.
  2. Refinement (Leiden의 핵심): 1단계에서 만든 cluster 안을 다시 보고, 연결이 부실한 부분은 쪼개거나 하위 cluster로 재배치.
  3. Aggregation: 확정된 cluster를 super-node 하나로 합친다. 내부 edge는 self-loop, cluster 사이 edge는 super-node 사이의 굵은 edge가 된다.
  4. Iteration: 축소된 graph로 1단계부터 반복. 구조가 변하지 않을 때까지.

이 덕분에 큰 줄기(면역세포)부터 세밀한 가지(특정 memory T subset)까지 계층적으로 찾고, 데이터를 조금 바꿔도 결과가 안정적이며, 수십만 cell도 몇 분 안에 처리한다.

Resolution: kkk 대신 조절하는 값

Modularity 식의 기대 연결 항에 붙는 γ\gammaγ다 → Modularity

Resolution 비유 결과
낮음 (0.1–0.4) 돋보기를 멀리서 cluster 수 적음 (예: "lymphocyte")
높음 (0.8–2.0) 돋보기를 가까이 cluster 수 많음 (예: naive T, memory T, Treg)

보통 0.5 근처에서 시작해 marker를 보며 조절한다.

잘 안 나뉠 때 체크

  • KNN의 kkk가 너무 크면 cell이 지나치게 끈끈해져 잘 안 쪼개진다.
  • 원하는 세밀함이 안 나오면 resolution을 조금씩 올린다.
  • 하나의 큰 cell type 안을 따로 subclustering하는 것도 흔하다 (예: T cell만 떼어 다시 clustering).

전체 흐름

  1. Input: cell별 발현량
  2. PCA 또는 scVI latent: 압축과 노이즈 제거
  3. KNN Graph: 이웃 찾기, local scaling
  4. Leiden: modularity 최적화로 cluster 확정
  5. Output: cell별 cluster ID → Cell Type Annotation

논문별 활용

  • 2025 Sheinin - scNET: 특정 cluster 수를 주지 않고 resolution을 0~1로 바꿔 가며 Leiden을 돌리고, 정답 label과 가장 잘 맞는 최대 ARI로 embedding 성능을 비교했다. Gene 임베딩 평가(Fig 2)에는 K-means(K = 30)를 따로 썼다.
