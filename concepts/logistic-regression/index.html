Logistic Regression

이항 반응(0/1)의 확률을 log-odds의 선형식으로 모델링하는 회귀. 계수 $\beta$는 "log-odds 변화량", $e^{\beta}$는 "odds ratio(OR)"로 해석한다.

#statistics#regression#glm#odds-ratio

쉽게 말하면

확률 ppp를 바로 직선으로 그리면 0과 1 밖으로 튀어 나갑니다. 그래서 ppp를 log-odds로 바꾼 뒤 그 값을 직선으로 모델링하고, 다시 sigmoid로 확률로 되돌립니다.

자세히

1. 기본식

η=β0+β1x1+⋯+βpxp,p=P(Y=1∣x)=σ(η)=11+e−η\eta = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p, \qquad p = P(Y=1 \mid x) = \sigma(\eta) = \frac{1}{1 + e^{-\eta}} η=β0​+β1​x1​+⋯+βp​xp​,p=P(Y=1∣x)=σ(η)=1+e−η1​

같은 식을 logit link로 쓰면:

logit(p)=log⁡p1−p=η\text{logit}(p) = \log\frac{p}{1-p} = \eta logit(p)=log1−pp​=η

여기서 log⁡\loglog는 자연로그(ln)입니다.

2. 계수 해석: 확률이 아니라 log-odds

다른 변수가 고정일 때 xjx_jxj​가 1 늘면 log-odds가 βj\beta_jβj​만큼 변합니다. 가장 안전한 해석입니다.

3. 같은 β\betaβ라도 확률 변화량은 ppp에 따라 다르다

dpdxj=βj p(1−p)\frac{dp}{dx_j} = \beta_j \, p(1-p) dxj​dp​=βj​p(1−p)

  • p≈0.5p \approx 0.5p≈0.5에서 p(1−p)p(1-p)p(1−p)가 최대 → 확률이 가장 민감하게 변함
  • ppp가 0이나 1에 가까우면 변화가 둔함

그래서 "xxx가 1 늘면 확률이 몇 %p 오른다"로 고정해서 말하면 위험합니다.

4. 스케일링이 계수에 미치는 영향

  • 상수배: x∗=axx^* = a xx∗=ax로 바꾸면 β∗=β/a\beta^* = \beta / aβ∗=β/a. 단위를 10배 키우면 계수는 1/10.
  • 표준화 (z=(x−μ)/sz = (x-\mu)/sz=(x−μ)/s): 계수는 "1 SD 증가당 log-odds 변화". L1/L2 regularization을 쓸 때는 스케일이 penalty에 영향을 주므로 표준화가 중요합니다.
  • 중심화 (x′=x−cx' = x - cx′=x−c): 기울기는 그대로, 절편만 바뀜. 0이 의미 없는 변수(나이 등)는 중심화하면 절편 해석이 쉬워집니다.

5. Separation과 Bayesian regularization

어떤 그룹에서는 전부 0, 다른 그룹에서는 전부 1인 complete separation이 생기면 MLE가 ∣β∣→∞|\beta| \to \infty∣β∣→∞로 발산합니다. scRNA-seq에서 "어떤 gene이 한 조건에서 전혀 검출되지 않는" 경우가 흔합니다.

해결책은 계수에 weakly informative prior를 거는 것입니다.

ℓ(β)⏟log-likelihood+log⁡p(β)⏟log-prior  →  maximize (MAP)\underbrace{\ell(\beta)}_{\text{log-likelihood}} + \underbrace{\log p(\beta)}_{\text{log-prior}} \;\rightarrow\; \text{maximize (MAP)} log-likelihoodℓ(β)​​+log-priorlogp(β)​​→maximize (MAP)

  • β∼N(0,τ2)\beta \sim \mathcal{N}(0, \tau^2)β∼N(0,τ2) prior → log⁡p(β)=−∑jβj2/(2τ2)+C\log p(\beta) = -\sum_j \beta_j^2 / (2\tau^2) + Clogp(β)=−∑j​βj2​/(2τ2)+C → ridge(L2)와 같은 효과
  • Cauchy prior (heavy-tailed) → 큰 효과는 어느 정도 허용하면서 발산은 막음
  • 비유: 절벽(separation)에서 끝없이 굴러떨어지는 추정에 난간을 설치하는 것
  • 데이터가 충분하면 prior 영향은 거의 사라지고, 희소하거나 불균형할수록 효과가 커집니다.

MAST의 discrete part(검출 여부)가 logistic regression인데, 이 문제 때문에 arm::bayesglm 같은 Bayesian GLM을 씁니다.

왜 중요한가

  • 진단 모델, 질병 위험 요인 분석(OR 보고)의 기본 모델입니다.
  • scRNA-seq differential expression의 hurdle model(MAST), Confusion Matrix 기반 분류 평가와 이어집니다.
