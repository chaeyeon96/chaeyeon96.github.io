Multi-task Learning

여러 prediction task를 함께 학습하면서 일부 representation을 공유하는 방법.

#machine-learning#deep-learning#multi-output#representation-learning

Intuition

(일반 지식) Pain, fatigue, sleep score를 각각 따로 예측하면 매번 입력의 pattern을 처음부터 배운다. Shared layer는 공통 pattern을 함께 배우고, task-specific head는 각 outcome에 필요한 차이를 남긴다.

Details

(일반 지식) Task ttt의 prediction은 y^t=gt(hθ(x))\widehat y_t=g_t(h_\theta(x))y​t​=gt​(hθ​(x))로 쓸 수 있다. hθh_\thetahθ​는 shared representation이고 gtg_tgt​는 전용 head다.

L=∑tαtLt(yt,y^t)+λΩ(θ).\mathcal L=\sum_t\alpha_t\mathcal L_t(y_t,\widehat y_t)+\lambda\Omega(\theta). L=t∑​αt​Lt​(yt​,y​t​)+λΩ(θ).

Task의 scale, loss와 weight αt\alpha_tαt​가 다르면 어떤 task가 shared layer를 지배할 수 있다. Related task가 서로 도움이 될 수도 있지만, 관련이 약한 task가 서로 방해하는 negative transfer도 가능하다. ‘여러 output이 있다’는 사실만으로 task sharing의 효과가 입증되지는 않는다.

Significance

(일반 지식) 복합적인 phenotype을 하나의 disease label로 압축하지 않고 여러 관점에서 학습할 수 있다. 평가할 때 outcome별 error, overall classification, 독립 cohort generalization을 각각 확인한다.
