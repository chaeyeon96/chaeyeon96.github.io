Batch Correction

실험 날짜, 시퀀싱 회사, sample 처리 방식처럼 생물학과 무관한 기술적 요인(batch)이 만든 발현 차이를 제거해, 여러 sample을 함께 분석할 수 있게 하는 단계.

#single-cell#batch-effect#integration#preprocessing

쉽게 말하면

같은 종류의 cell인데 실험실이 달라서 UMAP에서 따로 떨어져 있다면 batch effect입니다. 보정 후에는 같은 cell type끼리 batch와 상관없이 섞여야 하고, 진짜 생물학적 차이(질병, 치료)는 남아야 합니다.

자세히

무엇을 보정하나: 두 가지 목적

  1. Embedding 보정 (UMAP, clustering용): 보정된 저차원 표현(예: X_scVI)을 만든다. 이것으로 KNN Graph를 만든다.
  2. Count / expression 보정 (DE, 시각화용): 보정된 발현값(예: scVI get_normalized_expression). DE에서는 보정값 대신 원래 count + batch를 공변량으로 넣는 방식도 흔하다.

대표 방법 (일반 지식 포함)

방법 원리 출력
scVI 생성 모델(VAE)에 batch를 조건으로 넣어 latent에서 분리 latent embedding, 보정된 expression
Harmony PCA 공간에서 batch별 cluster 중심을 반복적으로 맞춤 보정된 PC
Seurat CCA/RPCA anchors batch 간 대응하는 cell 쌍(anchor)으로 정렬 보정된 expression
ComBat, limma gene별 batch 평균·분산 조정 (bulk 기반) 보정된 expression

보정 전에 빼는 gene

Batch를 설명하는 축을 만들 때 다음 gene은 노이즈가 되므로 빼는 것이 좋다.

  • MT- gene: batch 차이보다 cell 생존 상태를 반영한다. 한 batch의 sample 보관이 나빴다면 PC1이 "얼마나 죽어 가는가"를 잡아 버린다. 염증 조직 cell의 높은 스트레스를 batch로 오해해 지우면 질병 신호도 사라진다.
  • Ribosomal gene (RPS/RPL): 발현량이 워낙 커서 조금만 변해도 분산을 지배한다. 처리 시간, 온도, library 제작에 민감하다.
  • V(D)J gene (TRAV, IGHV 등): 특정 클론 확장은 생물학적 현상이다. 포함하면 batch가 아니라 같은 receptor를 가진 cell끼리 묶인다.

시각적으로는 UMAP에서 batch별 색이 섞였는지, 정량적으로는 kBET, LISI, scIB 지표를 쓴다 (일반 지식).

가장 어려운 상황: confounding

Case는 한 batch, control은 다른 batch에 몰려 있으면 batch와 질병이 완전히 겹쳐 어떤 보정으로도 둘을 구분하기 어렵다. 설계 단계에서 batch마다 case와 control을 섞는 것이 최선이고, 이미 그렇다면 control이 양쪽에 있는 subset 분석, 외부 데이터 검증 등을 함께 고려한다.

보정했어도 통계에서 다시 잡는다

입력 보정은 패턴을 깨끗하게 만들 뿐, 같은 sample cell끼리 닮은 성질을 없애지는 않는다. 통계 모델에서는 donor와 batch를 random effect로 다시 넣는 것이 안전하다 → Mixed Effects Model
