Beta Regression

0과 1 사이의 비율 데이터를 위한 회귀. Logit link로 평균을 모델링하고, random effect를 더하면 Beta GLMM이 된다.

#statistics#regression#proportion#mixed-model

쉽게 말하면

Cell type 비율, cNMF program usage처럼 0~1 사이에 갇힌 값은 정규분포를 따르지 않습니다. Beta 분포는 0~1 구간에서 정의되는 유연한 분포라서, 비율 데이터의 오차 구조를 잘 설명합니다.

자세히

모델

logit(E[Y])=β0+β1 Condition+β2 Time+β3 (Condition×Time)\text{logit}(E[Y]) = \beta_0 + \beta_1\,\text{Condition} + \beta_2\,\text{Time} + \beta_3\,(\text{Condition} \times \text{Time}) logit(E[Y])=β0​+β1​Condition+β2​Time+β3​(Condition×Time)

  • β3\beta_3β3​로 조건과 시간의 interaction(예: responder와 non-responder의 시간에 따른 변화 차이)을 검정할 수 있습니다.
  • Sample이나 batch 구조가 있으면 random effect를 더해 Beta GLMM으로 씁니다 → Mixed Effects Model

가장 중요한 주의점: 정확한 0과 1

Beta 분포는 **열린 구간 (0,1)(0, 1)(0,1)**에서만 정의됩니다. 값이 하나라도 정확히 0이나 1이면 log 계산이 발산해 에러가 납니다. 희소한 데이터(예: cNMF usage)는 정확한 0이 많습니다.

분석 전 체크리스트

  1. min(Y)가 0인가? → 0이 있으면 일반 beta regression은 불가능
  2. max(Y)가 1인가? → 드물지만 있으면 같은 처리 필요
  3. 히스토그램
    • U자형(0과 1 근처에 몰림) → beta regression이 잘 맞음
    • 0 근처에만 압도적으로 몰림(zero-heavy) → pseudobulk가 낫다

해결책

  • 변환 (가장 쉬움, NNN = 샘플 수):

Ytransformed=Y⋅(N−1)+0.5NY_{\text{transformed}} = \frac{Y \cdot (N-1) + 0.5}{N} Ytransformed​=NY⋅(N−1)+0.5​

0은 아주 작은 양수로, 1은 1보다 약간 작은 수로 밀어 넣습니다.

  • Zero-inflated beta model: "0이 나올 확률"과 "0이 아닐 때의 비율"을 따로 모델링. 통계적으로 가장 엄밀하지만 수렴이 어려울 수 있습니다.
  • Pseudobulk: sample별 평균을 내면 0이 거의 사라지고 정규분포에 가까워져 일반 LMM이나 t-test를 쓸 수 있습니다. 가장 현실적인 대안입니다. → Pseudobulk Analysis

도구

언어 패키지 비고
R glmmTMB 추천. zero-inflated beta family와 random effect 지원
R betareg random effect 없는 beta regression
Python statsmodels, Bambi GLMM 지원이 R보다 약함 
glmmTMB(Usage ~ Condition * Time + (1 | Sample), family = beta_family(), data = df)

왜 중요한가

  • Cell type proportion, gene program usage, 비율형 임상 지표 등 single-cell 분석에서 비율 데이터가 많습니다.
  • 비율을 그냥 t-test하거나 정규 회귀에 넣으면 오차 구조가 틀립니다.

논문별 활용

  • cNMF 원 논문(Kotliar et al., eLife 2019)은 usage 비교에 Mann-Whitney U test를 썼다. 시간 × 조건 interaction을 보려면 beta regression이 더 적합하다는 것이 이 노트의 정리다. (일반 지식)
