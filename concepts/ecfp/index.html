ECFP

Extended-Connectivity Fingerprint. 각 원자를 중심으로 주변 결합 구조를 단계적으로 확장해, 분자에 어떤 국소 구조가 있는지 수치로 나타내는 circular fingerprint다. Molecular Fingerprint의 한 종류다.

#chemistry#molecular-representation#cheminformatics

쉽게 말하면

분자의 모든 원자에서 동시에 주변을 살펴본다고 생각하면 된다. 처음에는 원자 자체를 보고, 다음에는 바로 연결된 이웃을 보고, 그다음에는 두 결합 거리 안의 이웃까지 본다. 이렇게 얻은 여러 크기의 원자 주변 환경을 모아서 분자를 표현한다.

예를 들어 ethanol의 CCO와 ethylamine의 CCN은 탄소 사슬 일부를 공유하지만, 산소와 질소 주변 환경이 다르다. 따라서 일부 특징은 겹치고 일부는 달라진다. 이는 개념 설명이며 실제 bit 번호는 구현과 설정에 따라 달라진다.

자세히

Fingerprint Generation

(일반 지식, 아래 참고 자료 기준)

  1. 초기 원자 식별자 생성: 원자 번호, 연결 상태, 전하, 고리 관련 정보 등 원자의 특성을 정수 식별자로 표현한다. 사용하는 속성은 구현과 설정에 따라 다르다.
  2. 주변 환경 확장: 이전 단계의 원자 식별자와 이웃 원자 및 결합 정보를 모아 새 식별자를 만든다. 한 번 반복할 때 탐색 반경이 한 결합만큼 늘어난다.
  3. 특징 수집: 설정한 최대 반경까지 생성된 국소 환경의 식별자를 수집한다. 최대 반경의 환경만 사용하는 것이 아니다.
  4. 벡터 표현: 식별자를 고정 길이 bit vector에 매핑하거나, 특징별 출현 횟수를 담는 count 표현으로 만든다.

ECFP는 미리 정한 작용기 목록을 확인하는 방식과 달리, 입력 분자의 연결 구조에서 특징을 생성한다. 원 논문은 이를 분자 특성 예측에 적합한 표현으로 제시한다. Rogers & Hahn, 2010

ECFP4 vs ECFP6

명칭 최대 반경 의미
ECFP2 1 중심 원자에서 한 결합 거리까지
ECFP4 2 중심 원자에서 두 결합 거리까지
ECFP6 3 중심 원자에서 세 결합 거리까지

이름의 숫자는 직경에 해당하는 관례적 값이다. 따라서 ECFP4에 대응하는 RDKit Morgan fingerprint를 만들 때는 radius=2를 지정한다. 반경은 3D 공간의 Å 단위 거리가 아니라 분자 그래프의 결합 거리다.

반경이 커지면 더 넓은 구조적 맥락을 구분할 수 있지만, 항상 예측 성능이 좋아지는 것은 아니다. 데이터와 예측 과제에 따라 비교해야 한다.

Morgan Fingerprint

RDKit의 Morgan fingerprint는 ECFP와 밀접하게 관련된 circular fingerprint 구현이다. 실무에서는 두 이름을 비슷한 의미로 쓰지만, 원자 특성 정의와 옵션까지 동일해야 동일한 표현을 기대할 수 있다. RDKit은 기본 원자 불변량 대신 기능적 특성에 기반한 불변량을 쓰는 FCFP 유사 표현도 지원한다. RDKit 공식 문서

Bit vs Count Fingerprint

  • Bit fingerprint: 매핑된 위치에 특징이 하나 이상 있으면 1로 표시한다. 같은 특징이 여러 번 나와도 단순한 존재 여부만 남는다.
  • Count fingerprint: 특징의 출현 횟수를 보존한다. 반복되는 환경의 수를 구분할 수 있다.
  • Hash collision: 서로 다른 특징이 같은 위치에 매핑될 수 있다. 따라서 한 bit를 항상 하나의 고유한 작용기로 해석할 수는 없다.

벡터 길이와 반경은 별도 설정이다. 예를 들어 radius=2, fpSize=2048에서 2는 탐색 범위, 2048은 출력 bit 수다. 길이를 늘리면 접힘 과정의 충돌을 줄일 수 있지만, 3D 정보가 추가되는 것은 아니다.

Tanimoto Similarity

이진 fingerprint의 Tanimoto similarity는 다음과 같다.

T(A,B)=ca+b−cT(A,B)=\frac{c}{a+b-c} T(A,B)=a+b−cc​

여기서 aaa, bbb는 각 fingerprint에서 1인 bit 수, ccc는 공통으로 1인 bit 수다. 예를 들어 a=10a=10a=10, b=12b=12b=12, c=6c=6c=6이면 T=6/16=0.375T=6/16=0.375T=6/16=0.375다.

유사도가 높으면 이 표현에서 공유하는 구조적 특징이 많다는 뜻이다. 같은 표적에 결합하거나 같은 생물학적 효과를 낸다는 보장은 아니다. 작은 구조 변화에도 활성이 크게 달라지는 activity cliff가 있을 수 있다. Count vector에는 이진식의 bit 개수를 그대로 적용하지 말고, 사용하는 라이브러리의 유사도 정의를 확인해야 한다.

RDKit Example

아래는 반경 2, 2048 bit인 Morgan fingerprint를 비교하는 예시다. 예시 코드는 실행 검증하지 않았다.

from rdkit import Chem, DataStructs
from rdkit.Chem import rdFingerprintGenerator

molecules = [Chem.MolFromSmiles(s) for s in ["CCO", "CCN"]]
if any(m is None for m in molecules):
    raise ValueError("Invalid SMILES")

generator = rdFingerprintGenerator.GetMorganGenerator(
    radius=2,
    fpSize=2048,
    includeChirality=True,
)
fp_a, fp_b = [generator.GetFingerprint(m) for m in molecules]
similarity = DataStructs.TanimotoSimilarity(fp_a, fp_b)
print(similarity)

includeChirality=True는 입체화학을 반영하기 위한 설정이며, 입력에도 입체화학이 제대로 지정되어 있어야 한다. 구현 API는 RDKit fingerprint generator 문서를 참고한다.

Interpretation & Reproducibility

  • 기본적으로 2D 연결 구조를 요약하므로 실제 conformation, 결합 자세, 단백질 환경을 직접 담지 않는다.
  • 염 제거, protonation, tautomer 처리 방식이 달라지면 fingerprint도 달라질 수 있다.
  • 재현하려면 라이브러리 버전, 반경, 벡터 길이, chirality, 원자 불변량, bit/count 여부와 전처리를 함께 기록한다.
  • 유사도 기준값은 fingerprint 설정과 데이터에 의존한다. 특정 점수를 모든 문제의 활성 판정 기준으로 쓰지 않는다.

왜 중요한가

  • Virtual Screening: 알려진 active compound와 유사한 후보를 찾고 순위를 매기는 데 쓴다.
  • Compound Library: structural similarity를 이용해 clustering하거나 다양한 후보를 선택할 수 있다.
  • Property Prediction: fingerprint를 molecule input으로 사용하고 실험값을 label로 학습한다.
  • Hit-to-Lead Optimization: 기존 hit와 유사한 analog를 탐색할 때 쓴다.

논문별 활용

  • 2026 Xing - GPS: structure에서 expression을 예측하는 GPS의 compound 표현으로 ECFP4를 사용한다. Gene predictability 평가에는 2048 bit를 사용했고, GPS input의 bit 수는 Pipeline의 input 설명에 추정 근거를 구분해 두었다.
  • 같은 논문의 Figure 2G legend에는 ECFP6, Methods의 해당 분석 설명에는 FCFP4로 적혀 있다. 이 차이는 표기 불일치 메모에서 확인한다.
