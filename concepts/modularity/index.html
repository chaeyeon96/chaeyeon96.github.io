Modularity

Network를 그룹으로 나눴을 때, 그룹 안의 연결이 무작위로 기대되는 것보다 얼마나 더 빽빽한가를 재는 점수 $Q$. Leiden과 Louvain 알고리즘이 최대화하는 목표 함수다.

#graph#network#clustering

쉽게 말하면

"우리끼리 친하다"만으로는 부족하고, "우연히 친할 정도보다 훨씬 더 친하다"여야 진짜 그룹이라는 기준입니다.

자세히

Newman modularity

Q=12m∑i,j[Aij−kikj2m]δ(ci,cj)Q = \frac{1}{2m}\sum_{i,j}\left[A_{ij} - \frac{k_i k_j}{2m}\right]\delta(c_i, c_j) Q=2m1​i,j∑​[Aij​−2mki​kj​​]δ(ci​,cj​)

기호 의미
AijA_{ij}Aij​ node iii와 jjj의 실제 연결(edge weight)
ki,kjk_i, k_jki​,kj​ 각 node의 연결 총합(degree)
mmm network 전체 edge weight의 합
kikj2m\dfrac{k_i k_j}{2m}2mki​kj​​ 연결이 무작위였다면 기대되는 iii–jjj 연결
δ(ci,cj)\delta(c_i, c_j)δ(ci​,cj​) 두 node가 같은 그룹이면 1, 아니면 0 → 그룹 안의 쌍만 합산

핵심은 대괄호 안의 **[실제 연결 − 기대 연결]**입니다.

  • 양수: 우연보다 더 연결됨 → 진짜 community의 증거
  • 0 이하: 우연 수준 → 의미 없는 그룹

QQQ는 각 그룹의 기여를 합한 값이라, 전체 분할의 품질을 나타냅니다.

Resolution γ\gammaγ

Seurat, Scanpy의 resolution 파라미터가 이것입니다.

Qγ=12m∑i,j[Aij−γkikj2m]δ(ci,cj)Q_\gamma = \frac{1}{2m}\sum_{i,j}\left[A_{ij} - \gamma\frac{k_i k_j}{2m}\right]\delta(c_i, c_j) Qγ​=2m1​i,j∑​[Aij​−γ2mki​kj​​]δ(ci​,cj​)

  • γ\gammaγ ↑: 무작위 기대치의 penalty가 커져 웬만큼 끈끈해서는 같은 그룹이 못 됨 → cluster가 잘게 쪼개진다
  • γ\gammaγ ↓: 웬만하면 같은 그룹으로 묶음 → cluster 수가 줄어든다

CPM (Constant Potts Model)

Leiden은 기존 modularity의 resolution limit(작은 community를 놓치는 문제)을 피하려고 CPM을 자주 씁니다.

QCPM=∑c[ec−γ(nc2)]Q_{\text{CPM}} = \sum_c\left[e_c - \gamma\binom{n_c}{2}\right] QCPM​=c∑​[ec​−γ(2nc​​)]

  • ece_cec​: cluster ccc 내부의 실제 edge 합, ncn_cnc​: cluster ccc의 node 수
  • Cluster 크기와 무관하게 일정한 밀도를 가진 그룹을 찾는다. 아주 큰 cluster와 아주 작은 cluster가 섞인 scRNA-seq에 유리하다.

Gene network에서의 의미

Gene co-expression network를 만들 때 correlation threshold를 바꿔 가며 modularity가 최대가 되는 지점을 고르면, 생물학적으로 끈끈한 gene module이 가장 잘 나뉜 상태로 볼 수 있습니다.

논문별 활용

  • 2025 Sheinin - scNET (Fig 3a): scNET embedding으로 만든 gene network에서 상위 1% correlation(99th percentile) threshold를 쓸 때 최대 modularity가 나왔다. 논문은 Leiden으로 modularity를 계산했다고만 쓰고 식은 싣지 않았다. 위 식은 일반적인 정의다.
