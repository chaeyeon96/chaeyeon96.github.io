KNN Graph

각 cell을 발현 패턴이 가장 비슷한 $k$개의 이웃 cell과 연결한 graph. Single-cell 분석에서 clustering(Leiden), 시각화(UMAP), trajectory(PAGA)의 공통 뼈대다.

#single-cell#graph#clustering#umap

쉽게 말하면

원래 KNN은 "주변 kkk개 중 다수가 고양이면 너도 고양이"라고 정답을 맞히는 지도 학습입니다. Single-cell에서는 정답 없이 **"누가 누구랑 가까운지 지도를 그리는 도구"**로 씁니다. 이웃 이름을 묻는 게 아니라 이웃과 손을 잡는 것입니다.

자세히

만드는 과정 (Scanpy sc.pp.neighbors 기준)

  1. 이웃 찾기: PCA나 scVI latent 공간에서 euclidean 거리로 가장 가까운 kkk개(기본 15)를 고른다.
  2. Local scale σi\sigma_iσi​ 계산: cell마다 "가깝다"의 기준을 따로 정한다 (아래).
  3. Edge weight: 거리를 유사도로 바꾼다.

wij=exp⁡ ⁣(−max⁡(0, dij−ρi)σi)w_{ij} = \exp\!\left(-\frac{\max(0,\, d_{ij} - \rho_i)}{\sigma_i}\right) wij​=exp(−σi​max(0,dij​−ρi​)​)

ρi\rho_iρi​는 가장 가까운 이웃까지의 거리. 그다음 비대칭 weight를 대칭화한다. 4. Sparse matrix 저장

  • adata.obsp['distances']: 실제 거리
  • adata.obsp['connectivities']: 0–1 유사도 = graph의 edge weight
  • 각 행에 kkk개 값만 있는 sparse 구조
  1. Downstream: UMAP, Leiden/Louvain, PAGA

Local scale은 왜 필요한가

  • Cell이 빽빽한 영역에서는 거리 0.1도 "멀다", 듬성한 영역에서는 거리 1.0도 "가깝다"일 수 있다.
  • 모든 cell에 같은 기준을 쓰면 드문 cell type이 graph에서 고립된다.
  • 그래서 σi\sigma_iσi​를 각자의 이웃 거리 분포에 맞춘다. UMAP 방식은 이진 탐색으로 다음을 만족하는 σi\sigma_iσi​를 찾는다:

∑jexp⁡ ⁣(−max⁡(0, dij−ρi)σi)≈log⁡2k\sum_j \exp\!\left(-\frac{\max(0,\, d_{ij} - \rho_i)}{\sigma_i}\right) \approx \log_2 k j∑​exp(−σi​max(0,dij​−ρi​)​)≈log2​k

  • 효과: 밀도가 낮은 영역 연결 유지, 상대적 밀도를 반영한 clustering, UMAP이 전체 구조를 잘 펼치는 이유

kkk (n_neighbors) 고르기

  • kkk가 작으면: 국소 구조에 민감, 노이즈에 약함
  • kkk가 크면: 전체 구조가 부드러워지지만 cell이 너무 끈끈하게 연결되어 Leiden이 잘 못 쪼갠다
  • 데이터가 매우 크면(수십만 cell) kkk를 키워 UMAP 모양을 안정화하기도 한다

왜 cell끼리는 KNN, gene끼리는 correlation?

  • Cell 데이터는 dropout과 노이즈가 심해 개별 값보다 이웃 정보로 보완해야 한다. KNN은 imputation과 smoothing의 잘 확립된 도구다 (예: GCN으로 이웃 정보를 모음).
  • Cell 상태는 연속적인 manifold 위에 있어 "가까운 몇 개"로 국소 구조를 잡는 게 자연스럽다.
  • Gene–gene 관계는 여러 cell에 걸친 공변동을 보는 것이라 correlation이 자연스럽다 → Co-expression Network Analysis

KNN pruning

고정된 kkk는 "모든 cell에게 정확히 kkk명의 친구가 있다"고 가정해, 드문 cell type에 잘못된 edge를 억지로 만든다. 학습 중 attention 계수가 낮은 edge를 threshold로 잘라 내 graph를 다듬는 방법이 있다.

UMAP과 clustering을 함께 보는 이유

UMAP은 고차원 구조를 2D 지도로, clustering은 그룹 색깔을 준다. UMAP 위에 cluster 색을 칠해 색이 뚜렷한 섬으로 모이는지 보면, 나눈 그룹이 실제 구조와 맞는지 눈으로 확인할 수 있다. 단, UMAP의 거리와 모양을 정량적으로 해석하면 안 된다 (일반 지식).
