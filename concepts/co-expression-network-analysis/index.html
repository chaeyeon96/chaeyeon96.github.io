Co-expression Network Analysis

Cell(또는 metacell)들에 걸쳐 함께 오르내리는 gene들을 module로 묶는 분석. Module은 공통 기능이나 조절을 공유하는 gene program 후보다.

#single-cell#network#co-expression#gene-module

쉽게 말하면

DE가 gene 하나하나를 보는 것이라면, co-expression은 "이 gene들은 항상 같이 움직인다"는 팀을 찾는 것입니다. 팀 단위로 보면 개별 gene보다 noise에 강하고 해석도 쉽습니다.

hdWGCNA 흐름

flowchart TD
    A["Cell filtering, gene selection<br/>(pseudobulk 검출률 기준, RP/MT/VDJ gene 제외)"] --> B["Metacell 생성<br/>sample × cell type 안에서 KNN으로 이웃 cell 평균"]
    B --> C["Soft power β 선택<br/>scale-free fit"]
    C --> D["Adjacency = |corr|^β"]
    D --> E["TOM (topological overlap)"]
    E --> F["1 − TOM 거리로 hierarchical clustering"]
    F --> G["Dynamic Tree Cut → module"]
    G --> H["유사 module 병합 (ME corr > 0.75)"]
    H --> I["Module eigengene (ME), batch 보정한 hME"]
    I --> J["kME로 hub gene, 그룹 비교"]

설명 그림 (직접 작성)

개념 뜻
Correlation 두 gene의 직접적인 동조
Adjacency correlation을 soft power β\betaβ로 거듭제곱해 강한 연결만 부각한 edge
TOM 직접 연결 + 공통 이웃까지 반영한 network 유사도 (noise에 강함)
Dendrogram 1−TOM1 - \text{TOM}1−TOM 거리로 gene을 계층적으로 배열한 tree
Dynamic Tree Cut dendrogram 가지를 잘라 module 결정
ME (module eigengene) module gene들의 첫 번째 주성분 = module 대표 발현
kME gene과 ME의 상관 = module 소속도. 높으면 hub gene

Metacell을 쓰는 이유: 개별 cell은 0이 너무 많아 correlation이 불안정하다. 같은 sample, 같은 cell type 안에서 비슷한 cell 수십 개(예: k=25k = 25k=25)를 평균 내 metacell을 만들면 correlation이 안정된다. Sample을 넘나들며 섞지 않도록 sample × cell type 단위로 만든다.

Gene 선택 예: cell-level HVG 대신 sample × cell type pseudobulk의 logCPM 검출률(예: 자격 donor의 50% 이상에서 logCPM > 4)로 고르고, ribosomal, mitochondrial, IG/TCR V(D)J gene은 뺀다. 이런 gene은 module을 기술적 신호로 오염시킨다 → Batch Correction › 보정 전에 빼는 gene

시나리오별 선택

  • Cell type 안 case vs control: cell type별 network를 만들고 module 보존도(preservation)나 ME 차이 비교
  • 종단(longitudinal): ME나 program usage를 sample 단위로 요약해 Mixed Effects Model로 시간 효과 검정
  • 반응군 비교: 위와 같고 group × time interaction

통계 주의

Module 점수(ME, usage)는 cell 단위로 많지만, 그룹 비교는 sample 단위로 요약하거나 sample random effect를 넣는다. Batch는 입력 단계 보정과 별개로 통계 모델에서도 다시 다룬다.

Measurement model and inference

2023 Su - CS-CORE는 raw UMI count와 depth에서 biological latent covariance를 추정한다. Log-normalized expression의 Pearson correlation과 같은 quantity가 아니다. Correlation estimate, independence test, condition 간 differential co-expression을 구분하고, cell-level resampling이 donor-level 독립성을 대신하지 않는지 확인한다. 구체적인 observation model은 CS-CORE measurement model 참고.

Multi-omics use

  • BioMapAI Figure 4는 gene뿐 아니라 species·KEGG·immune·metabolome feature를 modality별 WGCNA module로 요약하고 eigengene 사이 correlation을 비교했다. Bulk sample/visit 수준의 분석이며 single-cell metacell이나 DNN layer network가 아니다.
  • 구체적 input·soft power·module merge 설정은 BioMapAI WGCNA에 있다. Baseline correlation 부호와 patient–control correlation difference를 구분한다.
