B Cell and BCR

B cell은 항체를 만드는 lymphocyte이고, BCR(B cell receptor)은 그 항체(immunoglobulin, Ig)의 막 결합형이다. V(D)J 조각을 무작위로 조합해 엄청난 다양성을 만들고, 항원을 만난 뒤 Somatic Hypermutation과 Class Switch Recombination으로 진화한다.

#immunology#b-cell#bcr#antibody#vdj

쉽게 말하면

  • V, D, J: "누구를 잡을 것인가"를 정하는 열쇠 머리
  • C (constant): "잡은 뒤 어떻게 처리할 것인가"를 정하는 손잡이 → 이것이 isotype(IgM, IgG, IgA…)

자세히

1. BCR 구조

사슬 구성 유전자 비고
Heavy chain V + D + J + C IGHV, IGHD, IGHJ, IGHC C 영역이 isotype 결정
Light chain V + J + C (D 없음) IGKV/IGLV, IGKJ/IGLJ, IGKC/IGLC κ(kappa)와 λ(lambda) 중 하나만 사용
조각 이름 역할
V Variable 항원과 직접 결합하는 부위의 핵심
D Diversity V와 J 사이에서 결합 부위 다양성을 크게 늘림
J Joining V(또는 D)와 C를 잇는 다리
C Constant isotype과 effector function 결정

이 그림은 저작권 때문에 싣지 않았습니다

왜 조각으로 나뉘어 있나: V 수십 개, D 수십 개, J 몇 개를 무작위로 조합하면 수백 개 조각만으로 수백만 종 이상의 항체를 만들 수 있다. 모든 항원마다 완성된 유전자를 갖는 것보다 훨씬 경제적이다. 조합 경계에서 염기가 더해지고 빠지는 junctional diversity까지 더하면 다양성은 더 커진다 → Clonotype and CDR

2. 유전자 이름 읽기

유전자군 예 설명
IGHV IGHV3-23 heavy chain V (family 1–7)
IGHD IGHD2-2 heavy chain D
IGHJ IGHJ6 heavy chain J
IGHC IGHM, IGHD, IGHG1–4, IGHA1/2, IGHE heavy chain constant → isotype
IGKV / IGLV IGKV1-39, IGLV2-14 κ / λ light chain V
IGKJ / IGLJ IGKJ1, IGLJ3 light chain J
IGKC / IGLC IGKC, IGLC2 light chain constant

주의: IGHD는 "D 조각(IGHD2-2 등)"을 뜻할 수도, "IgD를 만드는 constant 유전자"를 뜻할 수도 있다. 숫자가 붙으면 D 조각이다.

3. Isotype과 IGHC 순서

사람 14번 염색체에 VDJ 뒤로 constant 유전자가 이 순서(5′ → 3′)로 늘어서 있다.

유전자 Isotype 특징
IGHM IgM 감염 초기 가장 먼저 생성, 오량체(pentamer)
IGHD IgD naive B cell 표면, IgM과 함께 발현
IGHG3 IgG3 complement 활성화 강함, IgG 중 먼저 switch되는 편
IGHG1 IgG1 혈청에서 가장 많은 IgG, 단백질 항원
IGHA1 IgA1 점막 면역
IGHG2 IgG2 다당류(세균 벽) 항원
IGHG4 IgG4 염증 억제 경향, 장기 노출 시
IGHE IgE 알레르기, 기생충
IGHA2 IgA2 대장 등 점막, 효소 저항성
  • IGHM, IGHD가 맨 앞이라 naive B cell은 IgM/IgD만 발현한다.
  • Class Switch Recombination은 앞쪽 constant 유전자를 잘라내고 뒤쪽으로 바꾸므로 되돌아갈 수 없다.
  • IgG subclass 비율이 질병 해석에 쓰인다. 급성 염증에서는 IgG3, 만성 자극에서는 IgG1, IgG4가 주목받는 경향이 있다.

4. Light chain: κ와 λ, allelic exclusion

κ (kappa) λ (lambda)
위치 2번 염색체 22번 염색체
구조 여러 V – J 5개 – C 1개 여러 V – (J-C 쌍)이 여러 세트 반복

Allelic exclusion: 한 B cell은 반드시 한 종류의 항체만 만들어야 한다(단일 특이성). 그래서 한 allele에서 재조합에 성공하면 나머지는 꺼진다. 순서는:

  1. κ 첫 번째 allele 시도 → 성공하면 끝
  2. 실패하면 κ 두 번째 allele
  3. 실패하면 λ 첫 번째 allele
  4. 실패하면 λ 두 번째 allele
  5. 모두 실패하면 apoptosis

κ를 먼저 시도하므로 정상 혈액의 κ:λ 비율은 약 **60:40 (1.5:1)**이다. 이 비율이 심하게 깨지면(10:1 등) 한 클론만 비정상적으로 늘어났다는 뜻으로, multiple myeloma나 lymphoma 진단 단서가 된다.

5. scRNA-seq에서 무엇이 보이나

일반 scRNA-seq은 transcript의 한쪽 끝만 읽는다. Constant region은 3′ 쪽(polyA 근처), V(D)J는 5′ 쪽에 있다.

유전자군 3′ scRNA-seq 5′ scRNA-seq 비고
IGHV / IGKV / IGLV ❌ 거의 안 보임 ✅ 5′ 쪽
IGHJ / IGKJ / IGLJ ❌ ✅ 일부
IGHC (IGHM, IGHG1, IGHA1 등) ✅ ✅ 3′ 쪽
IGKC / IGLC ✅ ✅ light chain 구분 가능
Isotype 추정 ✅ (IGHC 발현량) ✅
Clonotype, CDR3 ❌ ✅ (V(D)J kit 필요)

→ 일반 scRNA-seq으로도 IGHM / IGHG1 / IGHA1 발현으로 naive vs memory vs plasma 구분과 κ/λ 구분이 가능하다. Clone 추적과 CDR3는 **5′ + V(D)J kit(scBCR-seq)**이 필요하다.

6. PBMC 안의 B cell isotype

B cell 유형 비율
Naive B (IgM⁺IgD⁺) 전체 B cell의 약 60–70%
Memory B (IgD⁻) IgG⁺ > IgA⁺ > IgM⁺ 순

전체 B cell로 보면 IgM이 우세(naive가 많아서)하지만, memory B cell만 보면 class-switched isotype(IgG, IgA)이 우세하다.

7. 생성부터 진화까지 한눈에

  1. 골수: 조립 — V(D)J recombination, κ 먼저 → 안 되면 λ. Germline과 거의 같은 서열.
  2. 골수: 품질 검사 — 자기 항원에 반응하면 receptor editing이나 제거 (central tolerance)
  3. 림프절: 활성화 — 항원을 처음 만남. 아직 "대충" 잡는 수준.
  4. Germinal center: 훈련 — Somatic Hypermutation으로 BCR이 조금씩 달라지고, Class Switch Recombination으로 isotype이 바뀜
  5. 선발 — 항원을 가장 잘 잡는 클론만 생존 (affinity maturation) → plasma cell, memory B cell

분석할 때 볼 것

  • Clonal expansion: 어떤 클론이 가장 많이 늘었나
  • Isotype 분포: IgM vs IgG vs IgA — 반응의 성격과 만성화 정도
  • Mutation 수 (SHM): 얼마나 오래 훈련된 클론인가
  • κ/λ 비율: 특정 cluster에서 한쪽이 압도적이면 특정 항원에 반응한 클론 확장 가능성
