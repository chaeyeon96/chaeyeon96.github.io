Pseudobulk Analysis

Cell type마다 sample(donor) 단위로 cell의 count를 합쳐 bulk RNA-seq처럼 만든 뒤, edgeR, DESeq2, limma-voom 같은 bulk 도구로 분석하는 방법. 통계 단위를 cell이 아니라 sample로 맞춘다.

#single-cell#differential-expression#statistics#pseudoreplication

쉽게 말하면

환자 10명에게서 cell 10,000개를 얻었다면, 각 환자의 cell을 한 통에 모아 "환자 10명짜리 bulk 데이터"로 만듭니다. 그러면 N이 자연스럽게 10이 되어 p-value가 부풀려지지 않습니다.

자세히

왜 권장되나

  • Pseudoreplication 해결: 같은 sample의 cell끼리는 독립이 아니다 → Mixed Effects Model
  • 오래 검증된 bulk 도구(edgeR TMM, DESeq2, limma-voom)를 그대로 쓸 수 있다.
  • Paired, longitudinal, 공변량(batch, sex, age) 설계를 design formula에 자연스럽게 넣는다.
  • Benchmark에서 cell 수준 방법보다 위양성이 적다고 보고된다 (일반 지식).

절차

  1. Cell type별로 나눈다.
  2. (Cell type, sample)마다 raw count를 합친다 (평균이 아니라 합).
  3. Cell이 너무 적은 조합은 뺀다 (예: 10–20 cell 미만).
  4. Gene filtering (filterByExpr 등).
  5. Normalization (TMM, median-of-ratios) → RNA-seq Normalization
  6. Design: 예 ~ batch + sex + age + condition, paired면 ~ donor + time
  7. DE → 통계량(t, Wald)으로 GSEA

기술 신호가 DEG로 뜰 때

Pseudobulk에서는 cell 단위 QC 값(%MT, %HB)을 바로 공변량으로 넣기 어려워 다음 gene들이 DEG로 자주 뜬다.

Gene 가능한 원인
PPBP, PF4 혈소판 오염, platelet–leukocyte aggregate
HBA/HBB/HBD/HBG 적혈구, globin 잔존
MT-ATP*, MT-ND* 스트레스, 세포사 (MT% 높은 sample)
RPS/RPL 번역 활성, 정규화로 완전히 안 잡히는 조성 차이
전반적 sample별 cell 수와 library size 차이

대처

  • Sample 수준 공변량 만들기: cell 단위 QC를 (cell type, sample)별로 평균 내 n_cells, mt_pct, hb_pct를 design에 넣는다.
  • Module score 공변량: platelet signature(PPBP, PF4, …) 점수를 sample별로 계산해 공변량으로.
  • 숨은 요인: RUVSeq, svaseq로 잡아 공변량으로.
  • 보고 단계에서 분리: 분석에는 넣되 MT-, RPS/RPL, HB- gene은 해석·pathway 보고에서 별도 표시하거나 제외.
  • 진단: 같은 gene이 여러 cell type에서 같은 방향이면 기술·조성 요인 가능성↑, 특정 cell type에서만 기능과 맞게 뜨면 생물학 가능성↑.
  • edgeR-TMM과 voom으로 교차 확인.

한계

  • Sample이 적으면(그룹당 3명 이하) 검정력이 낮다.
  • Cell type 안의 상태 변화(subpopulation 이동)는 평균에 묻힌다 → Differential Abundance Analysis, cell 수준 MAST로 보완.
