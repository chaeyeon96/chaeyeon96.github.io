SCENIC

Single-cell 데이터에서 어떤 transcription factor(TF)가 활성화되어 어떤 target gene들을 조절하는지 찾는 GRN 추론 도구. Co-expression에 DNA motif 근거를 더해 regulon(TF + target set)을 만들고, cell마다 regulon 활성 점수를 준다.

#single-cell#gene-regulatory-network#transcription-factor#tool

쉽게 말하면

"TF A가 오를 때 gene B, C, D도 같이 오른다"(상관)에서 그치지 않고, "B, C, D 근처 DNA에 정말 A가 붙을 수 있는 서열이 있다"(motif)까지 확인합니다. 그래서 단순 상관보다 생물학적 근거가 탄탄합니다.

자세히

3단계

단계 명령 (pySCENIC) 하는 일 출력
1. Co-expression pyscenic grn GRNBoost2(gradient boosting)로 TF 발현이 각 gene 발현을 얼마나 잘 예측하는지 importance 계산 adjacencies.tsv (TF, target, importance) — 아직 검증 전
2. Motif 검증 pyscenic ctx RcisTarget으로 target gene 주변(예: TSS ±10 kb)에 TF motif가 유의하게 enriched된 target만 남김 regulons.csv (검증된 regulon)
3. 활성 점수 pyscenic aucell Cell마다 regulon target이 상위 발현 gene에 얼마나 몰렸는지 AUC → Gene Set Scoring pyscenic_output.loom (cell × regulon AUC)

입력

  • 발현 행렬 (genes × cells). 너무 낮게 발현되는 gene은 미리 걸러야 결과가 깨끗하다.
  • TF 목록 (내장)
  • Motif ranking database (.feather, human/mouse 다운로드)

Downstream

  • AUC 행렬로 clustering·heatmap: 발현량 대신 regulon 활성으로 cell을 보기
  • RSS (regulon specificity score): Jensen–Shannon divergence 기반. 특정 cell type에 특이적인 TF 찾기
  • 그룹·시간 비교: 예를 들어 STAT1 regulon 활성이 치료 4주차에 정점, 반응군에서만 FOXP3 regulon 유지 같은 해석 (sample 단위로 요약해 검정)

실무 주의

  • 계산량이 크다. Cell이 많으면 며칠 걸릴 수 있어 pySCENIC이 R 버전보다 훨씬 빠르고, cell subsampling도 흔하다.
  • GRNBoost2는 random 요소가 있어 여러 번 돌려 안정적인 regulon만 쓰기도 한다 (일반 지식).
  • TF 발현은 낮은데 regulon AUC만 높을 수 있다. TF 단백질은 적어도 효율적으로 일한다고 해석한다.
