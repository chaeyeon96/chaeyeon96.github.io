Cell Type Annotation

Cluster나 개별 cell에 cell type 이름을 붙이는 단계. 자동 분류 도구로 초벌을 하고, marker gene으로 사람이 확인·수정하는 방식이 일반적이다.

#single-cell#annotation#cell-types

쉽게 말하면

Clustering은 "비슷한 cell끼리 묶음"까지만 해 줍니다. 그 묶음이 CD4 T cell인지 monocyte인지는 알려진 marker gene과 reference 데이터를 보고 정합니다.

자세히

방법

방식 예 장단점
Reference 기반 자동 분류 CellTypist, Azimuth, scANVI label transfer, SingleR (일반 지식) 빠르고 일관적. Reference에 없는 cell state는 못 잡거나 엉뚱하게 붙임
Marker 기반 수동 cluster별 marker gene, dot plot, feature plot 해석이 투명. 시간이 들고 사람마다 다를 수 있음
혼합 (권장) 자동 분류 → 수동 확인 → subclustering → 재확인 현실적인 표준
  • CellTypist는 모델마다 해상도가 다르다(예: immune low / high). 처음에는 coarse 모델로 큰 계통을 나누는 게 안정적이다.
  • 자동 분류 결과는 cluster 단위 majority voting으로 정리하면 개별 cell 잡음이 줄어든다.

계층적으로 붙이기

한 번에 세밀하게 붙이기보다 단계를 나눈다.

  • Level 1: CD4 T, CD8 T, NK, B, Myeloid, MAIT 등 큰 계통
  • Level 2: Naive/Memory B, CD14/CD16 monocyte, cDC1/cDC2/pDC, Treg, γδ T 등
  • Level 3: Tfh-like, Th22-like, GZMB-high/GZMK-high CD8 TEM, KLRC2-high NK 등 상태

각 계통을 떼어 내 다시 clustering하면(subclustering) 세밀한 subtype이 잘 보인다.

PBMC marker 요약

Cell type별 marker는 면역 섹션에 정리해 두었다.

  • T cell 분화 단계와 CD4/CD8 subset marker → T Cell and TCR
  • B cell (IGHM, IGHG, IGKC/IGLC, naive vs memory vs plasma) → B Cell and BCR
  • Monocyte, DC subset (CLEC9A, CD1c, CD123 등) → PBMC

흔한 함정

  • CD4 CTL처럼 CD8 T, NK와 비슷한 세포독성 프로그램을 가진 cell은 섞여서 따로 구분이 어렵다. 처음에는 함께 묶어 subtyping하는 편이 낫다.
  • Doublet, 저품질 cell이 작은 "이상한" cluster를 만든다 → Cell Quality Control
  • Batch가 덜 보정되면 같은 cell type이 batch별 cluster로 갈린다 → Batch Correction
  • 혈액에 거의 없어야 할 cell(HSC 등)은 수가 아주 적으면 분석에서 빼거나 따로 표시한다.
