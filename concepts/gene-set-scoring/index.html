Gene Set Scoring

Gene set(signature, pathway)이 각 cell(또는 sample)에서 얼마나 활성화됐는지 점수를 매기는 방법. DE 없이도 pathway 활성을 cell 단위로 비교·시각화할 수 있다.

#single-cell#pathway#scoring#signature

쉽게 말하면

"이 cell은 interferon 반응 점수가 0.8, 저 cell은 0.1" 같은 점수를 모든 cell에 붙입니다. UMAP에 칠하거나, 시간축·pseudotime을 따라 그리기 좋습니다.

도구 비교

도구 원리 특징
AUCell 각 cell에서 gene을 발현 순으로 줄 세우고, gene set이 상위 순위(top-ranked)에 얼마나 몰렸는지를 recovery curve의 AUC로 계산 랭킹 기반이라 정규화 방식에 덜 민감. SCENIC에서 regulon 활성 계산에 쓰임 → SCENIC
UCell Mann–Whitney U 통계량 기반 rank 점수 다른 cell, dataset 구성에 영향을 덜 받음. R, Python(pyUCell) 모두
GSVA, ssGSEA Sample 안 분포 기반 enrichment 점수 원래 bulk용. Pseudobulk sample 점수로 좋음
Seurat AddModuleScore, Scanpy score_genes Set gene 평균 − 발현 수준이 비슷한 대조 gene 평균 간단, 널리 쓰임. Dataset 구성에 따라 값이 변함

AUCell 사용 메모

  • 입력: genes × cells 발현 행렬(log-normalized가 흔함; SingleCellExperiment, dgCMatrix 등), gene set 목록(list 또는 GSEABase GeneSetCollection)
  • 순서: AUCell_buildRankings → AUCell_calcAUC (상위 몇 %까지 볼지 aucMaxRank) → 필요하면 threshold로 "활성 cell" 구분
  • 가장 흔한 실수: gene set의 ID가 행렬 rownames와 정확히 맞지 않아 많이 빠지는 것

통계적으로 쓸 때

  • Score는 시각화와 탐색에 강하지만, 유의성 검정은 sample 단위로 요약한 뒤 한다 (cell을 독립 샘플로 쓰지 않기) → Mixed Effects Model
  • Score를 공변량으로 쓸 수도 있다. 예: platelet signature score를 pseudobulk DE의 공변량으로 → Pseudobulk Analysis
