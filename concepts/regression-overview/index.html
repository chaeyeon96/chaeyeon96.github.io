Regression Overview

Response variable의 종류(연속, 이항, count, 비율)와 데이터 구조(독립, 반복측정)에 따라 고르는 회귀 모델들의 지도.

어떻게 고르나

  1. 반응변수 종류
    • 연속형 → linear regression (반복측정이면 LMM)
    • 이항 → logistic / probit
    • count → Poisson / negative binomial
    • 비율(0–1) → beta regression
  2. 데이터 구조
    • 샘플이 서로 독립 → GLM
    • 같은 환자·배치에서 여러 측정이 나옴 → Mixed Effects Model (LMM, GLMM, NEBULA 등)
  3. 복잡도와 가정
    • 비선형 관계 → polynomial, spline
    • 과적합, multicollinearity → ridge, lasso, elastic net
  4. 해석 vs 예측
    • 계수와 p-value 해석이 목적 → 전통적 회귀 모델
    • 예측력이 목적 → regularized regression, 트리 앙상블

왜 중요한가

  • scRNA-seq 분석의 많은 단계가 결국 회귀입니다. 예: MAST의 hurdle model은 logistic + linear, cell-level 비교는 mixed model, program usage 비교는 beta regression.
  • 반응변수와 데이터 구조를 잘못 고르면 p-value가 틀립니다. 특히 cell을 독립 샘플로 취급하는 pseudoreplication이 흔한 실수입니다 (Mixed Effects Model 참고).

Prediction and validation in age models

2023 Zhu - PBMC Aging Clock의 PLSR과 2025 Wang - Lifespan Immune Trajectories의 random forest는 같은 age prediction 질문에 다른 모델을 적용한다. Training correlation, donor-level cross-validation, external healthy validation, disease-cohort generalization을 따로 본다. Correlation이 높아도 calibration·absolute error가 좋다는 보장은 없으며 prediction residual을 biological rejuvenation으로 단정하지 않는다. Feature selection과 scaling이 validation fold 바깥에서 수행되면 leakage가 생길 수 있다.
