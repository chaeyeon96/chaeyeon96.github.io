scVI (single-cell Variational Inference)

Raw count를 ZINB(zero-inflated negative binomial) 분포에서 생성된 것으로 보고, 신경망(VAE)으로 batch와 생물학적 신호를 분리하는 확률 모델 (Lopez et al., 2018). Batch correction된 latent embedding과 보정된 expression을 함께 준다.

#single-cell#deep-learning#batch-effect#vae#tool

쉽게 말하면

"이 cell의 count는 (생물학적 상태 + batch + sequencing 깊이)가 합쳐져 나온 결과"라고 모델링합니다. 학습 뒤에는 batch와 깊이 효과를 뺀 생물학적 상태만으로 "모든 cell이 같은 조건에서 측정됐다면 가졌을 발현량"을 다시 만들어 줍니다.

자세히

변수

변수 의미
xngx_{ng}xng​ cell nnn, gene ggg의 관측 count
znz_nzn​ 생물학적 latent 변수 (저차원). Batch와 독립이 되도록 학습
sns_nsn​ batch와 공변량 (batch_key의 sample, categorical_covariate_keys의 회사 등)
ℓn\ell_nℓn​ library size (sequencing depth, capture 효율)
ρng\rho_{ng}ρng​ 정규화된 기대 빈도 (cell nnn에서 gene ggg가 차지할 비율)
θg\theta_gθg​ gene별 inverse dispersion (overdispersion 학습)

학습과 출력

  1. Encoder: xnx_nxn​과 sns_nsn​을 받아 znz_nzn​의 분포를 추정한다. 발현 변동 중 batch(sns_nsn​)로 설명되는 부분과 생물학(znz_nzn​)으로 설명되는 부분을 나누려 한다.
  2. Decoder: znz_nzn​과 sns_nsn​으로 ZINB 파라미터를 만든다. 이때 나오는 ρng\rho_{ng}ρng​는 "batch가 보정된, 정규화된 transcript 비율 추정치"다.
  3. get_normalized_expression: 기술적 조건을 고정하거나 평균 내고 znz_nzn​만으로 ρ\rhoρ를 계산한 뒤 library size를 곱해 돌려준다 → batch와 깊이 차이가 빠진 denoised count

출력값의 성격 (자주 헷갈림)

  • Log 스케일이 아니다. 원래 count와 같은 선형 단위, 0 이상
  • Centering, scaling(z-score)이 안 되어 있다. 많이 발현되는 gene은 값도 크다
  • Overdispersion은 모델 안에서 θg\theta_gθg​로 다룰 뿐, 출력을 정규화해 주지 않는다
  • Heatmap, PCA 등에 쓰려면 받은 뒤 직접 sc.pp.log1p() → sc.pp.scale()을 적용한다

주요 설정 (예)

  • 입력은 raw count (normalize하지 않은 것)
  • HVG 수, latent 차원(n_latent, 보통 10–30), random seed
  • X_scVI를 use_rep로 KNN Graph를 만들어 clustering, UMAP

관련 모델 (일반 지식)

  • scANVI: 일부 cell type label을 함께 써서 latent를 다듬는 semi-supervised 버전. Annotation refine에 쓴다.
  • scVI 기반 DE: model.differential_expression()으로 Bayesian DE를 할 수 있다 → Differential Expression
