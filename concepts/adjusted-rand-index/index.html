Adjusted Rand Index (ARI)

Clustering 결과가 정답 label과 얼마나 일치하는지 재는 지표. 우연히 일치하는 정도를 빼서 보정한 것이 핵심이다. 1이면 완벽, 0이면 무작위 수준.

#statistics#clustering#evaluation

쉽게 말하면

모든 데이터 쌍을 하나씩 보며 "정답에서 같은 그룹인 쌍을 clustering도 같이 묶었나, 다른 그룹인 쌍을 따로 나눴나"를 셉니다. 그런데 아무렇게나 나눠도 어느 정도 맞으니, 그 우연한 점수를 빼고 봅니다.

자세히

1. Rand Index (RI)

모든 쌍에 대해:

  • TP: 정답에서 같은 그룹이고 clustering도 같은 cluster
  • TN: 정답에서 다른 그룹이고 clustering도 다른 cluster

RI=TP+TN전체 쌍의 수RI = \frac{TP + TN}{\text{전체 쌍의 수}} RI=전체 쌍의 수TP+TN​

단점: 무작위로 나눠도 꽤 높게 나온다.

2. ARI: 우연을 빼고 정규화

ARI=Index−Expected IndexMax Index−Expected IndexARI = \frac{\text{Index} - \text{Expected Index}}{\text{Max Index} - \text{Expected Index}} ARI=Max Index−Expected IndexIndex−Expected Index​

값 의미
1.0 완벽하게 일치
0.0 무작위로 나눈 것과 같음
음수 무작위보다 못함

3. Contingency table로 계산

정답 그룹 iii와 cluster jjj에 동시에 속한 개수를 nijn_{ij}nij​, 행 합을 aia_iai​, 열 합을 bjb_jbj​, 전체를 nnn이라 하면:

ARI=∑ij(nij2)−[∑i(ai2)∑j(bj2)]/(n2)12[∑i(ai2)+∑j(bj2)]−[∑i(ai2)∑j(bj2)]/(n2)ARI = \frac{\sum_{ij}\binom{n_{ij}}{2} - \left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right]\big/\binom{n}{2}} {\tfrac{1}{2}\left[\sum_i\binom{a_i}{2} + \sum_j\binom{b_j}{2}\right] - \left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right]\big/\binom{n}{2}} ARI=21​[∑i​(2ai​​)+∑j​(2bj​​)]−[∑i​(2ai​​)∑j​(2bj​​)]/(2n​)∑ij​(2nij​​)−[∑i​(2ai​​)∑j​(2bj​​)]/(2n​)​

from sklearn.metrics import adjusted_rand_score
adjusted_rand_score(true_labels, cluster_labels)

Single-cell에서

  • Label이 있는 benchmark 데이터에서 embedding이나 integration 방법이 생물학적 구조를 얼마나 잘 보존하는지 비교할 때 씁니다.
  • Leiden Clustering의 resolution에 따라 결과가 달라지므로, resolution을 바꿔 가며 최대 ARI를 보고하는 경우가 많습니다.
  • 비슷한 지표로 NMI(Normalized Mutual Information)가 있습니다. (일반 지식)

논문별 활용

  • 2025 Sheinin - scNET: Usoskin 데이터에서 Leiden resolution을 0~1로 바꿔 가며 최대 ARI를 비교했다. scNET embedding 0.46 vs 원래 발현 0.35.
