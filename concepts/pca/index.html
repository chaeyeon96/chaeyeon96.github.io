PCA (Principal Component Analysis)

많은 변수를, 데이터의 분산을 가장 많이 설명하는 소수의 새 축(principal component, PC)으로 요약하는 차원 축소 방법.

#statistics#dimensionality-reduction#preprocessing

쉽게 말하면

변수 2,000개짜리 데이터에서 "가장 크게 퍼져 있는 방향"부터 차례로 축을 잡아, 앞의 몇십 개 축만 남기는 것입니다. 정보 손실은 적게, 차원은 크게 줄입니다.

자세히

원리 (일반 지식)

  1. 각 변수를 중심화(평균 0)하고 보통 표준화(분산 1)한다.
  2. 공분산 행렬의 eigenvector가 PC 방향, eigenvalue가 그 방향의 분산이다.
  3. Eigenvalue가 큰 순서로 PC를 정렬하고 상위 kkk개에 데이터를 투영(projection)한다.
  4. 각 PC의 explained variance ratio로 몇 개를 남길지 정한다 (scree plot, elbow).

전처리가 결과를 좌우한다

PCA는 스케일에 민감합니다. 값이 큰 변수가 PC를 독차지하지 않도록 보통 다음 순서를 거칩니다.

  1. Count → 비율: sample마다 sequencing depth가 다르므로 총합이 1이 되도록 정규화
  2. Log 변환: 편차가 큰 값의 분포를 고르게
  3. Z-scoring: 변수마다 평균을 빼고 표준편차로 나눔
  4. PCA projection: 상위 kkk개 PC만 남김

Data leakage 주의

Train/test로 나눠 모델을 평가할 때는 평균, 표준편차, PCA 축을 모두 training set에서만 계산하고, test set은 그 기준으로 투영만 해야 합니다. 전체 데이터로 PCA를 먼저 하면 test 정보가 학습에 새어 들어가 성능이 부풀려집니다.

Single-cell에서 (일반 지식)

  • Normalize → log1p → HVG 선택 → scaling → PCA(보통 30~50 PC) → KNN Graph → Leiden Clustering, UMAP 순서의 표준 pipeline에서 PCA가 첫 차원 축소입니다.
  • PC 공간에서 batch 차이가 크면 batch correction(예: Harmony, scVI)을 고려합니다.

논문별 활용

  • 2025 Zaslavsky - Mal-ID (Model 1): sample별 V–J gene 조합 count → 비율 → log → z-score → PCA로 상위 15개 PC를 feature로 사용. BCR은 IgG, IgA, IgM/D 각각 따로 해서 15 × 3 = 45개. 모든 변환 기준은 training set에서만 계산했다.
