Reference Mapping

새 query cells를 이미 정의한 reference representation 또는 label 체계에 연결하는 분석이다. (일반 지식)

#reference#annotation#integration

Intuition

새 지도를 처음부터 다시 그리지 않고 기존 지도에서 새 sample의 위치를 찾는다. 기존 지도에 없는 지역을 억지로 가장 가까운 지역 이름으로 부르면 오해가 생긴다.

Details

  • Input은 query expression과 reference model/labels이며 output은 embedding, neighbors, transferred label 또는 uncertainty이다.
  • Reference mapping, de novo integration, nearest-neighbor annotation은 관련되지만 같은 작업은 아니다.
  • Healthy reference가 disease-specific state를 충분히 표현하지 못할 수 있다. Mapping이 잘 된다는 것과 biological disease effect가 보존된다는 것을 따로 평가한다.
  • Sample/study별 holdout, rare type coverage, batch confounding, unknown-type rejection을 확인한다. (일반 지식)

Why it matters

Atlas를 재사용할 수 있지만 reference 구성에 따른 편향을 query의 생물학적 차이로 해석해서는 안 된다.

Paper-specific use

  • 2023 Dann - Healthy Reference Design: Atlas-only와 atlas+control design을 구분한다.
  • 2023 De Donno - scPoli: Sample embedding과 prototype 기반 표현을 사용한다.
  • 2025 Heimberg - SCimilarity: Learned metric과 nearest-neighbor search를 이용한다. 세 방법의 output과 학습 목적이 다르므로 동일한 embedding이라는 이유로 성능을 직접 비교하지 않는다.

Query mapping assumptions

2023 De Donno - scPoli의 query mapping에서는 reference network와 저장된 prototype을 활용하면서 query condition representation을 학습한다. Prototype distance는 calibrated probability가 아니며 모든 dataset에 공통인 unknown threshold가 보장되지 않는다. Raw reference cells 없이 mapping할 수 있다는 것과 formal privacy guarantee는 다르다. Query mapping 참고.
