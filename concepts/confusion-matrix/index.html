Confusion Matrix

분류 모델(또는 진단 검사)의 예측과 실제 정답을 2×2 표로 정리한 것. Sensitivity, specificity, precision 같은 평가 지표가 모두 여기서 나온다.

#statistics#classification#diagnostics#evaluation

쉽게 말하면

  • Sensitivity: 실제 환자를 얼마나 놓치지 않고 찾아내나
  • Specificity: 실제 정상인을 얼마나 잘 걸러내나 (오진하지 않나)
  • Precision (PPV): "환자"라고 판정한 것 중 진짜 환자는 몇 %인가

자세히

표

실제 Positive (gold standard +) 실제 Negative (gold standard −)
예측 Positive TP (진양성) FP (위양성, 멀쩡한 사람을 오진) → Precision = TP / (TP + FP)
예측 Negative FN (위음성, 환자를 놓침) TN (진음성) → NPV = TN / (FN + TN)
↓ Sensitivity (Recall) = TP / (TP + FN) ↓ Specificity = TN / (TN + FP)
  • 앞 글자(T/F): 예측이 맞았나
  • 뒷 글자(P/N): 무엇이라고 예측했나

지표 정리

지표 식 의미
Sensitivity (= Recall, TPR) TP / (TP + FN) 실제 환자 중 찾아낸 비율
Specificity (TNR) TN / (TN + FP) 실제 정상 중 정상으로 판정한 비율
Precision (= PPV) TP / (TP + FP) Positive 판정 중 진짜 비율
NPV TN / (FN + TN) Negative 판정 중 진짜 비율
Accuracy (TP + TN) / 전체 전체 정답 비율
Prevalence (TP + FN) / 전체 전체 중 실제 환자 비율
Odds ratio (TP·TN) / (FP·FN) 환자가 정상인에 비해 positive를 받을 odds가 몇 배인가
Relative risk [TP/(TP+FP)] / [FN/(FN+TN)] Positive 판정이 negative 판정보다 실제 환자일 확률이 몇 배인가

Prevalence와의 관계

  • Sensitivity, specificity는 prevalence와 무관합니다. 검사 자체의 성질입니다.
  • PPV는 prevalence에 비례, NPV는 반비례합니다. 같은 검사라도 희귀 질환 집단에서는 PPV가 낮아집니다.
  • 그래서 데이터가 불균형할 때(예: 1000명 중 환자 5명) accuracy만 보면 안 되고 sensitivity/specificity나 precision/recall을 함께 봐야 합니다.

Threshold에 따른 trade-off

판정 기준(threshold)을 바꾸면 둘이 시소처럼 움직입니다.

  • Threshold를 낮추면 ("조금만 의심돼도 positive"): sensitivity ↑, specificity ↓ → screening용. 높은 sensitivity 검사에서 negative가 나오면 질병을 rule out할 수 있다.
  • Threshold를 높이면 ("확실할 때만 positive"): specificity ↑, sensitivity ↓ → 확진용. 높은 specificity 검사에서 positive가 나오면 rule in할 수 있다.
  • Precision과 recall도 같은 trade-off 관계입니다.
  • 모든 threshold에서의 sensitivity와 1 − specificity를 그린 곡선이 ROC curve, 그 아래 면적이 AUROC입니다. (일반 지식)
