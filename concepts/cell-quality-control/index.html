Cell Quality Control

각 droplet이 "온전한 cell 하나"라는 가정을 깨는 것들, 즉 죽어가는 cell, 배경 RNA, doublet을 걸러 내는 단계.

#single-cell#qc#preprocessing

쉽게 말하면

분석은 "droplet 하나 = 건강한 cell 하나"를 전제로 합니다. 막이 터져 내용물이 샌 cell, 빈 droplet에 떠다니던 RNA, cell 두 개가 한 droplet에 들어간 경우는 이 전제를 깨므로 미리 뺍니다.

자세히

무엇을 보나

지표 낮거나 높으면 의미
Detected genes (n_genes) 너무 낮음 죽어가는 cell, 빈 droplet
Total counts (UMI) 너무 낮음 / 너무 높음 저품질 / doublet 의심
MT fraction (MT- gene 비율) 높음 막이 손상된 cell. 세포질 mRNA는 빠져나가고 큰 미토콘드리아는 남아 MT 비율이 오른다
Hemoglobin fraction (HB-) 높음 적혈구 오염 (PBMC에서)
Ribosomal fraction (RPS/RPL) 비정상적으로 낮음 저품질 cell일 수 있음
Platelet gene (PPBP, PF4) 높음 혈소판 오염 또는 platelet–cell 결합
Doublet score 높음 두 cell이 한 droplet에 → scDblFinder, Scrublet 등
  • 낮은 gene 수, 낮은 count, 높은 MT 비율이 함께 나타나면 전형적인 저품질 cell이다.
  • Threshold는 데이터마다 다르다. 분포를 보고 정하거나, MAD(median absolute deviation) 기반으로 sample마다 자동으로 정하는 방법이 권장된다 (일반 지식).
  • PBMC 예시 기준: genes ≥ 400, counts ≥ 2000, MT < 10%, HB < 0.5%, platelet < 0.5%, singlet만. (예시이며 데이터에 맞게 조정)

순서

  1. CellBender로 ambient RNA 보정 (CellBender의 cell 확률로 바로 filtering하기보다, 보정된 count를 쓰고 QC는 따로 하는 경우가 많다)
  2. Cell QC threshold 적용
  3. Doublet 제거
  4. Sample QC: cell이 너무 적거나 품질이 전체적으로 나쁜 sample 제거

주의

  • 질병 조직의 cell은 원래 스트레스가 높아 MT 비율이 높을 수 있다. 너무 엄격하면 진짜 생물학적 신호를 버린다.
  • 같은 batch의 sample들이 한꺼번에 품질이 나쁘면 QC 지표 자체가 batch effect가 된다. 시점(timeline)별로 pool을 묶거나 문제 sample을 빼는 식으로 대응한다.
