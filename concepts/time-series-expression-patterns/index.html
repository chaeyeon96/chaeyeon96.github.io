Time-series Expression Patterns

여러 시점에서 측정한 발현을 gene별로 시간에 따른 변화 모양으로 묶어, 약물 반응이나 질병 진행의 타이밍을 이해하는 분석.

#single-cell#longitudinal#clustering#time-series

쉽게 말하면

치료 후 0, 4, 12주에 측정했다면 "초반에 확 올랐다 유지", "늦게 올라감", "잠깐 올랐다 내려옴" 같은 모양이 있습니다. 같은 모양끼리 gene을 묶으면 반응의 단계별 생물학을 볼 수 있습니다.

자세히

절차

  1. 시간 효과가 있는 gene 고르기: 종단 DE(시간 효과, 또는 group × time interaction)로 후보를 먼저 거른다 → Differential Expression
  2. 행렬 준비: cell type별·시점별 평균 발현 (row: gene, column: 0w, 4w, 12w). 가능하면 sample 단위 pseudobulk로.
  3. Gene별 Z-score: 절대량이 아니라 변화 추이만 보기 위해 필수.
  4. Clustering
    • K-means: 단순, gene마다 하나의 cluster
    • Mfuzz (soft / fuzzy c-means): gene이 여러 패턴에 소속 확률을 가짐. noise에 강해 시계열에 자주 쓰임. fuzziness mmm은 보통 1.25–2.
  5. Cluster 수: 4–6개에서 시작해 패턴이 중복되지 않는 선에서 결정.
library(Mfuzz)
eset <- ExpressionSet(as.matrix(avg_expr))  # genes × timepoints
eset_s <- standardise(eset)                  # gene별 Z-score
cl <- mfuzz(eset_s, c = 6, m = 1.25)
mfuzz.plot(eset_s, cl = cl, mfrow = c(2, 3), time.labels = c("0w", "4w", "12w"))

흔한 패턴과 해석

패턴 모양 의미 예
Early up 0 → 4주 급증 후 유지 초기 약물 효과
Late up 4주까지 조용하다 12주 증가 장기 적응, 늦은 반응
Transient 4주에 정점 후 회복 일시적 반응
Early down 초반 급감 후 유지 빠르게 억제되는 염증 경로
Late down 늦게 감소 서서히 꺼지는 경로
Rebound 내려갔다 다시 올라감 효과 소실, 보상 반응

Clustering 이후

  • 패턴별 enrichment → 시기별 생물학 → Gene Set Enrichment Analysis
  • 반응군 vs 비반응군에서 같은 gene이 다른 패턴에 속하는지 비교
  • 패턴 대표 gene을 score로 만들어 cell type, sample별로 확인
  • Trajectory의 pseudotime과 실제 시간을 연결해 해석 → Trajectory Analysis

주의

  • 시점이 3개면 가능한 모양이 제한적이다. 과도한 cluster 수는 noise를 패턴으로 오해한다.
  • 평균을 내기 전 sample 수와 시점별 결측을 확인한다.
