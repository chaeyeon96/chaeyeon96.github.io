Cell-Cell Communication (CCC)

Ligand(보내는 cell)와 receptor(받는 cell)의 발현으로 어떤 cell type이 어떤 신호로 서로 대화하는지 추론하는 분석.

#single-cell#cell-cell-communication#ligand-receptor

쉽게 말하면

CCC는 **"누가 누구에게 전화를 걸었나(통화 기록)"**입니다. Sender cell의 ligand와 receiver cell의 receptor가 둘 다 높으면 대화 중이라고 봅니다. 단, 전화를 실제로 받았는지(신호가 전달되어 receiver가 변했는지)는 따로 확인해야 합니다 → Cytokine and Pathway Activity

입력과 batch

  • CCC 도구는 이미 정규화·보정된 발현을 전제로 한다. CellChat은 log-normalized 데이터를 받는다.
  • scVI 보정값을 쓸 때는 log1p를 적용해 쓰고, scaling으로 음수가 생기거나 sparse 포맷이 깨지면 에러가 난다.

NicheNet 핵심

  1. Sender에서 발현되는 ligand, receiver에서 발현되는 receptor로 후보를 만든다.
  2. Ligand activity: 각 ligand가 알려진 target set으로 receiver의 **gene of interest(DEG)**를 얼마나 잘 설명하나 (Pearson, AUPR).
  3. 상위 ligand의 ligand → receptor → signaling → TF → target 경로를 network에서 추론.

P(G∣L)=∑R,S,TFP(G∣TF) P(TF∣S) P(S∣R) P(R∣L)P(G \mid L) = \sum_{R, S, TF} P(G \mid TF)\, P(TF \mid S)\, P(S \mid R)\, P(R \mid L) P(G∣L)=R,S,TF∑​P(G∣TF)P(TF∣S)P(S∣R)P(R∣L)

  • Input: sender/receiver 발현, receiver DEG 목록, background gene, prior network
  • Output: ligand activity 점수, ligand–target 링크 행렬, signaling path

Tensor-cell2cell 핵심

  • 텐서의 한 칸 (i,j,k,l)(i, j, k, l)(i,j,k,l) = sample iii에서 L–R pair jjj로 sender kkk가 receiver lll에게 보내는 communication score (예: ligand와 receptor 발현의 기하평균)
  • CP decomposition: 텐서를 rank RRR개 factor의 외적 합으로 근사. Factor마다 4개 loading 벡터(sample, L–R, sender, receiver)가 "어떤 sample에서, 어떤 cell들이, 어떤 신호로 함께 움직이나"를 알려 준다.
  • Rank는 elbow(reconstruction error)로 정하고, 설명 분산(예: 0.8)을 보고한다.
  • Sample loading을 그룹 간 비교하면 질병·반응군 특이 모듈을 찾을 수 있다.

자주 쓰는 조합

  1. Tensor-cell2cell → CellChat → NicheNet: 다중 sample 공통 모듈 발굴 → 상세 L–R와 송수신 역할 → 하류 유전자 변화로 기전 검증
  2. CCC + pathway activity: CCC로 가설("myeloid → T cell CD86–CD28 신호 증가")을 세우고, receiver T cell의 pathway·cytokine 점수로 실제 반응을 확인 → Cytokine and Pathway Activity

할 수 있는 분석

  • Pathway 수준 비교 (예: TNF 경로가 어느 그룹에서 강한가)
  • Differential interaction (질병군에서 새로 생기거나 사라진 L–R)
  • Hub cell (통신을 주도하는 cell type)
  • Niche (기능적으로 밀접하게 소통하는 cell 묶음)

주의

  • 상위 결과에 housekeeping 성격의 L–R(PPIA, CD99, MIF 등)이 많이 뜨는 경향이 있다. 생물학적 해석 전에 걸러 본다.
  • mRNA 기반 추론이다. 단백질 수준, 공간적 근접성은 보장하지 않는다.
