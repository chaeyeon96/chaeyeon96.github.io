scRNA-seq Workflow

Raw sequencing data에서 cell type별 해석까지 가는 scRNA-seq 분석의 표준 단계 지도. 각 단계는 별도 개념 페이지로 연결된다.

#single-cell#pipeline#workflow

쉽게 말하면

  1. 세포 만들기: read를 정렬하고 진짜 cell을 고른다.
  2. 청소하기: 배경 RNA, 질 나쁜 cell, doublet을 뺀다.
  3. 정리하기: normalize하고 batch 차이를 지운다.
  4. 지도 그리기: 이웃 graph를 만들고 clustering, UMAP으로 본다.
  5. 이름 붙이기: cluster에 cell type을 단다.
  6. 비교하기: 조건 간 발현, 비율, 통신, 경로를 비교한다.

자세히

flowchart TD
    A["FASTQ"] --> B["Step 1 · Alignment, cell calling<br/>Cell Ranger, STARsolo, DRAGEN"]
    B --> C["Step 2 · Ambient RNA 제거<br/>CellBender"]
    C --> D["Step 3 · Cell QC<br/>genes, counts, MT%, doublet"]
    D --> E["Step 4 · Normalization<br/>log1p(CPM), SCTransform"]
    E --> F["Step 5 · HVG 선택 → PCA"]
    F --> G["Step 6 · Batch correction / integration<br/>scVI, Harmony"]
    G --> H["Step 7 · KNN graph"]
    H --> I["Leiden clustering"]
    H --> J["UMAP"]
    I --> K["Step 8 · Cell type annotation<br/>CellTypist + marker"]
    K --> L["Step 9 · Downstream 분석"]

설명 그림 (직접 작성)

단계 하는 일 페이지
1 Read 정렬, barcode별 count matrix, cell calling Single-cell RNA-seq
2 빈 droplet의 배경 RNA(ambient RNA) 제거 CellBender
3 죽어가는 cell, doublet 제거 Cell Quality Control
4 Sequencing depth 차이 보정 RNA-seq Normalization
5–6 차원 축소, batch 제거 PCA, Batch Correction, scVI
7 이웃 graph, clustering, 시각화 KNN Graph, Leiden Clustering
8 Cluster에 cell type 이름 Cell Type Annotation

9. Downstream 분석 메뉴

질문 분석 페이지
어떤 gene이 달라졌나 Differential expression Differential Expression, MAST, Pseudobulk Analysis
어떤 pathway가 달라졌나 Enrichment, gene set scoring Gene Set Enrichment Analysis, Gene Set Scoring
Cell type 비율이 달라졌나 Differential abundance Differential Abundance Analysis
Gene들이 어떤 module로 묶이나 Co-expression, gene program Co-expression Network Analysis, cNMF
어떤 TF가 조절하나 GRN inference SCENIC
Cell끼리 어떤 신호를 주고받나 Cell–cell communication Cell-Cell Communication
Cytokine, pathway가 얼마나 활성화됐나 Activity scoring Cytokine and Pathway Activity
Cell 상태가 어떻게 이어지나 Trajectory, pseudotime Trajectory Analysis
시간에 따라 어떤 패턴으로 변하나 Time-series clustering Time-series Expression Patterns

꼭 기억할 원칙

  • Sample이 통계 단위다. Cell 수천 개도 환자 몇 명에서 나왔다면 N은 환자 수다 → Mixed Effects Model, Pseudobulk Analysis
  • Batch effect는 모든 단계에 영향을 준다. 특히 case와 control이 서로 다른 batch에 쏠려 있으면(confounding) 보정으로도 구분이 어렵다.
  • Clustering과 annotation은 반복 작업이다. Resolution을 바꾸고 marker를 확인하며 여러 번 오간다.
