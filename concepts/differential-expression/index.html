Differential Expression (DE)

두 조건(질병 vs 정상, 치료 전 vs 후 등) 사이에서 발현이 유의하게 다른 gene(DEG)을 찾는 분석. Single-cell에서는 cell 단위로 할지, sample 단위로 모아서 할지가 가장 큰 선택이다.

#single-cell#differential-expression#statistics

쉽게 말하면

"이 cell type에서 환자와 정상인 사이에 어떤 gene이 오르고 내렸나?"를 묻는 분석입니다. 핵심 함정은 cell 수천 개를 독립 샘플처럼 다루면 p-value가 터무니없이 작아진다는 것입니다.

자세히

방법 지도

계열 도구 특징 언제
단순 검정 Wilcoxon (Seurat 기본), t-test 빠르고 직관적. dropout, overdispersion, sample 구조 무시 cluster marker 찾기
Cell 수준 모델 MAST (hurdle model) dropout을 명시적으로 모델링, covariate와 random effect 가능 cell 수준 차이, 면역 연구에서 흔함
glmGamPoi 빠른 Gamma-Poisson GLM 대규모 데이터
Bayesian / generative scVI DE 모델에서 반복 샘플링해 Bayes factor 계산, batch를 모델 안에서 통제 batch가 복잡한 대규모 데이터
BASiCS 기술 노이즈와 생물학 변동 분리. 계산량 큼 소규모
Sample 수준 Pseudobulk + edgeR / DESeq2 / limma-voom cell을 sample별로 합쳐 bulk 도구 사용. paired, covariate 가능 반복 sample, 종단 연구에서 가장 권장
dream (variancePartition), lme4, glmmTMB pseudobulk에 mixed model 반복측정, 복잡한 random effect
종단 특화 PALMO, IDEAS longitudinal 변동 분해, 분포 수준 비교 시간축 cohort

정리

  • Cluster marker 탐색 → Wilcoxon, MAST
  • 노이즈 보정 + robust → scVI, glmGamPoi
  • Sample 반복, 종단, paired 설계 → pseudobulk → edgeR/DESeq2/limma-voom, 보조로 MAST(cell 수준 확인), 필요하면 scVI Bayes factor

Batch를 DE에서 다루는 법

전략 방법 비고
① 공변량으로 넣기 (가장 권장) 원래 count 유지 + ~ condition + batch + ... 해석이 가장 명확한 기준선
② latent factor 추가 sva/svaseq, RUVSeq, PEER(bulk·pseudobulk), zinbwave/NewWave, IA-SVA(single-cell)로 숨은 요인을 뽑아 공변량으로 알려지지 않은 노이즈가 클 때
③ 보정된 값으로 DE ComBat-Seq 등으로 count 자체를 보정 over-correction 위험. condition과 batch가 꼬여 있지 않은지 반드시 확인
✗ Representation 전용 Harmony, fastMNN, scVI latent clustering, UMAP용. DE 입력값으로 쓰지 않는다
  • scVI의 보정된 expression(평균값)을 MAST 같은 빈도주의 도구에 그대로 넣으면 분산이 실제보다 작다고 착각해 위양성이 늘어난다. scVI로 보정했다면 scVI 자체 DE를 쓰거나, 원래 count + 공변량을 쓴다.
  • Condition과 batch가 겹친(confounded) 설계에서는 batch를 공변량으로 넣으면 모델이 rank deficient가 되어 질병 효과가 batch에 먹힌다. 이때는 condition 정보를 먼저 빼고(그룹 내 centering) 남은 변동으로 batch 요인을 뽑는 등의 우회가 필요하다 → Batch Correction

DEG 결과 검증 체크리스트

  1. 통계: raw p-value 히스토그램(신호는 0 근처, 나머지는 균등), QQ-plot(초반에 크게 벗어나면 위양성 의심)
  2. 효과 크기: MA plot(신호가 low-count gene에만 몰리면 의심), volcano plot(logFC는 작은데 p만 작은 gene이 많으면 주의)
  3. 생물학: 알려진 marker가 기대 방향인지, 무관한 gene이 대거 뜨지 않는지
  4. 기술 요인: MT-, RPS/RPL, HB-, platelet gene(PPBP, PF4)이 여러 cell type에서 같은 방향으로 뜨면 오염이나 조성 차이 신호일 가능성 → Pseudobulk Analysis › 기술 신호가 DEG로 뜰 때
  5. 재현성: label permutation 시 DEG가 거의 없어야 함, pseudobulk로도 같은 패턴인지, 독립 데이터셋에서 같은 방향인지
