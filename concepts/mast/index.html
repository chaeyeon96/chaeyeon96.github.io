MAST

Single-cell DE 도구. 각 gene의 발현을 "검출됐나(discrete)"와 "검출됐다면 얼마나(continuous)" 두 부분으로 나눠 따로 회귀하는 hurdle model을 쓴다 (Finak et al., Genome Biology 2015).

#single-cell#differential-expression#hurdle-model#tool

쉽게 말하면

scRNA-seq에는 0이 너무 많고(dropout과 진짜 0이 섞임), cell마다 검출력이 다릅니다. MAST는 "켜졌나 꺼졌나"와 "켜졌다면 얼마나 세게"를 따로 보고, 둘 중 하나라도 조건 간에 다르면 DEG로 잡습니다.

자세히

모델 (gene ggg, cell iii, 설계행렬 XiX_iXi​)

입력은 보통 log2(TPM + 1) 같은 log-normalized 발현.

Discrete part (검출 여부 ZigZ_{ig}Zig​): logistic regression

logit P(Zig=1)=XiβgD\text{logit}\,P(Z_{ig} = 1) = X_i \beta_g^{D} logitP(Zig​=1)=Xi​βgD​

Continuous part (검출된 cell에서의 발현 YigY_{ig}Yig​): Gaussian 선형회귀

Yig∣Zig=1∼N(XiβgC,σg2)Y_{ig} \mid Z_{ig} = 1 \sim \mathcal{N}(X_i \beta_g^{C}, \sigma_g^2) Yig​∣Zig​=1∼N(Xi​βgC​,σg2​)

안정화 장치

  • Discrete 계수의 Bayesian regularization: 한 그룹에서만 검출되는 complete separation이 생기면 계수가 발산하므로 arm::bayesglm의 weakly informative prior를 쓴다 → Logistic Regression › 5. Separation과 Bayesian regularization
  • Continuous 분산의 empirical Bayes shrinkage: 검출된 cell 수가 gene마다 달라 분산 추정의 정보량이 다르다. Precision τg=1/σg2∼Gamma(α,β)\tau_g = 1/\sigma_g^2 \sim \text{Gamma}(\alpha, \beta)τg​=1/σg2​∼Gamma(α,β)로 두고 모든 gene에 공통 hyperparameter를 추정해 gene별 분산을 전체 쪽으로 당긴다.
  • CDR (cellular detection rate): cell에서 검출된 gene 비율을 공변량으로 넣어 cell별 검출력 차이를 보정한다. 실무에서는 n_genes를 넣기도 한다.

검정: hurdle test

두 부분을 조건부 독립으로 보므로 검정 통계량을 더할 수 있다.

Tghurdle=Tg(D)+Tg(C)∼χdfD+dfC2T_g^{\text{hurdle}} = T_g^{(D)} + T_g^{(C)} \sim \chi^2_{df_D + df_C} Tghurdle​=Tg(D)​+Tg(C)​∼χdfD​+dfC​2​

"검출률 또는 검출된 cell의 평균 중 하나라도 다른가?"를 묻는다. BH-FDR로 보정. 원 논문 기준 FDR < 0.01, fold change > 1.5.

결과 패턴 해석
pDp_DpD​만 유의 검출률(on/off) 차이가 주도
pCp_CpC​만 유의 검출된 cell 안에서 발현량 차이
둘 다 둘 다 기여하는 강한 DEG

logFC

모델이 예측한 그룹 평균 = 검출 확률 × 조건부 평균:

μgroup=P(Z=1∣group)×E[Y∣Z=1,group],logFC=log⁡2μtreatmentμcontrol\mu_\text{group} = P(Z = 1 \mid \text{group}) \times E[Y \mid Z = 1, \text{group}], \qquad \text{logFC} = \log_2\frac{\mu_\text{treatment}}{\mu_\text{control}} μgroup​=P(Z=1∣group)×E[Y∣Z=1,group],logFC=log2​μcontrol​μtreatment​​

Random effect를 넣을 때

  • zlm(..., method = "glmer")로 (1 | sample) 같은 random effect를 넣을 수 있다. Random effect가 있으면 반드시 method = "glmer"를 지정해야 한다.
  • 이때 Bayesian 경로(bayesglm, ebayes = TRUE)는 함께 쓸 수 없어 ebayes = FALSE로 둔다.
  • 흔한 에러와 원인
    • Fixed-effect model matrix is rank deficient: condition과 batch(또는 sex 등)가 완전히 겹쳐 모델이 변수를 버림 → 결과가 batch 효과에 오염됨
    • Grouping factors must have > 1 sampled level: 어떤 gene이 sample 하나에서만 검출 → 그 gene은 NA
    • Number of levels ≥ number of observations: cell보다 sample이 많은 희귀 cell type
  • Sample 구조가 강하면 Pseudobulk Analysis를 주 분석으로 하고 MAST를 보조로 쓰는 것이 안전하다.

MAST의 gene set 검정 (gseaAfterBoot)

  1. bootVcov1(zlmFit, R = ...): cell을 복원 추출해 모델을 다시 적합 → gene 간 상관을 반영한 계수 공분산 추정 (논문급 분석이면 R ≥ 50 권장)
  2. Gene set을 index로 매칭 (limma::ids2indices)
  3. gseaAfterBoot(zlmFit, boots, sets, CoefficientHypothesis("...")): gene set 안 평균 계수가 밖(background)과 다른지 검정
  4. summary(gsea, testType = "normal"): disc_Z, cont_Z, Stouffer로 합친 combined_P

일반 GSEA(fgsea 등)는 DE 결과(랭킹)를 쓰지만, MAST GSEA는 모델 계수와 공변량 보정을 그대로 쓰고 bootstrap으로 gene 상관을 보정한다. 대신 계산이 오래 걸리고, bootstrap에서 특정 batch cell이 하나도 안 뽑히면 모델이 깨질 수 있다.
