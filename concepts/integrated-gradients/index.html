Integrated Gradients (IG)

학습된 신경망의 예측을 입력 feature들의 기여도(attribution)로 나누는 방법. Baseline에서 실제 입력까지 가는 경로 전체에서 gradient를 적분해 saturation 문제를 피한다.

#deep-learning#explainability#attribution

쉽게 말하면

산 정상에 서서 발밑 경사만 보면 평평해서 "안 올라왔네?"라고 착각합니다. 출발점부터 걸어온 길 전체의 오르막을 더해야 "이만큼 올라왔구나"를 알 수 있습니다. IG는 출발점(baseline)부터 입력까지 걸으며 기울기를 누적합니다.

자세히

풀려는 문제: attribution

모델이 어떤 입력에 "0.9"라고 예측했을 때 **"입력의 어떤 부분이 그 0.9를 만들었나?"**를 묻는 것이 attribution입니다. 픽셀, gene, SNP마다 점수를 매깁니다.

단순 gradient가 실패하는 이유: saturation

가장 순진한 방법은 미분(gradient)입니다. "이 feature를 살짝 흔들면 출력이 얼마나 흔들리나?"

  • 어떤 뉴런이 x>1x > 1x>1이면 출력이 1에서 더 오르지 않고 납작해진다고 하자 (ReLU, sigmoid 뒤에서 흔함).
  • Baseline x=0x = 0x=0 → 출력 0, 실제 입력 x=3x = 3x=3 → 출력 1
  • 상식적으로 이 feature는 출력 1을 전부 만들었다.
  • 그런데 x=3x = 3x=3 지점의 기울기는 0이다. 단순 gradient는 "기여 0"이라는 틀린 답을 낸다.

해결: 경로를 따라 적분

IGi(x)=(xi−xi′)⏟얼마나 멀리 걸어갔나×∫01∂F∂xi∣x′+α(x−x′) dα⏟경로 위 기울기의 평균IG_i(x) = \underbrace{(x_i - x'_i)}_{\text{얼마나 멀리 걸어갔나}} \times \underbrace{\int_0^1 \frac{\partial F}{\partial x_i}\Big|_{x' + \alpha(x - x')}\, d\alpha}_{\text{경로 위 기울기의 평균}} IGi​(x)=얼마나 멀리 걸어갔나(xi​−xi′​)​​×경로 위 기울기의 평균∫01​∂xi​∂F​​x′+α(x−x′)​dα​​

  • x′x'x′: baseline(출발점), xxx: 실제 입력(도착점)
  • α\alphaα: 0 → 1로 가는 진행도. α=0\alpha = 0α=0이면 baseline, 1이면 실제 입력
  • 위 예에서 0 → 1 구간은 가파르고(기여 발생), 1 → 3 구간은 평평하다(기여 없음). 경로 전체를 훑으면 올바르게 "거의 전부 기여"가 나온다.
  • 실제 계산은 경로를 50~300개 점으로 쪼개 기울기를 더하는 Riemann 합으로 근사한다.

Baseline 고르기가 가장 중요

Attribution은 결국 "baseline 대비 얼마나 달라졌나"의 분해입니다. Baseline은 "아무 정보도 없는 중립 상태"를 뜻해야 합니다.

  • 이미지: 보통 검은 화면(all-zero)
  • 서열·유전체 모델: all-zero one-hot은 생물학적으로 무의미 → dinucleotide-shuffled 서열이나 여러 random baseline의 평균을 쓰는 것이 관례
  • Single-cell: 비교 기준이 될 "배경 cell"을 baseline으로 쓰기도 한다 (아래 SCimilarity)

해석할 때

  • 학습이 끝난 모델에 적용하는 post-hoc explainability 분석입니다.
  • 상위 feature가 알려진 생물학(marker gene 등)과 맞으면 모델이 의미 있는 신호를 학습했다는 근거가 됩니다.

논문별 활용

  • 2025 Heimberg - SCimilarity (Fig 4f): IG를 single-cell 검색 모델에 맞게 변형해 gene별 attribution score를 계산했다.
    • Baseline = 배경 cell yyy (무작위 macrophage), 도착점 = 관심 cell xxx (fibrosis-associated macrophage, FM)
    • 분류 label이 아니라 학습된 embedding 거리를 기준으로 미분
    • 적분값의 절댓값에 (xi−yi)(x_i - y_i)(xi​−yi​)를 곱하고, xi<yix_i < y_ixi​<yi​인 gene은 0으로 처리 → 관심 cell에서 올라간 gene만 점수화
    • 관심 cell 500개 × 배경 cell 500개 쌍에 대해 평균
    • 결과: query에 쓴 gene 6개(SPP1, TREM2, GPNMB, MMP9, CHIT1, CHI3L1) 외에 APOE, LPL, MARCO, MSR1, MMP7, FN1과 새 marker(HLA-DQA1, RGS1)까지 상위에 나와, 모델이 query를 외운 것이 아니라 fibrosis 상태 전반을 학습했다는 근거로 제시
