Differential Abundance Analysis

조건 사이에서 cell type(또는 cell state)의 비율이 달라졌는지 검정하는 분석. 비율 데이터의 compositional 성질과 sample 구조를 함께 고려해야 한다.

#single-cell#cell-proportion#compositional#statistics

쉽게 말하면

"환자에서 CD14 monocyte 비율이 늘었나?" 같은 질문입니다. 조심할 점은 비율의 합이 1이라는 것입니다. 한 cell type이 크게 줄면 나머지는 실제로 변하지 않아도 비율이 올라가 보입니다.

자세히

왜 단순 비교가 위험한가: compositionality

  • Sample당 총 cell 수가 정해져 있어 cell type count는 비율 데이터다.
  • 한 cell type만 줄어도 나머지 비율이 상대적으로 오른다 → cell type 사이에 **음의 상관(negative bias)**이 생긴다.
  • 각 cell type을 독립적으로 검정하는 일반 univariate 방법은 이런 가짜 변화를 진짜 효과로 잡을 수 있다.

방법

방법 원리 장점 한계
Wilcoxon / t-test on proportions sample별 비율을 그룹 간 비교 단순, sample 수가 적을 때 현실적 compositionality 무시
GLMM / brms binomial·beta·Dirichlet-multinomial mixed model 공변량, random effect sample이 적으면 수렴 어려움 → Beta Regression
scCODA Bayesian Dirichlet-multinomial. reference cell type 대비 log 비율을 공변량으로 모델링 모든 cell type을 한 번에, compositionality 고려, reference 자동 선택 annotation이 미리 필요, paired/반복측정 설계는 잘 안 맞음
Milo KNN graph의 neighborhood 단위로 cell 수를 세 NB-GLM으로 검정 cluster 경계 없이 연속 상태에서 변화 탐지 batch 보정이 덜 되거나 control이 특정 batch에 쏠리면 적용 어려움

scCODA 모델 요약

log⁡cell type k의 비율reference cell type의 비율=αk+Xβk\log\frac{\text{cell type } k \text{의 비율}}{\text{reference cell type의 비율}} = \alpha_k + X\beta_k logreference cell type의 비율cell type k의 비율​=αk​+Xβk​

Cell type마다 βk\beta_kβk​가 있고, 공변량(case/control 등)에 따라 비율이 변하는지 Bayesian으로 판단한다(FDR 기준). 변하지 않을 것 같은 cell type을 reference로 둔다.

Milo 단계

  1. KNN graph 생성
  2. Neighborhood 대표 cell 샘플링 (전체가 아닌 일부를 index로)
  3. Neighborhood × sample별 cell 수 count
  4. Negative binomial GLM으로 조건 간 차이 검정 (공변량 가능)
  5. 겹치는 neighborhood를 고려한 spatial FDR 보정
  6. 비슷한 neighborhood를 묶고, 그 안에서 DE

분석할 cell type 고르기 (실무 기준)

  1. Detection: sample의 30–50% 이상에서 관측
  2. Abundance: 평균 비율 ≥ 0.5–1% (또는 median > 0.1%)
  3. Count 안정성: sample당 20–30 cell 이상
  4. 드물지만 면역학적으로 중요한 population은 별도 보조 분석

설계별 질문 예

  • Case vs control (baseline만)
  • 시간 효과 (같은 그룹 안에서 전후)
  • 약물 반응 (responder vs non-responder)
  • 시점별 약물 효과

Sample이 적으면 GLMM이 잘 안 돌아가므로, sample 단위 비율에 Wilcoxon을 쓰고 해석을 보수적으로 하는 것이 현실적일 수 있다.

Reference-relative interpretation

2021 Büttner - scCODA의 coefficient는 reference cell type에 대한 상대적 변화이다. Reference가 실제로 안정적인지 sensitivity analysis가 필요하며, absolute cell number 변화가 복원되는 것은 아니다. Posterior expected FDR은 BH-adjusted p-value와 다른 절차이고, 원래 모델에는 donor random effect가 없다. 반복 samples·paired design과 더 많은 independent donors를 더 많은 cells와 구분한다. Reference selection 참고.
