AI Drug Discovery 17

Compound LibraryScreening 대상이 되는 compound 모음. 실제로 구매하거나 합성할 수 있는 molecule의 structure 목록이다.Connectivity Map (CMap)여러 compound를 cell에 처리하고 gene expression 변화를 측정해 모아 둔 database이자, signature로 compound를 query하는 방법.Disease SignatureDisease 상태에서 control 대비 up-regulated gene과 down-regulated gene의 목록. Disease를 gene expression으로 요약한 "지문"이다.Drug Repurposing이미 approved되었거나 개발된 drug을 원래와 다른 indication에 다시 쓰는 것. Drug repositioning이라고도 한다.ECFPExtended-Connectivity Fingerprint. 각 원자를 중심으로 주변 결합 구조를 단계적으로 확장해, 분자에 어떤 국소 구조가 있는지 수치로 나타내는 circular fingerprint다. Molecular Fingerprint의 한 종류다.Hit-to-Lead OptimizationScreening에서 찾은 hit의 structure를 조금씩 바꿔, potency, selectivity, drug-like property가 더 좋은 lead로 만드는 과정.IC50Compound가 어떤 활성(cell viability, enzyme activity 등)을 50% 억제하는 농도. 값이 낮을수록 강한(potent) compound다.LINCS L1000수만 개의 compound와 genetic perturbation을 여러 cell line에 처리하고 gene expression 변화를 측정한 대규모 perturbation transcriptomics database. Connectivity Map의 확장판이다.Mechanism of Action (MoA)Drug이 어떤 분자(target)에 작용해, 어떤 경로를 거쳐 효과를 내는지에 대한 설명.Molecular FingerprintMolecule의 structure를 0과 1로 이루어진 고정 길이 vector로 바꾼 표현. Computer가 molecule을 비교하고 학습할 수 있게 해 준다.Monte Carlo Tree Search (MCTS)가능한 선택지를 tree로 펼쳐 놓고, 유망한 가지는 더 깊이, 덜 시도한 가지도 가끔 탐색하면서 좋은 해를 찾는 search algorithm.Precision-Cut Lung Slices (PCLS)Lung tissue를 얇게 잘라 몸 밖에서 며칠간 배양하는 ex vivo model. 원래 tissue의 구조와 여러 cell type의 구성을 유지한 채 compound를 시험할 수 있다.RGES (Reverse Gene Expression Score)Compound의 drug signature가 Disease Signature를 얼마나 reverse하는지 나타내는 점수. 더 negative할수록 disease를 잘 reverse한다.Signature ReversalDisease에서 up된 gene은 down시키고, down된 gene은 up시키는 compound를 찾으면 그 compound가 disease를 치료할 수 있다는 drug discovery 전략.Target-based vs Phenotypic ScreeningDrug discovery의 두 가지 큰 전략. 특정 target을 먼저 정하고 그 target에 작용하는 compound를 찾느냐(target-based), 원하는 phenotype 변화를 일으키는 compound를 먼저 찾느냐(phenotypic).Virtual Screening큰 Compound Library에서 실험할 가치가 있는 compound를 computer로 골라내는 과정.Xenograft Model사람의 cancer cell이나 tumor tissue를 면역이 결핍된 mouse에 이식해 키운 in vivo model. Anti-cancer compound의 효과를 동물에서 확인할 때 가장 흔히 쓴다.

Immunology 9

AbataceptCTLA-4의 세포외 도메인과 IgG1 Fc를 융합한 단백질(CTLA4-Ig, 상품명 Orencia). 항원제시세포의 CD80/CD86을 막아 T cell의 공동자극(signal 2)을 차단함으로써 RA의 자가면역 반응을 억제한다.B Cell and BCRB cell은 항체를 만드는 lymphocyte이고, BCR(B cell receptor)은 그 항체(immunoglobulin, Ig)의 막 결합형이다. V(D)J 조각을 무작위로 조합해 엄청난 다양성을 만들고, 항원을 만난 뒤 Somatic Hypermutation과 Class Switch Recombination으로 진화한다.Class Switch Recombination (CSR)B cell이 항원 특이성(V(D)J)은 그대로 두고 heavy chain의 constant region만 바꿔 항체 isotype(IgM → IgG, IgA, IgE)을 바꾸는 DNA 재조합.Clonotype and CDRClonotype은 같은 조상 세포에서 나와 같은 V(D)J 재조합(특히 같은 CDR3 서열)을 공유하는 B cell 또는 T cell의 집합이다. CDR(complementarity determining region)은 항원과 직접 맞닿는 receptor의 고리 부위이고, 그중 CDR3가 가장 다양하다.HLA RestrictionT cell(TCR)은 항원 조각을 HLA(MHC) 분자에 실린 형태로만 인식한다. 사람마다 HLA가 매우 다르기 때문에, 같은 병원체에 반응하는 TCR도 사람마다 서열이 달라진다.PBMC (Peripheral Blood Mononuclear Cells)혈액에서 밀도구배 원심분리(Ficoll 등)로 분리한 핵이 하나인 둥근 세포들. Lymphocyte(T, B, NK)와 monocyte로 이루어진다. 혈액 scRNA-seq 연구의 가장 흔한 시료다.Rheumatoid Arthritis (RA)관절의 활막(synovium)에 만성 염증이 생겨 연골과 뼈가 파괴되는 전신성 자가면역 질환. 자가항체(RF, ACPA)와 T cell–B cell–myeloid cell의 상호작용이 병리의 중심이다.Somatic Hypermutation (SHM)항원을 만난 B cell이 germinal center에서 BCR의 variable region(V 유전자)에 의도적으로 돌연변이를 쌓아, 항원을 더 강하게 잡는 클론을 고르는 과정. 그 결과가 affinity maturation이다.T Cell and TCRT cell은 TCR(T cell receptor)로 MHC(HLA)에 제시된 항원 조각을 인식하는 lymphocyte다. CD4⁺ T cell은 cytokine으로 면역을 조절하고, CD8⁺ T cell은 감염·암세포를 직접 죽인다. TCR은 BCR과 달리 SHM이 없다.

Single-cell Analysis 28

Batch Correction실험 날짜, 시퀀싱 회사, sample 처리 방식처럼 생물학과 무관한 기술적 요인(batch)이 만든 발현 차이를 제거해, 여러 sample을 함께 분석할 수 있게 하는 단계.Cell Quality Control각 droplet이 "온전한 cell 하나"라는 가정을 깨는 것들, 즉 죽어가는 cell, 배경 RNA, doublet을 걸러 내는 단계.Cell Type AnnotationCluster나 개별 cell에 cell type 이름을 붙이는 단계. 자동 분류 도구로 초벌을 하고, marker gene으로 사람이 확인·수정하는 방식이 일반적이다.Cell-Cell Communication (CCC)Ligand(보내는 cell)와 receptor(받는 cell)의 발현으로 어떤 cell type이 어떤 신호로 서로 대화하는지 추론하는 분석.CellBender빈 droplet에 떠다니는 ambient RNA(배경 RNA)를 확률 모델로 추정해, 각 cell의 count에서 빼 주는 도구 (cellbender remove-background).CellChatLigand–receptor 발현을 mass action 법칙 기반 확률 모델로 바꿔 cell group 사이의 통신 확률을 계산하고, permutation으로 유의성을 판단한 뒤 signaling pathway 단위로 해석하는 CCC 도구 (R).cNMF (Consensus Non-negative Matrix Factorization)발현 행렬을 gene program(GEP)과 cell별 program usage로 분해하는 방법 (Kotliar et al., eLife 2019). NMF를 여러 번 돌려 반복해서 나타나는(consensus) program만 남긴다.Co-expression Network AnalysisCell(또는 metacell)들에 걸쳐 함께 오르내리는 gene들을 module로 묶는 분석. Module은 공통 기능이나 조절을 공유하는 gene program 후보다.Cytokine and Pathway ActivityCell이나 sample의 발현 패턴에서 어떤 cytokine 신호, signaling pathway, transcription factor가 현재 활성화되어 있는지 추정하는 분석. 대부분 bulk용으로 개발되어 single-cell로 확장되었다.Differential Abundance Analysis조건 사이에서 cell type(또는 cell state)의 비율이 달라졌는지 검정하는 분석. 비율 데이터의 compositional 성질과 sample 구조를 함께 고려해야 한다.Differential Expression (DE)두 조건(질병 vs 정상, 치료 전 vs 후 등) 사이에서 발현이 유의하게 다른 gene(DEG)을 찾는 분석. Single-cell에서는 cell 단위로 할지, sample 단위로 모아서 할지가 가장 큰 선택이다.Gene Regulatory NetworkTranscription factor와 target gene 사이의 regulatory relationship을 표현하는 network이다. 추정 edge와 실험으로 확인된 regulation은 구분한다. (일반 지식)Gene Set Enrichment AnalysisDE 결과를 gene 하나하나가 아니라 pathway, gene set 단위로 요약하는 분석. 유의 gene 목록이 특정 set에 몰렸는지(ORA), 전체 순위에서 set이 한쪽 끝에 몰렸는지(GSEA)를 본다.Gene Set ScoringGene set(signature, pathway)이 각 cell(또는 sample)에서 얼마나 활성화됐는지 점수를 매기는 방법. DE 없이도 pathway 활성을 cell 단위로 비교·시각화할 수 있다.KNN Graph각 cell을 발현 패턴이 가장 비슷한 $k$개의 이웃 cell과 연결한 graph. Single-cell 분석에서 clustering(Leiden), 시각화(UMAP), trajectory(PAGA)의 공통 뼈대다.Leiden ClusteringKNN Graph 위에서 modularity(또는 CPM)를 최대화하도록 cell을 community로 나누는 알고리즘. Seurat, Scanpy의 표준 clustering이다.MASTSingle-cell DE 도구. 각 gene의 발현을 "검출됐나(discrete)"와 "검출됐다면 얼마나(continuous)" 두 부분으로 나눠 따로 회귀하는 hurdle model을 쓴다 (Finak et al., Genome Biology 2015).Pseudobulk AnalysisCell type마다 sample(donor) 단위로 cell의 count를 합쳐 bulk RNA-seq처럼 만든 뒤, edgeR, DESeq2, limma-voom 같은 bulk 도구로 분석하는 방법. 통계 단위를 cell이 아니라 sample로 맞춘다.Reference Mapping새 query cells를 이미 정의한 reference representation 또는 label 체계에 연결하는 분석이다. (일반 지식)RNA-seq NormalizationSequencing depth, transcript 길이, sample 구성, batch 같은 기술적 차이를 보정해 gene 발현을 비교 가능하게 만드는 과정. 비교하려는 대상(같은 sample 안 / sample 사이 / dataset 사이)에 따라 방법이 다르다.SCENICSingle-cell 데이터에서 어떤 transcription factor(TF)가 활성화되어 어떤 target gene들을 조절하는지 찾는 GRN 추론 도구. Co-expression에 DNA motif 근거를 더해 regulon(TF + target set)을 만들고, cell마다 regulon 활성 점수를 준다.scRNA-seq WorkflowRaw sequencing data에서 cell type별 해석까지 가는 scRNA-seq 분석의 표준 단계 지도. 각 단계는 별도 개념 페이지로 연결된다.scVI (single-cell Variational Inference)Raw count를 ZINB(zero-inflated negative binomial) 분포에서 생성된 것으로 보고, 신경망(VAE)으로 batch와 생물학적 신호를 분리하는 확률 모델 (Lopez et al., 2018). Batch correction된 latent embedding과 보정된 expression을 함께 준다.Single-cell RNA-seqTissue를 cell 단위로 분리해 cell 하나하나의 gene expression을 측정하는 sequencing 기술.Spatial TranscriptomicsTissue 안의 위치 정보와 RNA expression을 연결하는 측정·분석 방법이다. (일반 지식)Splicing Quantitative Trait LocusGenotype와 RNA splicing variation의 연관을 나타내는 locus이다. Gene expression 양과의 연관인 eQTL과 같은 결과가 아니다. (일반 지식)Time-series Expression Patterns여러 시점에서 측정한 발현을 gene별로 시간에 따른 변화 모양으로 묶어, 약물 반응이나 질병 진행의 타이밍을 이해하는 분석.Trajectory AnalysisCell들을 발현의 연속적인 변화를 따라 늘어세워 상태 전이의 경로(trajectory)와 각 cell의 진행 정도(pseudotime)를 추정하는 분석.

Statistics & ML 19

Adjusted Rand Index (ARI)Clustering 결과가 정답 label과 얼마나 일치하는지 재는 지표. 우연히 일치하는 정도를 빼서 보정한 것이 핵심이다. 1이면 완벽, 0이면 무작위 수준.Attention정보를 모을 때 어떤 입력이 지금 나에게 중요한지 점수(attention score)를 매겨 가중 평균하는 메커니즘. 가중치가 고정이 아니라 데이터 내용에 따라 그때그때 계산된다.Beta Regression0과 1 사이의 비율 데이터를 위한 회귀. Logit link로 평균을 모델링하고, random effect를 더하면 Beta GLMM이 된다.Colocalization두 trait의 같은 genomic region에서 관찰한 association이 shared causal signal과 양립하는지 평가하는 분석이다. (일반 지식)Confusion Matrix분류 모델(또는 진단 검사)의 예측과 실제 정답을 2×2 표로 정리한 것. Sensitivity, specificity, precision 같은 평가 지표가 모두 여기서 나온다.Cross-validationData를 여러 training/evaluation partition으로 나눠, 학습에 직접 사용하지 않은 data에 대한 prediction을 평가하는 절차.Graph Convolutional Network (GCN)Graph 위에서 동작하는 신경망. 각 node가 이웃 node의 정보를 모아 자기 feature를 업데이트하는 층(layer)을 쌓는다.Information EntropyProbability distribution이 얼마나 여러 가능성에 퍼져 있는지 요약하는 값이다. Prediction의 calibration을 보장하는 지표는 아니다. (일반 지식)Integrated Gradients (IG)학습된 신경망의 예측을 입력 feature들의 기여도(attribution)로 나누는 방법. Baseline에서 실제 입력까지 가는 경로 전체에서 gradient를 적분해 saturation 문제를 피한다.Logistic Regression이항 반응(0/1)의 확률을 log-odds의 선형식으로 모델링하는 회귀. 계수 $\beta$는 "log-odds 변화량", $e^{\beta}$는 "odds ratio(OR)"로 해석한다.Metric Learning관측값 사이의 거리 자체가 목적에 맞도록 representation을 학습하는 방법이다. (일반 지식)Mixed Effects Model관심 있는 효과(fixed effect)와 환자·배치처럼 데이터를 묶는 구조(random effect)를 함께 모델링하는 회귀. 반복측정이나 계층 구조 데이터에서 p-value가 부풀려지는 것을 막는다.ModularityNetwork를 그룹으로 나눴을 때, 그룹 안의 연결이 무작위로 기대되는 것보다 얼마나 더 빽빽한가를 재는 점수 $Q$. Leiden과 Louvain 알고리즘이 최대화하는 목표 함수다.Multi-omics Integration서로 다른 biological measurement를 연결해 하나의 phenotype이나 system을 분석하는 방법.Multi-task Learning여러 prediction task를 함께 학습하면서 일부 representation을 공유하는 방법.Network Propagation출발점 node(관심 gene)의 신호를 network의 edge를 따라 퍼뜨려, 출발점과 기능적으로 가장 가까운 node를 점수로 찾는 방법. 대표적으로 random walk with restart(RWR)를 쓴다.PCA (Principal Component Analysis)많은 변수를, 데이터의 분산을 가장 많이 설명하는 소수의 새 축(principal component, PC)으로 요약하는 차원 축소 방법.Regression OverviewResponse variable의 종류(연속, 이항, count, 비율)와 데이터 구조(독립, 반복측정)에 따라 고르는 회귀 모델들의 지도.SHAP (Shapley Additive Explanations)모델의 예측 하나를 각 feature의 기여도(SHAP value)로 나누어 설명하는 방법. 게임 이론의 Shapley value에 기반한다.
