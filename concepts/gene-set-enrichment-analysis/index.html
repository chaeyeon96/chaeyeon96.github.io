Gene Set Enrichment Analysis

DE 결과를 gene 하나하나가 아니라 pathway, gene set 단위로 요약하는 분석. 유의 gene 목록이 특정 set에 몰렸는지(ORA), 전체 순위에서 set이 한쪽 끝에 몰렸는지(GSEA)를 본다.

#single-cell#pathway#enrichment#functional-analysis

쉽게 말하면

DEG가 300개 나왔을 때 "그래서 무슨 일이 일어난 건데?"에 답하는 단계입니다. "interferon 반응 gene들이 전반적으로 올라갔다" 같은 문장으로 바꿔 줍니다.

  • Self-contained test: "이 set 안 gene들의 효과가 0과 다른가?"

Single-cell 정석 workflow

Pseudobulk DE → preranked GSEA (+ camera)

  1. Cell type별로 sample 단위 count 합치기 → Pseudobulk Analysis
  2. edgeR / DESeq2 / limma-voom DE (공변량 포함)
  3. DE 통계량으로 랭킹 → fgsea. 랭킹 예: t 또는 sign(logFC) × |t|
  4. 보강: camera 또는 ORA

그룹당 sample이 5명 이상이면 체감이 좋다.

상황별 선택

  • Cell type별 case vs control: pseudobulk → fgsea/camera. Sample 구분이 불가능하면 cluster 수준 DE 통계량 → fgsea, 해석은 보수적으로.
  • Responder vs non-responder의 시간 변화: pseudobulk 선형모델에서 group × time interaction 계수의 통계량으로 GSEA. 시각화는 gene set score를 시간축에 그리고 mixed model로 검정.
  • Trajectory, pseudotime을 따라: DE 기반 GSEA보다 score 기반(AUCell, UCell, GSVA)이 직관적. 점수를 pseudotime에 회귀·smoothing.
  • MAST를 주로 쓸 때: MAST DEG → fgsea/clusterProfiler, 그 pathway를 UCell/AUCell로 cell 단위 확인, ORA는 요약용.

자주 터지는 함정

  1. Gene universe: ORA의 background는 "검정 가능했던 gene 전체", single-cell에서는 그 cell type에서 충분히 발현·검정된 gene으로.
  2. MT, ribosomal, hemoglobin gene이 결과를 지배: 랭킹에서 빼거나 해석에서 분리.
  3. Gene ID 매핑: SYMBOL vs ENSEMBL 혼용, alias, 대소문자. 매칭이 빠지면 검정력이 급감한다.
  4. Cell 수와 sample 불균형: cell 수준 DE의 작은 p-value가 그대로 GSEA를 부풀린다.

결과에서 볼 것

  • NES: 방향과 크기 (normalized enrichment score)
  • FDR (q-value)
  • Leading-edge genes: 실제로 그 pathway를 끌고 간 핵심 gene. 특정 cell state의 marker인지 확인한다.
