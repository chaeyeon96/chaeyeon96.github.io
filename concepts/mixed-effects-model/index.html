Mixed Effects Model

관심 있는 효과(fixed effect)와 환자·배치처럼 데이터를 묶는 구조(random effect)를 함께 모델링하는 회귀. 반복측정이나 계층 구조 데이터에서 p-value가 부풀려지는 것을 막는다.

#statistics#regression#mixed-model#pseudoreplication

쉽게 말하면

환자 10명에게서 cell 10,000개를 측정했다면, 진짜 독립 샘플 수는 10,000이 아니라 10입니다. 같은 환자에서 나온 cell은 서로 닮았기 때문입니다. Mixed model은 "같은 환자에서 나온 것끼리는 원래 비슷하다"는 사실을 random effect로 인정해 줍니다.

자세히

기본식

환자 iii, 측정(시점이나 cell) ttt에 대해:

Yit=βXit+αi+ϵitY_{it} = \beta X_{it} + \alpha_i + \epsilon_{it} Yit​=βXit​+αi​+ϵit​

  • αi\alpha_iαi​: 환자 iii의 고유한 baseline
  • ϵit\epsilon_{it}ϵit​: 순수한 측정 오차

αi\alpha_iαi​를 어떻게 다루느냐에 따라 fixed와 random이 갈립니다.

Fixed effects: 환자 특성을 완전히 제거

αi\alpha_iαi​를 모르는 상수로 보고, 환자별 평균을 빼서(demeaning) 없앱니다.

(Yit−Yˉi)=β(Xit−Xˉi)+(ϵit−ϵˉi)(Y_{it} - \bar{Y}_i) = \beta (X_{it} - \bar{X}_i) + (\epsilon_{it} - \bar{\epsilon}_i) (Yit​−Yˉi​)=β(Xit​−Xˉi​)+(ϵit​−ϵˉi​)

  • αi\alpha_iαi​가 완전히 소거되므로 αi\alpha_iαi​가 XXX와 상관이 있어도 β\betaβ는 편향되지 않습니다.
  • 대신 성별처럼 환자 안에서 변하지 않는 변수는 분석에서 사라집니다.
  • 예: 환자 A의 약 복용 전 10, 후 12 → 평균 11을 빼면 (−1, +1). 모델은 환자 안의 +2 변화만 봅니다.

Random effects: 환자 특성을 확률 변수로

αi\alpha_iαi​를 평균 0인 확률 변수로 보고 오차의 일부로 넣습니다. 같은 환자의 측정끼리는 같은 αi\alpha_iαi​를 공유하므로 서로 상관이 생기고, 이를 GLS로 처리합니다. 효과적으로는 평균을 λ\lambdaλ만큼만 뺍니다(partial demeaning).

(Yit−λYˉi)=β(Xit−λXˉi)+⋯ ,λ=1−σϵ2σϵ2+Tσα2(Y_{it} - \lambda\bar{Y}_i) = \beta (X_{it} - \lambda\bar{X}_i) + \cdots, \qquad \lambda = 1 - \sqrt{\frac{\sigma^2_\epsilon}{\sigma^2_\epsilon + T\sigma^2_\alpha}} (Yit​−λYˉi​)=β(Xit​−λXˉi​)+⋯,λ=1−σϵ2​+Tσα2​σϵ2​​​

  • 환자 간 변동 σα2\sigma^2_\alphaσα2​가 매우 크면 λ→1\lambda \to 1λ→1 → fixed effects와 같아짐
  • σα2=0\sigma^2_\alpha = 0σα2​=0이면 λ=0\lambda = 0λ=0 → 일반 OLS와 같아짐
  • 행렬로는 β^RE=(X⊤Ω−1X)−1X⊤Ω−1Y\hat\beta_{RE} = (X^\top\Omega^{-1}X)^{-1}X^\top\Omega^{-1}Yβ^​RE​=(X⊤Ω−1X)−1X⊤Ω−1Y. Ω\OmegaΩ는 오차 구조 전체를 담은 행렬이고, 분산 성분을 먼저 추정해 Ω\OmegaΩ를 만든 뒤 한 번에 β\betaβ를 구합니다.

Mixed model = 둘을 섞은 것

실제로는 관심 변수(조건, 시간, 약물)는 fixed, 환자·배치·회사는 random으로 넣습니다.

# R lme4
lmer(Y ~ Condition + Time + (1 | Sample) + (1 | Batch), data = df)

scRNA-seq에서 왜 필요한가: pseudoreplication

  • Batch correction은 gene expression 패턴(또는 cNMF program 정의)을 깨끗하게 만들기 위한 것이지, **같은 sample 안 cell끼리 닮는 성향(intra-class correlation)**까지 없애 주지는 않습니다.
  • 그래서 cell 단위로 t-test나 일반 회귀를 하면 N이 cell 수로 부풀려져 p-value가 비정상적으로 작게 나옵니다.
  • 정리: 입력 보정은 "프로그램이나 발현 패턴을 깨끗하게 뽑기 위해", mixed model은 "통계적 유의성을 부풀리지 않기 위해" 하는 것이고, 둘 다 필요합니다. 입력에서 batch를 보정했더라도 통계 모델에서 random effect로 한 번 더 잡는 것이 보수적이고 안전합니다.

더 쉬운 대안: Pseudobulk

Sample별로 cell 값을 평균(또는 합)해서 sample 단위 데이터로 만든 뒤 t-test, ANOVA, 일반 LMM을 돌립니다. N이 자연스럽게 sample 수가 되어 pseudoreplication이 원천적으로 해결되고, 리뷰어도 쉽게 납득합니다. → Pseudobulk Analysis

왜 중요한가

  • 종단(longitudinal) 연구, 반복측정, 다중 배치 single-cell 데이터의 표준 모델입니다.
  • 비율 데이터면 Beta GLMM, count면 negative binomial GLMM(예: NEBULA)으로 확장합니다.

Variance decomposition in longitudinal data

2023 Vasaikar - PALMO는 longitudinal multi-omics에서 donor 및 time 관련 variation을 구분한다. Variance component의 크기는 fixed-effect coefficient나 explained causal contribution과 같은 값이 아니다. 분석별 biological replicate와 random-effect 구조를 2023 Vasaikar - PALMO (Pipeline)에서 확인한다.

BioMapAI use

  • BioMapAI confounder analysis는 MaAsLin2 model에 participant baseline ID의 random intercept를 포함했다.
  • BioMapAI validation caveat: Confounder model에 random effect를 넣는 것과 prediction 평가에서 participant를 train/test 사이에 분리하는 것은 별개의 절차다 (일반 지식).
