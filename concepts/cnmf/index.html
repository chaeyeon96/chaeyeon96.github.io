cNMF (Consensus Non-negative Matrix Factorization)

발현 행렬을 gene program(GEP)과 cell별 program usage로 분해하는 방법 (Kotliar et al., eLife 2019). NMF를 여러 번 돌려 반복해서 나타나는(consensus) program만 남긴다.

#single-cell#gene-program#matrix-factorization#tool

쉽게 말하면

Clustering은 cell 하나에 이름표 하나를 붙입니다. cNMF는 "이 cell은 **세포 주기 program 30% + 염증 program 70%**를 쓰고 있다"처럼, 한 cell이 여러 생물학적 과정을 동시에 돌리는 것을 분리해 냅니다. Cell type을 정하는 identity program과 상태를 나타내는 activity program을 함께 찾습니다.

이 그림은 저작권 때문에 싣지 않았습니다 V(cell × gene) ≈ W(cell × program usage) × H(program × gene)

이 그림은 저작권 때문에 싣지 않았습니다 Kotliar et al., eLife 2019, Figure 1 (CC BY 4.0). a: identity program과 activity program, b: 반복 분해 → program clustering → consensus

자세히

단계

단계 함수 하는 일
1. Prepare prepare 저품질 cell(UMI < 1000 등)과 거의 안 쓰이는 gene 제거, HVG 약 2,000개 선택, 정규화
2. Factorize factorize NMF를 수백 번(예: 200) 다른 random 초기값으로 실행 (worker_i, total_workers로 병렬)
3. Combine combine 모든 실행 결과를 하나로 합침
4. K 선택 k_selection_plot program 수 KKK별 stability(재현성)와 error(재구성 오차)를 보고 고름
5. Consensus consensus 다른 실행과 동떨어진 component는 outlier로 제거(local density threshold), 나머지를 K-means로 묶고 median을 consensus program으로
6. Refit usage program을 고정하고 cell별 usage를 다시 계산 → cell마다 합이 1인 0–1 비율
7. TPM refit usage를 고정하고 전체 gene의 TPM에 회귀해 HVG가 아니던 gene의 program 기여도까지 얻음
8. Marker Z-score 회귀 계수로 program별 상위 gene → program 정체 해석

정규화가 다르다

  • 일반 scRNA-seq처럼 log 변환을 하지 않는다. NMF는 비음수 선형 결합을 가정하므로, gene별로 분산만 맞추고(평균은 빼지 않음) 원래 스케일을 유지한다.
  • 입력은 raw count가 기본. scVI의 transform_batch 보정값은 counterfactual decoding으로 만든 denoised 값이라 NMF 가정과 맞지 않을 수 있어 조심한다.
  • Batch는 cNMF 안의 Harmony 기반 보정 옵션을 쓰거나 입력을 보정한다. 보정하지 않으면 batch 특이 program이나 identity–donor hybrid program이 생긴다.
  • Cell이 아주 많으면 sample당 일정 수(예: 200 cell)로 down-sampling해 돌리는 경우가 많다.

Usage를 통계로 비교할 때

  • Usage는 0–1 비율이고 정확한 0이 많다 → Beta Regression (zero 처리 필수)
  • 같은 sample cell끼리 닮았으므로 sample random effect 또는 sample 평균(pseudobulk) → Mixed Effects Model, Pseudobulk Analysis
  • 원 논문은 Mann–Whitney U test와 usage > 10% 같은 threshold를 썼다.

Reference projection: starCAT / TCAT

  • starCAT은 cNMF처럼 새로 학습하지 않고, 미리 학습된 reference program에 데이터를 투영만 한다 (일반 지식 포함).
  • TCAT.V1: T cell 전용 reference (52 program × 3,412 gene).
    1. 입력: raw integer count (음수가 있으면 에러)
    2. Reference와 겹치는 gene만 사용
    3. Gene별로 전체 query cell에 걸친 표준편차로 나눔 (평균은 안 뺌). Cell 사이를 잇는 유일한 단계라, 어떤 cell 집합과 함께 돌리느냐에 따라 usage가 미세하게 달라진다.
    4. Reference spectra HHH를 고정하고 cell마다 독립적으로 NNLS로 usage WWW를 구함
    5. Cell마다 usage 합 = 1로 정규화
    6. 부가 점수: ASA(antigen-specific activation), Proliferation(cell cycle program 합), 이진 label, multinomial label
  • 장점: dataset 간 같은 program 정의로 비교 가능, 계산이 빠름. 한계: reference에 없는 program은 못 찾음.
