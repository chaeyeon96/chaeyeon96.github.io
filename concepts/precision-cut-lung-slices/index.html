Precision-Cut Lung Slices (PCLS)

Lung tissue를 얇게 잘라 몸 밖에서 며칠간 배양하는 ex vivo model. 원래 tissue의 구조와 여러 cell type의 구성을 유지한 채 compound를 시험할 수 있다.

#ex-vivo#tissue-model#fibrosis

쉽게 말하면

환자나 동물의 폐 조직을 햄 썰듯 얇게 잘라 접시에서 살려 두고, 거기에 약을 넣어 보는 실험입니다. Cell 하나만 키우는 실험보다 실제 폐에 가깝고, 사람에게 직접 쓰는 것보다 훨씬 쉽습니다.

자세히

만드는 방법 (일반 지식)

  1. Lung에 agarose를 채워 단단하게 만든다.
  2. Vibratome으로 수백 μm 두께로 일정하게 자른다.
  3. 배양액에서 며칠간 유지하며 compound를 처리한다.

재료

  • Human PCLS: 폐 이식이나 수술로 얻은 환자 lung. IPF 같은 disease tissue를 그대로 쓸 수 있다.
  • Mouse PCLS: 동물 model의 lung. 대량으로 빠르게 시험할 때.

측정

  • Fibrosis marker의 protein(western blot)이나 mRNA(qPCR) 변화
  • Bulk RNA-seq 후 deconvolution으로 cell type 비율 변화 추정

장단점 (일반 지식)

  • 장점: tissue 구조, ECM, 여러 cell type 간 상호작용이 유지된다. 환자 tissue로 사람 biology를 직접 본다.
  • 단점: 배양 기간이 짧다(보통 며칠). Blood flow, 면역 세포 유입, 전신 PK가 없다. 환자마다 편차가 크다.

왜 중요한가

  • Cell line 실험과 동물 실험 사이를 잇는 단계다.
  • 사람 disease tissue에서 직접 효과를 볼 수 있어, 동물 model이 사람 disease를 잘 재현하지 못하는 질환(예: IPF)에서 특히 유용하다.

논문별 활용

  • 2026 Xing - GPS: IPF drug 검증의 핵심 model이다.
    • Mouse PCLS로 repurposing 후보 20개를 1차 시험 → human PCLS로 진행
    • Pyrithyldione: 환자 8명의 PCLS에서 fibrosis marker(COL1A, FN1, SMA, CTHRC1) 감소, nintedanib과 비슷 (Figure 6C). PCLS bulk RNA-seq deconvolution으로 myofibroblast fraction 감소 확인 (Figure 6E)
    • Drug 18: 여러 환자 PCLS에서 10 μM로 FN1, SMA, CTHRC1 유의하게 감소 (Figure 6H)
    • Adjacent lung slice를 control로 써서 환자 간 편차를 줄였다.

관련 개념

  • Single-cell RNA-seq: PCLS bulk data를 deconvolution하는 reference
  • Xenograft Model: 또 다른 preclinical model (in vivo)
  • IC50: 단순 cell 실험 단계의 지표
