Graph Convolutional Network (GCN)

Graph 위에서 동작하는 신경망. 각 node가 이웃 node의 정보를 모아 자기 feature를 업데이트하는 층(layer)을 쌓는다.

#deep-learning#graph#gnn

쉽게 말하면

CNN이 이미지에서 주변 픽셀을 섞듯, GCN은 graph에서 연결된 이웃의 정보를 섞습니다. Single-cell에서는 KNN Graph의 이웃 cell들 정보를 모아 noise와 dropout이 많은 개별 cell 데이터를 매끄럽게 보정합니다.

자세히

Input: 두 개의 행렬

행렬 모양 내용
Feature matrix XXX cell 수 NNN × feature 수 FFF 각 cell의 발현값 또는 PC 좌표 ("각 마을 사람들의 특성")
Adjacency matrix AAA N×NN \times NN×N 누가 누구와 연결됐나. KNN graph의 connectivities ("마을 사이 도로망")

Layer 하나의 연산: Message passing

  1. Aggregate: edge로 연결된 이웃의 정보를 모은다. Edge weight가 큰(가까운) 이웃 정보를 더 많이 가져온다.
  2. Update: 모은 정보에 학습 가능한 weight WWW를 곱해 변환한다.
  3. Activate: ReLU 같은 비선형 함수를 통과시킨다.

H(l+1)=σ ⁣(D~−1/2A~D~−1/2H(l)W(l))H^{(l+1)} = \sigma\!\left(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2} H^{(l)} W^{(l)}\right) H(l+1)=σ(D~−1/2A~D~−1/2H(l)W(l))

  • A~=A+I\tilde{A} = A + IA~=A+I: 자기 자신(self-loop)을 더한 adjacency. 내 정보가 이웃에 묻혀 사라지지 않게 한다.
  • D~\tilde{D}D~: degree matrix (각 node의 연결 수)
  • D~−1/2A~D~−1/2\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}D~−1/2A~D~−1/2: 정규화. 연결이 아주 많은 node의 정보가 전체를 지배하지 않도록 평균을 내 주는 역할
  • H(l)H^{(l)}H(l): lll번째 층의 feature, W(l)W^{(l)}W(l): 학습할 weight
  • 층을 쌓을수록 "친구의 친구" 정보까지 반영된다.

Toy example: A×XA \times XA×X는 이웃 평균이다

Cell 3개, gene 1개. C1=10C_1 = 10C1​=10, C2=2C_2 = 2C2​=2, C3=0C_3 = 0C3​=0 (dropout으로 0이라고 가정). C3C_3C3​이 C1C_1C1​, C2C_2C2​와 연결되어 있고 self-loop 포함이면 AAA의 C3C_3C3​ 행은 [1,1,1][1, 1, 1][1,1,1].

C3′=(1×10+1×2+1×0)/3=4C_3' = (1 \times 10 + 1 \times 2 + 1 \times 0) / 3 = 4 C3′​=(1×10+1×2+1×0)/3=4

0이었던 값이 이웃 정보로 4가 됩니다. 사진에 blur를 주듯 튀는 값이 깎이고 비슷한 cell끼리 더 비슷해지는 smoothing 효과입니다. 여기에 WWW를 곱해 "어떤 정보 조합이 중요한가"를 학습합니다.

무엇이 "업데이트"되나

  • 수학적으로: weight matrix WWW가 backpropagation으로 학습된다. 예를 들어 "T cell과 B cell을 구분하라"는 목표를 주면 그 구분을 가장 잘하는 WWW를 찾는다.
  • 데이터 관점: 각 cell이 이웃 정보를 흡수한 새 embedding을 갖게 된다.

Output

형태 모양 활용
Node embedding N×DN \times DN×D clustering, UMAP, imputation (0이던 값 복원)
Node classification N×CN \times CN×C cell type 확률 (label transfer)

Single-cell 활용 (일반 지식)

  • Imputation, batch effect 제거, cell type label transfer, gene–gene network 학습
  • 한계: 모든 이웃을 정해진 weight로만 섞는다. 이웃 중요도를 데이터에 따라 바꾸려면 Attention (GAT)을 쓴다.

논문별 활용

  • 2025 Sheinin - scNET: gene–gene(PPI) graph와 cell–cell(KNN) graph에 각각 GCN을 적용해 gene embedding과 cell embedding을 함께 학습했다.
