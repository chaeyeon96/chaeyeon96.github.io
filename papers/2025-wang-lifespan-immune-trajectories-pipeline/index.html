Step 1 · Inputs

하는 일 · Atlas의 여러 assay와 clock model의 sample 수를 구분한다.

Input → Output · PBMC expression, cell labels, donor age → development/validation tables.

쉽게 말하면 · Atlas 전체 참여자 수가 age model의 training 수는 아니다.

Details · Main study 220은 scRNA+paired TCR/BCR 61, CyTOF 70, bulk RNA 34, flow 55로 구성된다. Figure 7C의 model training 표본은 56이다. 61→56 제외 사유는 이번 검토에서 확인하지 못했으므로 추정하지 않는다. Independent healthy validation은 33(공개 21+신규 12), disease application은 56(SLE 40,NPC 10,KD 6)이다. Assay/cohort의 donor 중복 여부를 확인하지 않고 모두 독립 인원으로 합산하면 안 된다.

Toy example · 설명용 donor A를 RNA와 flow에서 각각 측정해도 unique donor는 1명이다.

Figures · Main Figure 1/7.

Step 2 · Representation

하는 일 · Cell-type-specific age-associated expression을 model feature로 만든다.

Input → Output · Annotated donor expression → candidate cell-type/gene feature matrix.

쉽게 말하면 · 같은 gene도 어느 cell type에서 측정했는지가 다르면 다른 정보일 수 있다.

Details · 논문은 cell-type-specific DEGs를 independent variables로 사용한다. 25 subset-specific models와 integrated model을 비교한다. 정확한 donor aggregation, scaling, missing-subtype 처리와 feature identifier는 공개 code에서 추가 확인해야 하며 일반적인 pseudobulk recipe를 논문 설정으로 대체하지 않는다. Feature discovery에 validation age/labels가 섞이지 않는지 점검한다.

Toy example · 설명용 donor matrix의 CD4:G와 Mono:G는 gene 이름 G가 같아도 열 두 개다. 평균내어 하나로 만들면 cell-type specificity를 잃는다.

Figures · Main Figure 7A–B/G–I.

Step 3 · Feature selection

하는 일 · Predictive features를 줄여 final random forest를 만든다.

Input → Output · Candidate features + chronological age → 21-feature siAge model.

쉽게 말하면 · 여러 decision tree의 예측을 모으되, 덜 유용한 입력을 줄인다.

Details · R randomForest 4.7-1.1, rfcv 10-fold CV를 사용한다. IncMSE importance를 기준으로 top 21 genes를 선택한다. 총 26 models는 25 cell-subset-specific models와 integrated model이다. Tree 수, mtry, seed, feature selection/CV nesting의 상세 구현은 본 노트에서 검증하지 못했다. Package default를 저자가 명시한 값처럼 적지 않는다.

일반적 regression forest의 prediction은 y^(x)=B−1∑b=1BTb(x)\widehat y(x)=B^{-1}\sum_{b=1}^{B}T_b(x)y​(x)=B−1∑b=1B​Tb​(x)다. TbT_bTb​는 tree b의 prediction, B는 trees 수이며 이 수식은 원리를 설명한 것이다. IncMSE는 feature를 교란했을 때 prediction error 증가를 평가하며 causal effect size가 아니다.

Toy example · 설명용 3 trees가 30,36,39세를 예측하면 평균 prediction은 35세다(Python 검산). 이는 논문의 tree 수가 3이라는 뜻이 아니다.

Figures · Figure 7; exact heading은 논문 페이지의 Figure 7 참조.

Step 4 · Validation

하는 일 · Training fit, independent prediction, disease deviation을 별도로 평가한다.

Input → Output · Fixed model + new donor features → siAge, error, fit index.

쉽게 말하면 · 배운 사람을 다시 맞히는 시험과 처음 보는 사람의 나이를 맞히는 시험을 구분한다.

Details · Figure 7의 PCC는 training 0.9940, healthy validation 0.8894, disease application 0.6526이다. Training PCC를 외부 성능으로 인용하지 않는다. Fit index는 log⁡2(siAge/cAge)\log_2(siAge/cAge)log2​(siAge/cAge)다. 양수는 chronological age보다 높은 prediction, 음수는 낮은 prediction이다. Disease deviation이 prognosis나 causal immune aging임을 자동으로 의미하지 않는다. cAge=0에서는 정의되지 않으며 매우 어린 age에서 ratio가 불안정할 수 있다.

Toy example · 설명용 cAge=40,siAge=50이면 fit index=0.321928; cAge=40,siAge=20이면 −1이다(Python 검산). 같은 +10세 차이도 cAge=10이면 index=1이므로 연령에 따른 해석이 다르다.

Reproduction checklist

  1. Donor overlap·cohort leakage·age range를 확인한다.
  2. Training에서만 feature discovery/selection과 calibration을 적합한다(재현 audit 권고이며 원문에서 모두 입증한 사실은 아님).
  3. PCC와 함께 MAE, bias, age-stratified residual을 확인한다.
  4. 실제 model 실행과 supplementary 전체 검증은 미완료다.
