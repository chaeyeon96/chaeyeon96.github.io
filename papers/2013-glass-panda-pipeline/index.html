Step 1 · Seed networks

Action

Motif, expression, PPI의 node identifiers와 순서를 맞춰 같은 TF·gene 집합을 표현한다.

Input → Output

Motif matches + gene-by-experiment expression + physical TF interactions → W(0)∈RT×GW^{(0)}\in\mathbb R^{T\times G}W(0)∈RT×G, C(0)∈RG×GC^{(0)}\in\mathbb R^{G\times G}C(0)∈RG×G, P(0)∈RT×TP^{(0)}\in\mathbb R^{T\times T}P(0)∈RT×T.

Intuition

같은 동네를 세 지도로 그린다: ‘누가 누구를 조절할 수 있나’, ‘누가 함께 움직이나’, ‘어떤 TF들이 협력할 수 있나’이다.

Details

Wij(0)=1{TF i motif in promoter of gene j},Cjk(0)=cor⁡(xj,xk),Pim(0)=1{Affinity Capture-MS interaction}.W^{(0)}_{ij}=\mathbf1\{\text{TF }i\text{ motif in promoter of gene }j\},\quad C^{(0)}_{jk}=\operatorname{cor}(x_j,x_k),\quad P^{(0)}_{im}=\mathbf1\{\text{Affinity Capture-MS interaction}\}.Wij(0)​=1{TF i motif in promoter of gene j},Cjk(0)​=cor(xj​,xk​),Pim(0)​=1{Affinity Capture-MS interaction}.

TTT는 TF 수, GGG는 gene 수, xjx_jxj​는 gene jjj의 experiments별 expression vector다. Pii=Cjj=1P_{ii}=C_{jj}=1Pii​=Cjj​=1로 시작한다. PPI가 없으면 P=IP=IP=I로 시작할 수 있지만 ‘모든 TF가 서로 독립’이 사실이라는 뜻은 아니다.

Step 2 · Normalization and similarity

Action

각 network의 row와 column Z-score를 합쳐 √2로 나누어 공통 scale에 놓고 neighborhood agreement를 계산한다.

Input → Output

세 seed matrices → approximately Z-scored matrices와 modified Tanimoto similarity TZT_ZTZ​.

Intuition

각 TF가 원래 얼마나 많은 targets를 갖는지, 각 gene이 얼마나 많은 regulators를 갖는지를 양쪽에서 고려한 뒤 두 이웃 목록의 일치도를 비교한다.

Details

Methods S1 Eqs.7–11:

Z(Xpq)=12Xpq−μpσp+12Xpq−μqσq,Z(X_{pq})=\frac1{\sqrt2}\frac{X_{pq}-\mu_p}{\sigma_p}+\frac1{\sqrt2}\frac{X_{pq}-\mu_q}{\sigma_q}, Z(Xpq​)=2​1​σp​Xpq​−μp​​+2​1​σq​Xpq​−μq​​,

TZ(x,y)=x⊤y∥x∥2+∥y∥2−∣x⊤y∣.T_Z(x,y)=\frac{x^\top y}{\sqrt{\lVert x\rVert^2+\lVert y\rVert^2-|x^\top y|}}. TZ​(x,y)=∥x∥2+∥y∥2−∣x⊤y∣​x⊤y​.

μp,σp\mu_p,\sigma_pμp​,σp​는 row statistics, μq,σq\mu_q,\sigma_qμq​,σq​는 column statistics이다. Normalization은 초기 한 번 하며 row/column Z-score 조합이 정확한 standard-normal distribution이라는 뜻은 아니다. Original Materials S1 code는 W의 row 또는 column SD=0인 방향을 global prior mean/SD로 대체한다; 둘 다 0이거나 global SD도 0인 degenerate input을 완전히 안전하게 처리하는 일반 safeguard는 보장되지 않는다(아래 audit).

TZT_ZTZ​는 같은 positive pattern뿐 아니라 같은 negative pattern도 agreement로 본다. 따라서 negative edge weight는 곧 biological repression이 아니다. 이 score는 probability도 [-1,1] correlation도 아니다. Supplement의 대안 T2T_2T2​는 denominator의 dot-product coefficient를 2로 바꾸며 singularity 방지용 ϵ=10−10\epsilon=10^{-10}ϵ=10−10을 사용했지만 original 기본은 TZT_ZTZ​이다.

숫자는 설명용. Row Z-score가 1이고 column Z-score가 0.5라면 합친 값은 (1+.5)/2=1.060660(1+.5)/\sqrt2=1.060660(1+.5)/2​=1.060660이다. x=(1,−1)x=(1,-1)x=(1,−1), y=(1,−1)y=(1,-1)y=(1,−1)이면 TZ=2/2=1.414214T_Z=2/\sqrt{2}=1.414214TZ​=2/2​=1.414214이고, y=(−1,1)y=(-1,1)y=(−1,1)이면 −1.414214다. y=(1,1)y=(1,1)y=(1,1)이면 dot product가 0이므로 score는 0이다.

Step 3 · Messages and updates

Action

TF 쪽 협력자와 gene 쪽 co-expression partners가 같은 edge를 얼마나 지지하는지 계산한다.

Input → Output

현재 P,W,CP,W,CP,W,C → responsibility RRR, availability AAA, proposed regulatory weights W~\widetilde WW, damped WWW.

Intuition

TF의 협력자들이 이미 gene을 target한다면 TF→gene edge를 지지한다. TF의 다른 targets와 gene이 함께 움직여도 같은 edge를 지지한다.

Details

Rij(t)=TZ(Pi⋅(t),W⋅j(t)),Aij(t)=TZ(Wi⋅(t),C⋅j(t)),R^{(t)}_{ij}=T_Z(P^{(t)}_{i\cdot},W^{(t)}_{\cdot j}),\qquad A^{(t)}_{ij}=T_Z(W^{(t)}_{i\cdot},C^{(t)}_{\cdot j}),Rij(t)​=TZ​(Pi⋅(t)​,W⋅j(t)​),Aij(t)​=TZ​(Wi⋅(t)​,C⋅j(t)​),

W~ij(t)=12(Rij(t)+Aij(t)),W(t+1)=(1−α)W(t)+αW~(t).\widetilde W^{(t)}_{ij}=\tfrac12(R^{(t)}_{ij}+A^{(t)}_{ij}),\qquad W^{(t+1)}=(1-\alpha)W^{(t)}+\alpha\widetilde W^{(t)}.Wij(t)​=21​(Rij(t)​+Aij(t)​),W(t+1)=(1−α)W(t)+αW(t).

RRR는 길이 TTT vector끼리, AAA는 길이 GGG vector끼리 비교한다. 따라서 단순 PWPWPW 또는 WCWCWC matrix product만으로 동일한 algorithm이 되지 않는다: 각 pair의 TZT_ZTZ​ denominator도 필요하다.

Step 4 · Consensus and convergence

Action

Regulatory neighborhoods로 P/C를 다시 추정하고 self-connections를 anneal하며 반복한다.

Input → Output

Updated regulatory information → refined P,CP,CP,C → converged W,P,CW,P,CW,P,C.

Intuition

‘같은 targets를 가진 TF는 협력할 가능성’, ‘같은 TF가 조절하는 genes는 co-regulation 가능성’을 되돌려 보내 세 지도를 맞춘다.

Details

Off-diagonal proposals:

P~im=TZ(Wi⋅,Wm⋅),C~jk=TZ(W⋅j,W⋅k).\widetilde P_{im}=T_Z(W_{i\cdot},W_{m\cdot}),\qquad \widetilde C_{jk}=T_Z(W_{\cdot j},W_{\cdot k}).Pim​=TZ​(Wi⋅​,Wm⋅​),Cjk​=TZ​(W⋅j​,W⋅k​).

Original Methods S1 p.7에서 visually checked diagonal equations:

C~jj(t)=σjNGe2αt,P~ii(t)=σiNTe2αt.\widetilde C^{(t)}_{jj}=\sigma_j N_G e^{2\alpha t},\qquad \widetilde P^{(t)}_{ii}=\sigma_i N_T e^{2\alpha t}.Cjj(t)​=σj​NG​e2αt,Pii(t)​=σi​NT​e2αt.

NG,NTN_G,N_TNG​,NT​는 genes/TFs 수, σj\sigma_jσj​는 C⋅jC_{\cdot j}C⋅j​의 SD, σi\sigma_iσi​는 Pi⋅P_{i\cdot}Pi⋅​의 SD다. 두 matrices도 X(t+1)=(1−α)X(t)+αX~(t)X^{(t+1)}=(1-\alpha)X^{(t)}+\alpha\widetilde X^{(t)}X(t+1)=(1−α)X(t)+αX(t)로 갱신한다. 구현별로 diagonal normalization convention이 달라질 수 있으므로 이 식을 modern package 기본식이라고 주장하지 않는다.

Supplement의 convergence 식은

H(t)=1NTNG∑ij∣W~ij(t)−Wij(t−1)∣<10−5H^{(t)}=\frac{1}{N_TN_G}\sum_{ij}|\widetilde W^{(t)}_{ij}-W^{(t-1)}_{ij}|<10^{-5} H(t)=NT​NG​1​ij∑​∣Wij(t)​−Wij(t−1)​∣<10−5

이다. 원문은 이를 Hamming distance라고 부르지만 실제 연산은 continuous weights의 mean absolute difference다. 제안값과 이전값을 비교하는 식을 임의로 ‘damped successive W의 차이’로 바꾸지 않는다. Yeast example은 약 120 iterations에 수렴했다.

Step 5 · Evaluation

Action

Input으로 쓰지 않은 evidence로 prediction ranking과 robustness를 평가한다.

Input → Output

Weighted networks + gold standards → ROC AUC, sensitivity, precision, jackknife comparison.

Intuition

세 지도가 서로 동의한다는 사실만으로 실제 지형이 맞는 것은 아니다. 별도의 관측으로 확인한다.

Details

WWW는 ChIP-chip bindings, CCC는 ChIP-chip에서 shared TF가 있는 gene pairs, PPP는 stringent low-throughput physical interactions와 비교한다. Gold standard에서 정보가 없는 zero-sum rows/columns에 연결된 edges는 AUC 평가에서 제외했다.

TPR=TPTP+FN,specificity=TNTN+FP,precision=TPTP+FP.\mathrm{TPR}=\frac{TP}{TP+FN},\quad \mathrm{specificity}=\frac{TN}{TN+FP},\quad \mathrm{precision}=\frac{TP}{TP+FP}. TPR=TP+FNTP​,specificity=TN+FPTN​,precision=TP+FPTP​.

일반 정의로 쓴 식이며 논문 Figure 3B는 specificity 90%에서 비교한다. Jackknife는 TFs와 genes 각각 10% 제거 후 100회 반복, 각 반복의 final−initial AUC 차이를 normal approximation으로 평가한다. Independent human cohort validation과는 다른 것이다.

Toy example

숫자는 설명용. TP=4, FN=6, FP=3, TN=27이면 sensitivity=.4, specificity=.9, precision=4/7=.571429다. 높은 specificity가 높은 precision을 자동 보장하지 않는다.

Step 6 · Modules

Action

Condition별 상위 edges와 그 주변 genes를 묶어 functional interpretation을 만든다.

Input → Output

세 condition networks → unique-edge sets, GO enrichment, selected modules.

Intuition

모든 조건에서 공통으로 켜지는 ‘기본 회로’와 특정 조건에서만 강조되는 회로를 구분한다.

Details

각 WWW의 top 1,000 edges를 선택한다. 세 sets의 union을 만들고 한 condition에만 나타나는 edges를 condition-specific으로 정의한다. DAVID enrichment background는 2,555 genes; Figure 3F–G 표시 기준은 BH FDR<10−510^{-5}10−5와 selected gene set의 ≥10%를 포함하는 GO term이다.

Module TF/gene은 union 내 incident edges 중 ≥1/2가 특정 condition에만 있고 total degree가 TF ≥10 또는 gene ≥3인 경우를 선택한다. P/C visualization은 각 final matrix의 top 10% edges, W visualization은 위 top 1,000 기준을 쓴다.

Toy example

숫자는 설명용. TF degree=10, 그중 한 condition unique=6이면 6/10=.6이므로 두 조건을 통과한다. Gene degree=4, unique=2도 .5라 통과한다. Degree=2 gene은 unique=2여도 minimum-degree filter를 통과하지 않는다.

Notation audit

  • Main Methods availability 설명에 Wj⋅W_{j\cdot}Wj⋅​가 등장하지만 equation/Methods S1은 TF iii의 targets인 Wi⋅W_{i\cdot}Wi⋅​이다.
  • Main Results의 simulated-network size 비교는 두 번 ‘cooperative-effects’라고 쓰지만 100-node·4,950-pair network는 co-affected targets이다.
  • Methods S1은 W update와 convergence 식에 같은 Eq.16 번호를 쓴다. Time indices도 그대로 기록하고 implementation이 동일한 update ordering인지 별도 확인해야 한다.
  • Methods S1의 stability 문장 Figure S2B 참조와 main text Figure S1A 참조가 다르다.
  • Original material archive의 source는 아래처럼 직접 확인했지만 code compile·full network execution은 수행하지 않았다. Degenerate all-constant matrices에 대한 numerical robustness는 검증하지 않았다.

Original source-code audit

Materials S1의 Version0/PANDA_v0.c와 README를 실제로 열어 주요 functions를 확인했다. Archive SHA256=61f95b9444af8687db285f312296f40a78bb4c7736847012759715f5ae686f9e, source SHA256=5d034eb03365f518d702cc8e38d822cdd969b08c9139131d03cc3302dcea7560.

  • Lines39–40: α=.05, maxstep=1000; loop는 killstep<=maxstep이므로 step index0부터 시작하는 off-by-one convention을 주의한다.
  • Lines219–229,313–323: proposed R/A average와 현재 undamped W의 mean absolute difference를 먼저 계산한 뒤 W를 damped update한다. 다음에 UpdateCorrelation, UpdatePPI가 그 updated W를 쓴다. Main loop는 세 return values를 더하지만 C/P update functions는 0을 반환하므로 stopping statistic은 W proposal difference뿐이다.
  • Lines328–440: C/P proposals의 off-diagonal entries로 row means와 population variance를 계산하고 그 SD를 diagonal inflation에 사용한다. Supplement prose가 ‘across C/P’라고 짧게 쓴 부분을 구체화한다.
  • Lines618–657: W는 population SD를 사용한다. Column SD=0이면 column component를 global prior Z-score로, row SD=0이면 row component를 global prior Z-score로 대체한다. Row/column components는 각각 1/√2 coefficient이며 단순 산술평균 1/2가 아니다.
  • Lines770–815: expression pair에서 usable observations>2이고 두 variances>0일 때 Pearson을 계산, 아니면 off-diagonal correlation=0; diagonal=1이다. P/C Z-normalization에는 모든 degenerate SD에 대한 동일 fallback가 보이지 않아 full-constant 입력은 사전 검사해야 한다.
  • README는 expression/motif required, PPI optional; output columns는 TF, gene, original motif, expression correlation, PANDA prediction이다. 사용 예의 α=.25는 README 예시이고 논문 실험 α=.05를 대체하지 않는다.

이는 original source inspection이며 modern netZoo defaults를 original 2013 실행에 소급한 것이 아니다.

Run it yourself

  1. Original Materials S1에서 code·input·output을 함께 확보한다.
  2. TF/gene IDs와 행·열 순서를 고정하고 세 input matrices의 dimensions·finite values를 검사한다.
  3. Original settings와 현대 package settings를 별도 config로 보관한다; 결과 파일에는 software version, α, stopping criterion을 적는다.
  4. Gold standard를 training prior에 넣지 않고 동일한 evaluable-edge universe로 비교한다.
  5. Full biological reproduction 전에 위 toy calculations를 검사한다. Toy는 Python으로 검산했고 network inference 전체 run은 수행하지 않았다.
