1. Network and labels

Task

ID를 통일하고 experimental/curated relations를 통합한다.

Input → Output

DrugBank IDs, Entrez gene IDs, UMLS disease IDs, GO terms → typed graph와 approved-pair labels.

Intuition

서로 다른 database의 같은 사람을 이름만으로 중복 집계하지 않도록 식별자를 맞추는 과정이다.

Details

DisGeNET에서는 curated associations만 사용하고 therapeutic 관계를 제거해 circularity를 줄인다. PPI는 human physical interaction의 direct experimental evidence로 제한한다. GO는 experimental evidence를 선택하고 physical-interaction-derived annotation, expression-pattern inference, computational/electronic annotation 등을 제외한다. GO function edges는 regulates/positively regulates/negatively regulates/part of/is a를 허용한다.

Approved pairs는 FDA-approved treatment에 해당하는 관계만 남기고 prevention/diagnosis 등의 indication과 infectious-agent target에 의존하는 treatment를 제외한다. 최종 5,926 pairs는 graph의 treatment edge로 넣는 입력과 구분되는 evaluation labels다.

Toy example

숫자는 설명용: database A의 (drug D, disease X)와 B의 같은 pair는 합집합에서 1개다. 두 database가 있다는 이유만으로 두 번의 독립 clinical validation이 되는 것은 아니다.

2. Biased transition and restart

Task

Node type의 중요도를 먼저 정하고 그 type 안의 이웃으로 확률을 나눈다.

Input → Output

Graph, weights W, source s → stationary row vector r.

Intuition

갈림길의 ‘protein 방향’과 ‘function 방향’을 먼저 고른 뒤 그 방향의 개별 길을 고른다. 이웃 수가 많은 type이 무조건 모든 확률을 가져가지는 않는다.

Details

Edge를 양방향으로 만든 뒤 관심 drug/disease를 no-in-edge source로, 나머지 drug/disease를 no-out-edge sink로 만든다. 다른 drug/disease를 경유하는 walk는 허용하지 않는다.

pt=wt∑u∈Tiwu,Mij=ptni,t.p_t={w_t\over\sum_{u\in T_i}w_u},\qquad M_{ij}={p_t\over n_{i,t}}. pt​=∑u∈Ti​​wu​wt​​,Mij​=ni,t​pt​​.

TiT_iTi​는 node i의 이웃 type 집합, ni,tn_{i,t}ni,t​는 type t 이웃 수다. Sink 집합 J의 확률 질량을 restart vector s로 되돌린다.

r(k+1)=(1−α)s+α(r(k)M+s∑j∈Jrj(k)).r^{(k+1)}=(1-\alpha)s+\alpha\left(r^{(k)}M+s\sum_{j\in J}r_j^{(k)}\right). r(k+1)=(1−α)s+α​r(k)M+sj∈J∑​rj(k)​​.

α는 continue probability이며 restart는 1−α다. 초기 ri=1/∣V∣r_i=1/|V|ri​=1/∣V∣, 종료는 L1 change≤10⁻⁶, 매 step total probability는 1이다.

Optimal multiscale setting Value
wdrug / wdisease / wprotein 3.21 / 3.54 / 4.40
whigher / wlower / wfunction 2.10 / 4.49 / 6.58
α 0.860
Comparison Correlation-based distance/similarity

Toy example

숫자는 설명용: protein 이웃 2개, function 이웃 1개이며 weights가 각각 2와 1이면 type 확률은 2/3와 1/3이고 각 이웃 확률은 모두 1/3이다. 모든 weights를 10배 해도 확률은 같다.

Source A→B→sink C의 toy graph에서 α=0.8이면 stationary r는 약 (0.409836,0.327869,0.262295)다; C의 질량도 매 step A로 돌려야 합이 1을 유지한다. 실제 논문 graph의 결과는 아니다.

3. Ranking and evaluation

Task

Disease별로 drug profile similarity를 계산해 approved treatment를 얼마나 위에 놓는지 평가한다.

Input → Output

Drug/disease profiles + held-out labels → ranked drugs, AUROC/AP/Recall@50.

Intuition

정답 목록을 학습에 모두 보여 주지 않고 일부 drug를 통째로 숨긴 뒤 ranking을 평가한다.

Details

L1, L2, Canberra, cosine, correlation 비교와 두 visitation-based metric을 시험한다. Distance는 부호를 바꿔 높은 값이 비슷함을 뜻하게 한다. 5-fold split 단위는 drug다. Disease별 AUROC의 median, AP와 Recall@50의 mean을 구한 뒤 held-out performance를 folds에 걸쳐 평균한다.

Hyperparameter sweep은 486 combinations: drug/disease/protein weights [3,9], higher/lower [1.5,4.5], α [0.85,0.9], function weight=higher+lower; seven comparison metrics. Training-fold median AUROC 평균으로 선택한다. Supplementary Note 2의 wider sweep은 560 combinations, weights [1,100], α [0.667,1.0]이며 성능 개선은 없었다.

Baseline은 protein Jaccard, 17 functional-overlap variants, degree/size-matched 1,000 permutations의 PPI proximity, molecular-only diffusion을 포함한다.

Toy example

숫자는 설명용: 세 disease의 AP가 (0.1,0.2,0.9)이면 mean=0.4이고 median=0.2다. 원문은 AP에 mean을 쓰므로 둘을 바꾸면 다른 결과가 된다.

4. Explanation and expression check

Task

Profile의 주요 node를 압축하고 별도 expression evidence와 비교한다.

Input → Output

Top-ranked nodes → subgraph; matched-condition CMap pairs → similarity association.

Intuition

전체 지도를 다 보여 주는 대신 주요 정거장을 보여 주되, 잘라 낸 지도가 전체 network는 아니라는 점을 기억한다.

Details

Drug와 disease profile 각각의 top k=10 protein/function nodes로 subgraph를 유도하고 isolated components를 제거한다. Supplementary Figures 16–18은 top 20 rank를 보완한다.

CMap은 Level 5 measured landmark genes만 쓰며, 같은 cell/dose/exposure-time의 signature pair만 비교한다. Drug QC는 inter-cell connectivity≥0.4, aggregated TAS≥0.3, touchstone membership. Signature QC는 distil_cc_q75≥0.2, pct_self_rank_q25≤0.1, exemplar, TAS≥0.35, replicates≥3이며 남은 signature 중 가장 높은 TAS를 선택한다.

Expression similarity는 up/down top 25 gene sets의 Jaccard 평균이다:

Sexpr=12(∣U1∩U2∣∣U1∪U2∣+∣D1∩D2∣∣D1∪D2∣).S_{expr}={1\over2}\left({|U_1\cap U_2|\over|U_1\cup U_2|}+{|D_1\cap D_2|\over|D_1\cup D_2|}\right). Sexpr​=21​(∣U1​∪U2​∣∣U1​∩U2​∣​+∣D1​∪D2​∣∣D1​∩D2​∣​).

Toy example

숫자는 설명용: up-set overlap/union=2/4, down-set=1/5이면 similarity=(0.5+0.2)/2=0.35. 반대 방향의 up-vs-down overlap을 같은 방향 similarity로 더하지 않는다.

5. Treatment importance

Task

Drug와 disease 양쪽에서 자주 방문되는 gene을 우선순위화한다.

Input → Output

두 profiles → gene-wise TI와 treatment 내 percentile rank.

Intuition

한쪽에서만 중요한 정거장보다 두 경로가 함께 의존하는 정거장을 찾는다.

Details

TI(i∣c,d)=ri(c)ri(d).TI(i\mid c,d)=r_i^{(c)}r_i^{(d)}. TI(i∣c,d)=ri(c)​ri(d)​.

PharmGKB의 efficacy/dosage/metabolism/pharmacokinetics/toxicity 관련 triplets를 승인 treatment로 제한한다. 1,223 positives와 동수의 unknown triplets를 비교한다. 같은 disease의 두 drug에 대한 비교는 gene별 가능한 triplets가 100개 이상인 경우에 평가한다.

Toy example

숫자는 설명용: gene A의 drug/disease 방문확률이 (0.2,0.3)이면 TI=0.06, gene B가 (0.5,0.01)이면 0.005다. Drug profile만 보면 B가 크지만 joint importance는 A가 크다.

Notation discrepancies

  • 기존 노트의 drug–protein edge 8,565를 Methods의 8,568로 수정했다.
  • 기존 노트의 ‘모든 metric의 disease median’은 부정확했다; AUROC median, AP/Recall mean이다.
  • Printed optimized higher+lower=2.10+4.49=6.59지만 function=6.58로 적혀 있다. 반올림/원값 차이 가능성이 있으므로 그대로 별도 기록하며 code의 원값을 확인한다.
  • α를 restart probability로 바꾸어 쓰면 반대 walk가 된다. 이 원문에서는 continue probability다.
