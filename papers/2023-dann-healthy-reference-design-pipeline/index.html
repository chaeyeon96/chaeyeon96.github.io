Step 1 · Inputs

하는 일 · Embedding을 위한 atlas와 검정을 위한 matched control의 역할을 나눈다.

Input → Output · Healthy atlas, cohort-matched control, disease counts → design별 training/query/test sample 목록.

쉽게 말하면 · 큰 지도는 길을 찾는 데 쓰고, 차이의 크기는 비교 가능한 이웃끼리 잰다.

Details

Design Embedding DA comparison
AR Atlas train, disease query Atlas vs disease
CR mapping Control train, disease query Control vs disease
CR joint Control+disease joint scVI Control vs disease
ACR Atlas train, control+disease query Control vs disease; atlas는 DA graph에서 제외

PBMC atlas는 13 studies의 1,248 individuals/1,268 samples에서 시작한다. Sample당 500 cells로 downsample하고 500 미만 sample을 제외했다. Cell당 ≥1,000 mRNA, ≥1 cell에서 검출한 genes를 사용하여 QC 후 599,379 cells, doublet cluster 제거 후 597,321 cells/16 cell types를 얻었다. Benchmark query study의 healthy 29 donors를 pseudo-disease 16/control 13으로 나누고 남은 12 studies/1,219 donors를 atlas로 쓴다. OOR simulation은 특정 population을 atlas와 control에서 제거하고 pseudo-disease에 남긴다. 15 simulations 중 OOR cells <250인 7개는 주요 분석에서 제외했다.

Toy example · 설명용으로 atlas 100명, control 10명, disease 10명이 있으면 ACR의 embedding reference는 100명, DA의 biological replicates는 20명이다. Atlas 100명을 control 10명에 합치면 다른 design이 된다.

Step 2 · Representation

하는 일 · Technical variation을 모델링하며 reference latent space에 query를 배치한다.

Input → Output · Raw counts + batch covariate → low-dimensional cell representation.

쉽게 말하면 · 서로 다른 카메라로 찍은 세포를 같은 좌표계에 정렬한다. 같은 좌표가 곧 disease effect라는 뜻은 아니다.

Details

Scope Reported setting
Atlas harmonization 5,000 HVGs; scVI n_latent=30, gene_likelihood=nb, n_layers=2, dropout 0.2
Covariate architecture use_layer_norm=both, use_batch_norm=none, encode_covariates=True
Atlas training library ID batch; max 200 epochs, train size 0.9, early-stopping patience 45, batch size 1,024, limit_train_batches=20
Atlas annotation k=50 graph, Leiden resolution 1.5, majority annotation
Benchmark embedding scvi-tools 0.17.4; reference-derived 5,000 HVGs, sample ID batch; 400 epochs or convergence
Query adaptation scArches 200 epochs, weight_decay=0

Harmonization과 benchmark의 training 설정을 혼합하지 않는다. Benchmark의 모든 default parameter가 위 표에서 확정된 것은 아니다. Mixed OOR에서는 classical monocytes와 다른 population을 섞고 query population을 PC1로 나눈 뒤 atlas에 kNN(k=10) label을 적용한다.

Toy example · 설명용 reference HVGs가 {A,B,C}라면 query에서 D가 강하게 발현되어도 이 representation 입력에는 D가 없다. OOR detection은 feature selection에 제약받는다.

Step 3 · Testing

하는 일 · Neighborhood별 disease enrichment를 donor-level로 검정한다.

Input → Output · Latent cells + donor/condition → neighborhood logFC, spatial FDR.

쉽게 말하면 · 세포 한 개씩 투표시키지 않고, 사람마다 각 지역에 몇 개의 세포가 있는지 센다.

Details

Milo(milopy 0.1.0) graph는 k=min⁡(5Nsamples,200)k=\min(5N_{samples},200)k=min(5Nsamples​,200), neighborhood sampling prop=0.1이다. Neighborhood jjj, sample sss의 count YjsY_{js}Yjs​를 NB GLM으로 비교한다. 일반적 표현은 log⁡μjs=offsets+β0j+βDjDs+βSjSites\log\mu_{js}=\mathrm{offset}_s+\beta_{0j}+\beta_{Dj}D_s+\beta_{Sj}Site_slogμjs​=offsets​+β0j​+βDj​Ds​+βSj​Sites​이며, 정확한 normalization 구현은 해당 milopy version/code를 따른다. CR/ACR에는 disease와 collection site covariate를 사용한다. Graph overlap을 고려한 weighted BH의 spatial FDR <0.1, logFC>0을 disease enrichment로 판정한다.

Toy example · Python 검산: 6 samples이면 k=30, 60 samples이면 k=200이다. Control의 10/100 cells와 disease의 20/100 cells는 설명용 비율 차이 2배(log2 ratio=1)이지만 이것만으로 Milo P value를 얻을 수 없다. Donor replication과 dispersion이 필요하다.

Step 4 · Validation

하는 일 · 알려진 simulation truth와 실제 disease biology를 다른 기준으로 평가한다.

Input → Output · Ranked neighborhoods / annotations / gene scores → performance와 biological consistency.

쉽게 말하면 · 정답이 있는 모의시험과 정답을 완전히 모르는 실제 진료 상황을 나눠 평가한다.

Details

  • Simulation true OOR neighborhood는 OOR fraction이 해당 simulation 최대 fraction의 20%를 넘는 경우다. AUPRC ranking에는 logFC를 사용한다. Stratified bootstrap 1,000회로 95% CI를 계산한다.
  • COVID-19: graph k=100; scanpy.score_genes IFN score를 사용한다. PR truth proxy는 score>0.05이다. Monocyte high/low IFN 경계는 0.2이고, DA 조건과 함께 해석한다. ≥3 neighborhoods에 속하면 phenotype label을 부여하고 나머지는 mixed다. Sample×phenotype pseudobulk DE는 FDR 1%다.
  • IPF: GSE136831을 HLCA에 mapping한다. CR은 HLCA의 2,000 HVGs와 dataset batch를 쓴 scANVI이다. Milo prop=0.01; profibrotic macrophage score>0.32(90th quantile), cell-type IPF signature는 상위 50%를 proxy로 사용한다. Pseudobulk DE는 7,500 HVGs, FDR 1%다.

Toy example · 최대 OOR fraction 0.8이면 truth threshold는 0.16이다(Python 검산). 0.17은 positive, 0.15는 negative지만 threshold 선택을 바꾸면 평가도 달라진다.

Reproduction checklist

  • Donor split과 cell split을 혼동하지 않는다. Atlas와 tested control에 동일 donor가 중복되는지 점검한다.
  • Matched control은 confounding을 줄이지만 없는 covariate까지 보정하지 않는다.
  • Simulation 제거 population과 실제 disease OOR의 난도는 같지 않다.
  • Design reproducibility code, benchmark code, milopy.
  • Processed data/models, original Methods.

Unresolved settings

Supplementary PDF 전체 및 code 실행을 검증하지 않았다. Harmonization의 n_latent=30을 모든 downstream model에 자동 적용하지 않는다. Real-disease signature를 independent ground truth로 간주하지 않는다.
