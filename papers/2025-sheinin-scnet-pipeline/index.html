1. Inputs and preprocessing

Task

Expression과 PPI가 같은 gene을 같은 순서로 가리키도록 정리하고, cell graph를 만든다.

Input → Output

공개 scRNA-seq counts + weighted human PPI → MMM, AgA_gAg​, AcA_cAc​, reconstruction loss에 사용할 highly variable gene(HVG) mask.

입력 data의 출처와 원래 크기는 Data map에 있다. 예를 들어 B cell data의 19,374 genes를 그대로 전부 모델 node로 썼다고 가정하면 안 된다.

Intuition

Cell expression 표와 protein 관계표에서 서로 다른 이름·순서의 명단을 쓰면, 다른 gene의 정보를 합치게 된다. 먼저 공통 명단과 순서를 만들고, gene별 값의 크기도 비교 가능하게 맞춘다.

Details

Methods에 적힌 순서와 계산

  1. 각 cell의 total count로 나눈 뒤 scale factor를 곱하고 log1p한다. RNA-seq Normalization 참고.
  2. highly_variable_genes로 변이가 큰 gene subset을 정한다. 이 subset은 expression reconstruction loss를 계산하는 데 사용한다.
  3. Scale-normalized matrix에서 PCA와 UMAP을 계산한다. PCA 차원은 elbow plot으로 수동 선택했다고 적었다.
  4. PCA space에서 cell KNN graph를 만든다. KNN Graph 참고.
  5. Log-normalized expression을 gene별 mean 0, standard deviation 1로 scale한다.
  6. Weighted human PPI에서 score <0.5인 edge를 버린다. 이 단계의 network는 14,136 proteins, 111,790 interactions다.
  7. Dataset 전체에서 발현이 없는 gene, 유효한 PPI edge에 연결되지 않는 gene을 제외하고 matrix와 graph의 순서를 맞춘다.

Counts를 ngcn_{gc}ngc​, scale factor를 sss라 하면 normalization은 다음과 같다.

ℓgc=log⁡(1+sngc∑hnhc),Mgc=ℓgc−μgσg.\ell_{gc}=\log\left(1+s\frac{n_{gc}}{\sum_h n_{hc}}\right),\qquad M_{gc}=\frac{\ell_{gc}-\mu_g}{\sigma_g}. ℓgc​=log(1+s∑h​nhc​ngc​​),Mgc​=σg​ℓgc​−μg​​.

μg\mu_gμg​, σg\sigma_gσg​는 cell 사이에서 계산한 gene ggg의 mean과 standard deviation이다. 이 수식은 Methods의 prose를 풀어 쓴 것이다. σg=0\sigma_g=0σg​=0 처리, 표본/모집단 standard deviation 선택, 수치 안정화 상수는 구현과 함께 확인해야 한다.

2. Dual-view encoder

Task

같은 matrix에서 cell 방향과 gene 방향의 graph convolution을 번갈아 적용한다.

Input → Output

MMM, cell KNN, gene PPI → 두 종류의 이웃 정보가 섞인 중간 feature matrix HHH.

Intuition

표의 열 방향에서는 비슷한 cell끼리 의견을 모으고, 행 방향에서는 연결된 gene끼리 의견을 모은다. 한 방향에서 모은 정보를 다른 방향으로 넘기므로 두 graph가 따로 작동하는 것이 아니다.

Details

Methods의 graph convolution은 다음과 같다.

Aˉ=A+I,A^=Dˉ−1/2AˉDˉ−1/2,X′=ϕ ⁣(A^ δ(X)W).\bar A=A+I,\quad \hat A=\bar D^{-1/2}\bar A\bar D^{-1/2},\quad X'=\phi\!\left(\hat A\,\delta(X)W\right). Aˉ=A+I,A^=Dˉ−1/2AˉDˉ−1/2,X′=ϕ(A^δ(X)W).

III는 self-loop, Dˉ\bar DDˉ는 Aˉ\bar AAˉ의 degree matrix, δ\deltaδ는 dropout, WWW는 학습할 weight, ϕ\phiϕ는 activation이다. Graph Convolutional Network에 일반 원리가 있다.

Gene × cell 방향을 유지해 쓰면 한 차례의 dual-view 처리는 다음처럼 나타낼 수 있다.

H~(l)=CellConv⁡ ⁣((H(l))⊤,Ac)⊤,H(l+1)=GeneConv⁡ ⁣(H~(l),Ag).\tilde H^{(l)}= \operatorname{CellConv}\!\left((H^{(l)})^\top,A_c\right)^\top, \qquad H^{(l+1)}=\operatorname{GeneConv}\!\left(\tilde H^{(l)},A_g\right). H~(l)=CellConv((H(l))⊤,Ac​)⊤,H(l+1)=GeneConv(H~(l),Ag​).

Cell graph를 사용할 때 node는 cell이므로 transpose한다. Gene graph로 돌아오면 node는 gene이다. 이 식은 방향을 설명하기 위한 표기이며, 모든 weight matrix를 생략한 shorthand다.

3. Gene and cell attention

Task

Gene graph와 cell graph의 이웃 중요도를 학습하면서 각각 저차원 embedding을 만든다.

Input → Output

중간 HHH + PPI → ZgZ_gZg​; H⊤H^\topH⊤ + KNN → ZcZ_cZc​ 및 cell-edge attention coefficients.

Intuition

연결된 이웃을 모두 똑같이 참고하는 대신, 현재 입력을 복원하는 데 어느 이웃을 더 참고할지 학습한다. Cell branch의 점수는 나중에 KNN edge를 줄이는 근거가 된다.

Details

원문은 node iii의 새로운 feature를 다음처럼 설명한다.

xi′=W1xi+∑j∈N(i)αijW2xj,αij=sigmoid⁡((W3xi)⊤(W4xj)d).x'_i=W_1x_i+\sum_{j\in N(i)}\alpha_{ij}W_2x_j, \qquad \alpha_{ij}=\operatorname{sigmoid} \left(\frac{(W_3x_i)^\top(W_4x_j)}{\sqrt d}\right). xi′​=W1​xi​+j∈N(i)∑​αij​W2​xj​,αij​=sigmoid(d​(W3​xi​)⊤(W4​xj​)​).

N(i)N(i)N(i)는 graph상 이웃, W1W_1W1​은 자기 feature, W2W_2W2​는 이웃 feature를 바꾸는 weight다. W3xiW_3x_iW3​xi​와 W4xjW_4x_jW4​xj​는 중요도를 계산하기 위한 두 projection이다. 원문은 ddd를 node degree로 소개하지만, 현재 구현의 denominator는 attention output dimension의 square root다. 자세한 차이는 마지막 메모에 남겼다.

Sigmoid의 의미 · Softmax는 같은 node의 이웃 점수 합을 1로 만든다. Sigmoid는 edge마다 0–1로 변환하며, 합이 1일 필요가 없다. 따라서 모든 이웃 점수가 낮게 남을 수도 있다. 이 값을 biological interaction의 calibrated probability로 보지는 않는다.

현재 코드에서는 cell branch만 custom sigmoid attention을 사용하고, gene branch는 standard TransformerConv를 사용한다. Cell branch의 계산에는 score 표준화도 있다.

sij=qi⊤kjdc,s~ij=3sij−mean⁡(s)sd⁡(s),αij=sigmoid⁡(s~ij).s_{ij}=\frac{q_i^\top k_j}{\sqrt{d_c}},\qquad \tilde s_{ij}=3\frac{s_{ij}-\operatorname{mean}(s)}{\operatorname{sd}(s)},\qquad \alpha_{ij}=\operatorname{sigmoid}(\tilde s_{ij}). sij​=dc​​qi⊤​kj​​,s~ij​=3sd(s)sij​−mean(s)​,αij​=sigmoid(s~ij​).

이 식은 현재 코드의 기본 scale_param=3 경로를 설명한 것이며 논문 Methods에 추가해 적힌 수식은 아니다. Mean과 standard deviation은 그 호출에서 처리한 edge score 전체에서 계산한다. 그래서 sigmoid를 사용한다고 batch 구성과 무관한 절대척도가 자동 보장되는 것은 아니다.

4. Reconstruction and losses

Task

Gene embedding으로 PPI edge를, cell embedding으로 expression을 복원하도록 model parameter를 학습한다.

Input → Output

ZgZ_gZg​, ZcZ_cZc​ → PPI edge score, M^\hat MM^, reconstruction loss 및 gradient update.

Intuition

두 개의 시험을 동시에 치른다. 어떤 protein끼리 연결되어 있는지도 맞혀야 하고, cell expression도 다시 만들어야 한다. 한 시험만 잘 보는 representation을 피하려는 공동 학습이다.

Details

PPI decoder

A^ij=sigmoid⁡(zg,i⊤zg,j).\hat A_{ij}=\operatorname{sigmoid}(z_{g,i}^\top z_{g,j}). A^ij​=sigmoid(zg,i⊤​zg,j​).

Gene embedding 두 개의 inner product를 edge score로 바꾼다. Positive set E+E_+E+​는 학습에 사용하는 PPI edge, negative set E−E_-E−​는 같은 수로 random sampling한 non-edge다. 원문의 식을 edge index가 분명하도록 풀면

LPPI=−∑(i,j)∈E+log⁡A^ij−∑(i,j)∈E−log⁡(1−A^ij).\mathcal L_{\mathrm{PPI}}= -\sum_{(i,j)\in E_+}\log\hat A_{ij} -\sum_{(i,j)\in E_-}\log(1-\hat A_{ij}). LPPI​=−(i,j)∈E+​∑​logA^ij​−(i,j)∈E−​∑​log(1−A^ij​).

Non-edge는 기존 network에 없다는 뜻이며, 생물학적으로 절대 상호작용하지 않는다고 실험 확인된 negative와는 다르다 (일반 지식).

Expression decoder

M^⊤=FC⁡3(Zc),Lv=1C∣V∣∑c=1C∑g∈V(Mgc−M^gc)2.\hat M^\top=\operatorname{FC}_3(Z_c),\qquad \mathcal L_v= \frac{1}{C\lvert V\rvert}\sum_{c=1}^{C}\sum_{g\in V} (M_{gc}-\hat M_{gc})^2. M^⊤=FC3​(Zc​),Lv​=C∣V∣1​c=1∑C​g∈V∑​(Mgc​−M^gc​)2.

VVV는 HVG subset이다. Decoder는 남아 있는 전체 gene 차원을 출력하지만 expression MSE는 HVG 위치에서 계산한다. PPI와 교집합을 취하기 전에 제외된 gene까지 모두 복원하는 것으로 해석하지 않는다.

Joint loss — paper

L=λPPILPPI+λvLv.\mathcal L=\lambda_{\mathrm{PPI}}\mathcal L_{\mathrm{PPI}} +\lambda_v\mathcal L_v. L=λPPI​LPPI​+λv​Lv​.

5. Training and KNN pruning

Task

학습을 반복하면서 낮은 cell-edge attention을 제거하고, cell이 graph에서 고립되지 않도록 보호한다.

Input → Output

현재 model, cell graph, cell-edge coefficients → 업데이트한 parameter와 더 작은 KNN graph. Cell subset 학습 모드에서는 통합된 pruned graph가 생성되지 않는다.

Intuition

처음에는 일정 수의 이웃을 연결하지만, 그중에는 실제로 도움이 되지 않는 이웃도 있을 수 있다. 학습 중 참고하지 않는 연결을 줄이되, 이웃을 전부 잃은 cell이 생기지 않게 한다.

Details

원문은 다음 pruning rule을 제시한다.

β=max⁡(0,P10({αij})),E′={(i,j)∈E:αij>β}.\beta=\max(0,P_{10}(\{\alpha_{ij}\})),\qquad E'=\{(i,j)\in E:\alpha_{ij}>\beta\}. β=max(0,P10​({αij​})),E′={(i,j)∈E:αij​>β}.

P10P_{10}P10​은 현재 coefficient의 10th percentile이다. Sigmoid coefficient는 음수가 아니므로 보통 max⁡(0,⋅)\max(0,\cdot)max(0,⋅)는 값에 영향을 주지 않는다. Methods는 30 epoch마다 최대 10%, cell마다 최소 5개 edge 유지도 명시한다. Percentile rule을 cell별 보호 규칙과 함께 읽어야 하며, 무조건 매번 정확히 10%가 사라지는 것은 아니다.

두 mini-batch 방식

  • Edge split · KNN edge를 보통 5개 또는 10개 batch로 나눠 처리한다. Cell을 서로 다른 biological sample로 나누는 것이 아니라 계산에 사용할 edge를 나누는 것이다.
  • Cell split · 10,000 cells를 넘는 큰 data에서는 cell subset으로 나눠 처리한다. Methods는 100,000 cells 미만 data를 보통 10개 subset으로 나눈다고 설명한다. 이 경로에서는 공통 cell embedding space를 학습하지만 통합된 pruned KNN graph는 만들지 않는다.

또한 논문은 model 선택에 쓰는 subset을 test set으로 부른다. 선택에 사용한 score와 완전히 독립적인 최종 성능 평가는 다르므로, 재현 연구에서는 validation/test 분리를 확인해야 한다 (일반 지식).

직접 돌려 보려면

  1. 저자 저장소와 기본 notebook을 기준으로 별도 실행 환경을 준비한다. 패키지명은 scnet, import 이름은 scNET이다. 논문 환경은 PyTorch 2.1.1 / torch-geometric 2.1.1이다.
  2. 원래 counts와 cell/gene 식별자를 보존한 AnnData를 준비한다. Gene identifier가 symbol인지 확인하고 종 및 PPI coverage를 확인한다. 사용자 data를 이 위키 작업에서 학습시키지는 않았다.
  3. 실제 실행 버전과 Git commit을 기록한다. 아래는 현재 API에 맞춘 시작 예시이며 논문 결과의 재현을 보장하는 설정집은 아니다. 전처리를 이미 한 data라면 pre_processing_flag와 .raw 처리를 먼저 확인한다.
import scNET

# obj: 분석용으로 복사해 둔 AnnData, 여기서는 raw counts 입력을 가정
# Human data의 예시. Mouse data는 gene symbol/PPI 대응을 먼저 확인한다.
model = scNET.run_scNET(
    obj,
    pre_processing_flag=True,
    human_flag=True,
    number_of_batches=5,  # 설명용 선택: paper는 edge split 5 또는 10을 기술
    split_cells=False,   # 큰 data는 현재 구현이 cell split으로 바꿀 수 있음
    n_neighbors=25,      # 현재 API 기본값; paper의 명시값은 아님
    max_epoch=250,       # paper에 적힌 epoch 수를 명시
    model_name="scnet_example",
    save_model_flag=True,
)

gene_z, cell_z, node_features, reconstructed = scNET.load_embeddings(
    "scnet_example"
)
  1. node_features의 gene/cell 순서를 출력과 맞춘다. Cell split 경로는 마지막 불완전 batch를 버리는 drop_last=True를 사용하므로, 입력 cell 수와 출력 cell 수가 같은지 확인한다. Model output에서 새 AnnData를 만들 때 metadata를 단순 위치로 붙이기 전에 identifier 대응을 확인한다.
  2. Gene 관계가 목적이면 gene_z로 coembedded network를, cell 구분이 목적이면 cell_z로 neighbor graph와 clustering을 만든다. Reconstructed expression의 marker/pathway 해석과 원래 counts 기반 검증을 함께 설계한다.

도움이 되는 저자 notebook: batch integration, gene inference, GO prediction, CD8 subsets. 대규모 subsampling notebook은 README가 beta라고 표시하므로 논문 Methods의 cell-split 경로와 구분한다.
