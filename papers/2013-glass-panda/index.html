PANDA (2013 Glass)

Passing Messages between Biological Networks to Refine Predicted Interactions — Glass et al.

Motif, PPI, co-expression의 서로 다른 근거를 message passing으로 조정해 condition-specific TF–gene network를 추정한다.

모델식·설정값·손계산 예시는 2013 Glass - PANDA (Pipeline)에 있다.

Background

Motif가 있다고 실제 binding이 일어나는 것은 아니며, TF와 target의 발현이 함께 움직이지 않아도 regulation은 가능하다. PANDA는 개별 TF–target correlation 대신 TF의 협력자와 target들의 neighborhood가 서로 맞는지를 묻는다. 원 논문은 single-cell 연구가 아니라 yeast bulk expression을 이용한 방법 검증이다.

Figure 1 · Three networks, one consensus

Context · 서로 다른 data는 같은 regulation을 부분적으로 관찰한다. 세 graph를 함께 움직여 모순을 줄이는 기본 구조를 먼저 본다.

Figure: Glass et al., PLoS ONE (2013) · CC BY

A · Message-passing framework

  • 목적: 서로 다른 종류의 관계를 어떤 graph로 표현하는가?
  • Data & method: 개념적 effector–target graph와 세 edge type을 정의한다 (Pipeline).
  • 그림 읽기: Node 종류와 세 edge 종류를 구분한다.
  • 결과와 의미: Cooperation, influence, co-affection을 별도 network로 갖고 같은 구조에 연결한다.

B · PANDA instantiation

  • 목적: 이 틀을 TF regulation에 어떻게 적용하는가?
  • Data & method: Motif W, PPI P, expression correlation C를 반복적으로 갱신한다 (Pipeline).
  • 그림 읽기: TF–gene W를 중심으로 P와 C가 message를 주고받는 방향을 본다.
  • 결과와 의미: 한 network의 이웃 정보가 다른 network의 edge weight를 정제한다.

Takeaway · Co-expression은 TF–target 직접 상관이 아니라 target–target 근거로 들어간다.

Figure 2 · Network recovery and robustness

Context · Network가 수렴하는 것과 biological truth에 가까워지는 것은 다르다. 독립적인 validation 기준과 input noise를 이용해 이 차이를 평가한다.

Figure: Glass et al., PLoS ONE (2013) · CC BY

A · Convergence and binding accuracy

  • 목적: 반복할수록 TF–gene prediction이 개선되는가?
  • Data & method: Perturbation expression 기반 PANDA를 ChIP-chip gold standard로 평가한다 (Pipeline).
  • 그림 읽기: Iteration별 AUC와 random 0.5, motif prior 0.687 기준선을 비교한다.
  • 결과와 의미: 전체 AUC는 0.687에서 0.725로 증가하며 특히 motif-supported false positives의 재순위화가 기여한다.

B · Noisy motif prior

  • 목적: 잘못된 prior에서도 signal을 회복하는가?
  • Data & method: Degree를 유지한 motif edge swaps 후 10 randomizations별 성능을 비교한다 (Pipeline).
  • 그림 읽기: Prior randomization 정도에 따른 최종 AUC를 읽는다.
  • 결과와 의미: 완전 randomization에서도 약 0.55지만 accurate prior보다 낮아 prior 품질의 중요성을 보여 준다.

C · All three networks

  • 목적: P와 C도 정제되는가?
  • Data & method: 10% TF·gene 제거 jackknife 100회로 세 network의 초기·최종 AUC를 비교한다 (Pipeline).
  • 그림 읽기: Network 종류별 paired initial/final estimates를 비교한다.
  • 결과와 의미: PPI AUC 0.611→0.692, co-regulation 0.548→0.590으로 개선되지만 각각의 validation 기준은 다르다.

Takeaway · 합의는 gold standard에서 실제 개선으로 이어졌지만 edge weight는 probability가 아니다.

Figure 3 · Benchmark and condition specificity

Context · 같은 motif prior를 가진 방법도 integration 방식에 따라 달라질 수 있다. 성능과 condition-specific biological meaning을 함께 비교한다.

Figure: Glass et al., PLoS ONE (2013) · CC BY

A · Overall AUC

  • 목적: 다른 reconstruction 방법보다 나은가?
  • Data & method: 세 expression datasets에 PANDA, SEREND, ReMoDiscovery, CLR, C3Net을 적용한다 (Pipeline).
  • 그림 읽기: 색은 knockout·cell cycle·stress, 별표는 motif input 사용을 뜻한다.
  • 결과와 의미: PANDA는 세 조건에서 약 0.72 AUC를 보이나 expression-only 방법과 input 정보량이 다르다.

B · Fixed-specificity performance

  • 목적: False positives를 제한해도 유리한가?
  • Data & method: ChIP-chip 기준 specificity 90%에서 sensitivity·precision을 계산한다 (Pipeline).
  • 그림 읽기: 두 지표를 분리해 높을수록 좋은지 확인한다.
  • 결과와 의미: PANDA sensitivity 36–39%, precision 13–14%로 보고되어 높은 AUC와 별개로 top predictions의 실험 확인이 필요하다.

C · PANDA overlap

  • 목적: 공통 regulation과 조건 특이성을 함께 보존하는가?
  • Data & method: 조건별 top 1,000 PANDA edges의 교집합을 계산한다 (Pipeline).
  • 그림 읽기: Venn 영역은 edge 수이며 gene 수가 아니다.
  • 결과와 의미: 공통 backbone과 condition-unique subsets가 함께 남는다.

D · SEREND overlap

  • 목적: 같은 motif input을 쓰는 방법의 overlap은 어떤가?
  • Data & method: SEREND의 조건별 top 1,000 edges를 비교한다 (Pipeline).
  • 그림 읽기: C와 동일한 selection 크기에서 overlap 구조를 비교한다.
  • 결과와 의미: PANDA보다 공통 edges가 적지만 그 자체만으로 biological quality를 결정할 수는 없다.

E · CLR overlap

  • 목적: Expression-only 결과는 조건 간 얼마나 겹치는가?
  • Data & method: CLR의 조건별 top 1,000 edges를 비교한다 (Pipeline).
  • 그림 읽기: C–D와 edge selection 기준은 같고 input modality는 다르다.
  • 결과와 의미: 공통 edges가 매우 적어 expression condition 의존성이 크다.

F · PANDA functional enrichment

  • 목적: Unique edges가 알려진 condition biology를 담는가?
  • Data & method: Unique-edge genes를 DAVID로 분석하고 2,555 genes를 background로 둔다 (Pipeline).
  • 그림 읽기: BH FDR<10⁻⁵ 및 gene-set member ≥10% 조건의 GO terms를 읽는다.
  • 결과와 의미: Cell-cycle·stress network가 해당 condition 관련 기능을 포착한다.

G · CLR functional enrichment

  • 목적: 대조 방법에서도 같은 기능적 특이성을 얻는가?
  • Data & method: CLR unique-edge genes에 같은 enrichment 기준을 적용한다 (Pipeline).
  • 그림 읽기: F와 같은 cutoff의 terms만 비교한다.
  • 결과와 의미: Stress 관련 일부 broad terms만 남고 SEREND는 이 기준에서 유의한 term이 없었다.

Takeaway · 정확한 edge ranking과 condition-specific function은 서로 보완하는 평가다.

Figure 4 · Condition-specific modules

Context · Global score만으로 어떤 regulator가 중요한지 알 수 없다. 조건 특이적 edges 비중이 높은 TF와 gene을 골라 expression과 network를 함께 확인한다.

Figure: Glass et al., PLoS ONE (2013) · CC BY

A · Expression and function

  • 목적: 선택한 genes가 해당 condition에서 일관된 expression을 보이는가?
  • Data & method: Condition-specific connectivity로 선택한 genes의 두 expression datasets를 row Z-score로 표시한다 (Pipeline).
  • 그림 읽기: TF는 bold이고 heatmap의 비교 단위는 각 gene 내 상대 발현이다.
  • 결과와 의미: Cell-cycle·stress modules는 관련 expression patterns를 보이지만 MBP1·SUT1은 target과 직접 co-expression하지 않아도 포착된다.

B · Cell-cycle module

  • 목적: Cell-cycle regulatory structure는 무엇인가?
  • Data & method: Selected genes 사이 W edges와 top 10% P/C edges를 시각화한다 (Pipeline).
  • 그림 읽기: TF–TF, TF–gene, gene–gene edge 종류를 구분한다.
  • 결과와 의미: MBP1–SWI6와 cell-cycle targets가 연결되어 cooperative structure를 제안한다.

C · Stress module

  • 목적: Stress response에서 어떤 구조가 달라지는가?
  • Data & method: Stress network에 동일한 module selection을 적용한다 (Pipeline).
  • 그림 읽기: B와 색·edge 유형을 맞추되 condition별 selection임을 기억한다.
  • 결과와 의미: MSN4, SUT1, ADR1 주변의 inferred cooperation은 직접 physical interaction의 확정이 아니다.

Takeaway · TF expression과 target expression의 불일치가 곧 regulation 부재는 아니다.

Figure 5 · Integrated condition-specific network

Context · 선택된 module을 전체 graph에 다시 놓으면 조건 간 공유와 연결을 볼 수 있다. 공통 edges를 제외하여 condition-dependent structure를 강조한다.

Figure: Glass et al., PLoS ONE (2013) · CC BY

Network · Global organization

  • 목적: 조건별 modules가 전체 network에서 어떻게 연결되는가?
  • Data & method: 세 조건의 top-edge union에서 세 network 모두에 공통인 edges를 제외한다 (Pipeline).
  • 그림 읽기: Magenta는 cell cycle, yellow는 stress, cyan은 perturbation이며 labeled TF 주변을 본다.
  • 결과와 의미: MBP1·MSN4 주변은 조건별 cluster를 보이고 perturbation-specific edges는 더 넓게 분산된다.

Takeaway · 이 그림은 whole-cell causal wiring diagram이 아니라 선택된 condition-specific predictions의 지도다.

Limitations

  • Message passing은 heuristic이며 calibrated probability 또는 activation/repression sign을 주지 않는다.
  • Yeast 53 TF·2,555 genes subset과 불완전한 ChIP-chip gold standard에서 평가되었다.
  • Co-expression=co-regulation, PPI=cooperation은 유용하지만 불완전한 가정이다.
  • Motif·ChIP 자료가 같은 연구실에서 나왔으므로 filtering을 분리해도 완전한 independence가 보장되지는 않는다.
  • α와 diagonal annealing에 결과가 의존한다; original parameters와 후속 패키지 기본값을 구분한다.
