Step 1 · Counts and design

Action

Cell annotations를 sample별로 집계하고 관심 조건과 adjustment covariates를 design matrix로 만든다.

Input → Output

Cell-level annotation + sample IDs + metadata → Y∈NN×KY\in\mathbb N^{N\times K}Y∈NN×K, X∈RN×MX\in\mathbb R^{N\times M}X∈RN×M, ni=∑kYikn_i=\sum_kY_{ik}ni​=∑k​Yik​.

Intuition

세포를 각각 환자로 취급하지 않는다. 각 sample이 ‘어떤 cell types를 몇 개 포획했는지’라는 하나의 구성표를 제출한다.

Details

NNN은 samples, KKK는 cell types, MMM은 covariates 수다. Count는 library-normalized gene counts가 아니다. Cell-level normalization·clustering은 labels를 만드는 upstream 과정이며 이후 표에 들어가는 것은 cell 수다. Reference는 cell-type axis에서, disease contrast는 sample covariate axis에서 정한다.

Original analysis preprocessing:

  • Supercentenarian: log expression, PCA 50 PCs, Leiden clustering, marker annotation; Scanpy 1.5.1.
  • AD: GSE98969 37,248 cells 출발, ERCC 제외, <500 UMI cells 12,053개와 unexpressed genes 11,065개 제외; library target 10,000, log1p; six-month subset 9,196 cells; Louvain resolution 1, region-labeled cells에 kNN k=30.
  • UC: 원 51 annotations에서 Epi 내 non-epithelial cells, LP 내 epithelial cells를 각각 하나로 묶어 Epi 16 / LP 37 groups를 분석했다.

Step 2 · Reference selection

Action

Reference cell type을 정하고 그 type의 covariate effects를 0으로 고정한다.

Input → Output

YYY, biological prior knowledge → reference index rrr, constraint βmr=0\beta_{mr}=0βmr​=0.

Intuition

높이가 바뀌는 지형에서 어느 곳을 기준 해발 0으로 둘지 정한다. 기준점 자체가 움직이면 모든 상대 높이의 해석이 달라진다.

Details

Known stable type이 있으면 manually 지정한다. Automatic rule은 relative abundance Yik′=Yik/niY'_{ik}=Y_{ik}/n_iYik′​=Yik​/ni​의 dispersion이 작고 samples 대부분에서 관측되는 type을 고른다:

r=arg⁡min⁡kDisp⁡(Y⋅k′)s.t.#{i:Yik>0}N≥t.r=\underset{k}{\arg\min}\operatorname{Disp}(Y'_{\cdot k})\quad\text{s.t.}\quad\frac{\#\{i:Y_{ik}>0\}}{N}\ge t. r=kargmin​Disp(Y⋅k′​)s.t.N#{i:Yik​>0}​≥t.

Recommended t=.95t=.95t=.95. Main paper는 Disp의 구체적 convention을 생략하지만 publication-linked v0.1.6 source는 population variance/mean을 사용한다(아래 audit). 이는 CV나 CV²가 아니다. Rare, mostly-zero type이 자동 reference가 되는 것을 prevalence constraint가 방지한다.

ϕik=eαk+Xiβk\phi_{ik}=e^{\alpha_k+X_i\beta_k}ϕik​=eαk​+Xi​βk​이고 pik=ϕik/∑lϕilp_{ik}=\phi_{ik}/\sum_l\phi_{il}pik​=ϕik​/∑l​ϕil​이므로 한 binary covariate에서

(pk/pr)case(pk/pr)control=eβk.\frac{(p_k/p_r)_{case}}{(p_k/p_r)_{control}}=e^{\beta_k}. (pk​/pr​)control​(pk​/pr​)case​​=eβk​.

이는 reference-relative ratio fold change이며 각 type의 absolute fold change가 아니다.

Step 3 · Likelihood and priors

Action

한 sample의 모든 cell counts를 joint model로 설명하고 unnecessary effects를 0 근처로 수축한다.

Input → Output

Y,X,rY,X,rY,X,r → likelihood, hierarchical priors, posterior target.

Intuition

한 type의 비율이 커지면 다른 type의 몫이 줄어드는 ‘한 상자 안의 자리 배분’을 함께 모델링한다. 많은 effect 후보 중 필요한 것만 열어 두는 gate도 둔다.

Details

pi∼Dirichlet⁡(ϕi),Yi∣pi∼Multinomial⁡(ni,pi),log⁡ϕi=α+Xiβ.p_i\sim\operatorname{Dirichlet}(\phi_i),\quad Y_i\mid p_i\sim\operatorname{Multinomial}(n_i,p_i),\quad \log\phi_i=\alpha+X_i\beta.pi​∼Dirichlet(ϕi​),Yi​∣pi​∼Multinomial(ni​,pi​),logϕi​=α+Xi​β.

두 분포를 합치면 Dirichlet-multinomial이다. ϕi0=∑kϕik\phi_{i0}=\sum_k\phi_{ik}ϕi0​=∑k​ϕik​라 할 때 (분포의 일반 성질)

E[Yik]=niϕikϕi0,Var⁡(Yik)=nipik(1−pik)ni+ϕi01+ϕi0.E[Y_{ik}]=n_i\frac{\phi_{ik}}{\phi_{i0}},\qquad \operatorname{Var}(Y_{ik})=n_ip_{ik}(1-p_{ik})\frac{n_i+\phi_{i0}}{1+\phi_{i0}}.E[Yik​]=ni​ϕi0​ϕik​​,Var(Yik​)=ni​pik​(1−pik​)1+ϕi0​ni​+ϕi0​​.

Step 4 · Posterior inference

Action

HMC로 posterior samples를 얻고 chain behavior를 검사한다.

Input → Output

Likelihood + priors → retained posterior draws of α,β,τ,σ2,γ\alpha,\beta,\tau,\sigma^2,\gammaα,β,τ,σ2,γ.

Intuition

최적 parameter 한 점만 찾는 대신 data와 prior에 비춰 가능한 parameter들의 분포를 탐색한다.

Details

p(Θ∣Y,X)∝p(Y∣X,Θ)p(Θ).p(\Theta\mid Y,X)\propto p(Y\mid X,\Theta)p(\Theta). p(Θ∣Y,X)∝p(Y∣X,Θ)p(Θ).

HMC의 일반 원리는 potential U(Θ)=−log⁡p(Θ∣Y,X)U(\Theta)=-\log p(\Theta\mid Y,X)U(Θ)=−logp(Θ∣Y,X)와 momentum을 이용한 leapfrog trajectory다. 이 설명은 일반 지식이며 논문은 ten leapfrog steps/iteration과 automatic step-size adjustment를 사용한다.

Step 5 · Inclusion and FDR

Action

Posterior draws의 effect inclusion을 집계하고 expected false-discovery fraction을 제한한다.

Input → Output

Retained effect draws → inclusion probabilities, credible effect set, conditional effect estimates / HDIs.

Intuition

‘선택한 후보들이 틀릴 가능성’을 평균해 허용한 수준 이내가 되는 가장 큰 후보 집합을 찾는다. p-value의 BH procedure와 같지 않다.

Details

Original Eq.10:

Pj=1H∑h=1H1(∣βjh∣≥10−3).P_j=\frac1H\sum_{h=1}^{H}\mathbf1(|\beta_{jh}|\ge10^{-3}). Pj​=H1​h=1∑H​1(∣βjh​∣≥10−3).

jjj는 covariate–cell-type pair이다. Local error proxy qj=1−Pjq_j=1-P_jqj​=1−Pj​를 오름차순 정렬한 뒤,

FDR^(J)=1∣J∣∑j∈Jqj\widehat{\mathrm{FDR}}(J)=\frac1{|J|}\sum_{j\in J}q_j FDR(J)=∣J∣1​j∈J∑​qj​

가 원하는 αFDR\alpha_{FDR}αFDR​를 넘지 않는 가장 큰 prefix를 고르는 것으로 계산 원리를 설명할 수 있다. 이는 원문의 ‘가능한 많은 effects를 선택’한다는 문장과 Eq.11을 일관되게 해석한 것이며, 원 Eq.12 표기 불일치는 아래 audit에 남긴다. Synthetic headline comparison은 FDR=.05, 주요 real-data 예는 .2이며 .2는 .05보다 느슨하다.

Credible effects는 included posterior draws에서의 mean을 보고하고 conditional HDI도 zero-component를 제외해 계산한다. 전체 mixture HDI와 ‘포함되었다고 가정한’ HDI는 다른 불확실성이다. HDI가 zero를 포함하는지 여부만으로 spike-and-slab selection을 대체하지 않는다.

Toy example

숫자는 설명용. Posterior inclusion probabilities가 (.99,.95,.80,.40)이면 local errors는 (.01,.05,.20,.60)이다. 첫 1/2/3/4개 누적 expected FDR는 .01/.03/.086667/.215다. Target=.10이면 앞 3개를 선택한다. 15,000 draws 중 12,000개가 |β|≥.001이면 inclusion=.8이다. 이것은 β=.8이라는 뜻이 아니다.

Step 6 · Benchmark design

Action

Known truth simulations와 기존 biological validation을 나누어 성능을 점검한다.

Input → Output

Generation parameter grid / real annotated datasets → MCC, TPR, FDR, ROC/AP, power·heterogeneity analysis.

Intuition

정답을 아는 연습문제에서는 false positives를 직접 셀 수 있다. 실제 data에서는 외부 실험 근거와 sensitivity checks가 그 역할을 보완한다.

Details

Generation은 fitted DM model과 동일하지 않다:

zi∼N(μi,.05IK),pi=softmax⁡(zi),Yi∼Multinomial⁡(ni,pi).z_i\sim N(\mu_i,.05I_K),\quad p_i=\operatorname{softmax}(z_i),\quad Y_i\sim\operatorname{Multinomial}(n_i,p_i). zi​∼N(μi​,.05IK​),pi​=softmax(zi​),Yi​∼Multinomial(ni​,pi​).

즉 logistic-normal multinomial simulation이다. Last cell type을 reference로 삼았다.

Source-code audit

Publication-linked scCODA v0.1.6 tag의 commit 5ee943f56f15b020c35fbb71a0ed83af50f607ae를 읽었다. 이 package snapshot의 구현을 모든 original experiment의 실행 설정이라고 단정하지 않는다.

  • comp_ana.py L33–94: relative abundances의 np.var(...)/np.mean(...), 즉 population variance/mean으로 Disp를 계산한다. Automatic absence threshold=.05, eligibility는 zero_fraction < .05라 presence >.95다. Paper의 ≥.95 및 docstring의 ‘at least90%’와 다르다. Reference selection은 zero pseudocount를 넣기 전 raw cell-count table에서 한다.
  • 같은 code는 eligible candidates의 minimum Disp를 구한 후 전체 vector에서 그 minimum과 같은 첫 index를 찾는다. Ineligible candidate와 exact tie가 나면 별도 확인이 필요한 작은 implementation caveat가 있다.
  • result_classes.py L243–280: PIP와 included mean은 ∣β∣>10−3|\beta|>10^{-3}∣β∣>10−3인 draws로 계산한다. Unique positive PIP cutoffs를 오름차순 순회하여 mean⁡(1−Pj:Pj≥c)<αFDR\operatorname{mean}(1-P_j:P_j\ge c)<\alpha_{FDR}mean(1−Pj​:Pj​≥c)<αFDR​를 처음 만족하는 cutoff를 고른다. 여기서 c는 PIP cutoff이므로 낮을수록 많은 effects가 들어간다; main Eq11의 error cutoff c와 방향이 다르다.
  • Return 전 cutoff를 floor(c*1000)/1000으로 내린다. 옆 comment의 ‘ceiling’과 다르며 rounding 후 FDR를 이 function에서 다시 계산하지 않아 경계 PIP가 추가될 가능성이 있다. None passes이면 threshold1.0으로 fallback한다.
  • result_classes.py L175–183: HDI는 gate ind >= 1e-3인 draws에서 b_raw*ind로 계산한다. 이는 PIP의 ∣β∣>.001|\beta|>.001∣β∣>.001 criterion과 다른 selection rule이다.
  • scCODA_model.py L648–688: half-Cauchy sigma_d를 standard-normal b_offset에 곱하고 logistic gate를 적용한다. α prior는 Normal scale=5이므로 SD5다. Paper의 σ² 기호를 code에서 한 번 더 제곱하지 않는다.
  • Zero handling L90–100: zero entries만 .5로 바꾼다.

실제 TensorFlow/HMC 실행이나 원 reproducibility repository의 전체 simulation-grid 재구성은 수행하지 않았다. 따라서 5,000 vs1,800 discrepancy와 모든 figure의 exact package-runtime provenance는 남는다.

Run it yourself

Original source, reproducibility repository, simulation deposit.

Original software stack는 Python 3.8, TensorFlow 2.3.2, TensorFlow Probability .11, ArviZ≥.10, NumPy≥1.19, Scanpy≥1.5; power analysis는 R4.1/caret이다. 최신 package API와 동일하다고 가정하지 말고 논문 version을 별도 환경에 고정한다.

실행 전 checks: sample IDs와 donors를 분리하고 design의 confounding/rank를 점검 → counts 합과 zero rates 확인 → stable references 비교 → posterior trace·mixing 확인 → prespecified FDR의 credible set과 conditional intervals 기록. 이번 작업에서 full HMC benchmark는 실행하지 않았다.
