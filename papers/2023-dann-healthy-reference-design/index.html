Healthy Reference Design (Dann 2023)

Precise identification of cell states altered in disease using healthy single-cell references — Dann et al.

Disease data를 healthy reference와 비교할 때, embedding은 큰 healthy atlas로 학습하고 differential analysis는 cohort가 맞는 control로 하는 ACR design이 disease-specific cell state를 비교한 benchmark에서 더 안정적으로 찾는다. False positive가 없어지는 보장은 아니다.

Background

  • Latent embedding 단계에는 크고 다양한 healthy atlas가 유리하다.
  • Differential analysis(disease vs healthy) 단계에는 disease cohort와 특성이 맞는 control이 적합하다.
  • 이 논문은 두 역할을 나눈 design을 시뮬레이션과 실제 data로 검증한다.

OOR는 새로 실험 측정한 disease cell이 아니라 annotation된 population을 reference에서 제거해 만든 label이다. 실제 disease signature는 biological ground truth 전체가 아니다.

Figure 1 · Reference designs

Context · Atlas는 embedding을 잘 학습하게 하지만 disease와 직접 비교할 control 역할까지 자동으로 충족하지 않는다. 먼저 두 reference의 목적을 나눈다.

Panel observations

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0 분석은 세 단계다 (Fig. 1b).

  1. Embedding reference · Healthy data로 scVI 같은 차원 축소 model을 학습한다. Phenotype 구조는 보존하고 batch 같은 기술적 변이는 줄인다.
  2. Query mapping · Disease가 포함된 query를 scArches로 학습된 model에 mapping한다. Healthy와 disease가 같은 latent space에 놓인다.
  3. Differential analysis reference · 같은 공간에서 disease vs healthy를 비교해 disease-associated state를 찾는다.
Design Embedding Differential analysis
AR (atlas reference) Atlas Atlas
CR scArches (control reference) Control로 학습, disease는 query mapping Control
CR scVI Control + disease joint embedding Control
ACR (atlas → control reference) Atlas로 학습, disease와 control을 mapping Control
  • Control = 인구학적 특성과 실험 protocol이 disease cohort와 맞는 healthy sample.
  • Atlas = 여러 cohort와 protocol에서 모은 수백–수천 명 규모의 healthy data.

Context · Design을 평가하려면 실제 정답을 아는 예제가 필요하다. Healthy cohort 일부 population을 숨겨 OOR benchmark를 만든다.

Panel observations

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0

  • Data · 실제 healthy PBMC scRNA-seq 13개 study, donor 1,248명. 한 study의 donor를 무작위로 나눠 pseudo-disease와 control을 만든다. 같은 study라 cohort와 protocol이 완전히 같고, donor effect와 library effect 같은 실제 특성은 남는다. 나머지 12개 study(donor 1,219명)가 atlas다.
  • OOR state · Annotation된 cell type 일부를 control과 atlas에서 지우고 pseudo-disease에만 남긴다. "Healthy reference에는 없고 disease에만 있는" population이다.
  • Pipeline · (1) 선택한 reference로 scVI latent space 학습, (2) scArches로 pseudo-disease(+ control, 필요 시 atlas) mapping (CR scVI는 처음부터 함께 학습), (3) Milo로 neighborhood 단위 DA.
  • ACR에서 atlas는 latent model 학습에만 쓰이고, mapping 뒤 DA에는 disease와 control만 쓴다.
  • Milo의 spatial FDR · Neighborhood끼리 cell을 공유하고 graph상 이웃해 있어 독립이 아니다. 일반 Benjamini–Hochberg는 이를 무시하므로, Milo는 neighborhood의 겹침을 반영해 각 test의 가중치를 조정한 spatial FDR을 쓴다.

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0

  • Design 간 integration quality(batch correction, embedding 품질)는 비슷했다 (Extended Data Fig. 2). UMAP에서 잘 섞여 보여도 disease state 검출 성능은 같지 않다.

Figure 3 · Detection of simulated OOR states

Context · 간단한 OOR 하나에서 잘 되는 design이 복합적인 disease에서도 잘 될지는 별개다. Feature selection과 mixed OOR를 추가해 비교한다.

Panel observations

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0

  • 점 = 서로 다른 OOR state 8개의 simulation (split 후 OOR cell이 250개 미만인 경우 제외). 같은 data의 test는 선으로 연결.
  • a, b · Single OOR state
    • ACR · OOR cell 비율이 높은 neighborhood를 가장 민감하게 잡고 FDR도 낮았다.
    • AR · OOR cell이 거의 없는 neighborhood에서도 유의하게 나오는 false positive가 많았다.
    • CR scArches · logFC 분포는 균형적이지만 FDR이 ACR보다 높았다.
    • CR scVI · ACR과 거의 비슷하게 좋았다.
    • logFC 크기로 순위를 매길 때의 AUPRC로도 ACR과 CR joint가 좋았다.
  • c · HVG 선택의 영향 · 가설: CR scVI가 좋은 이유는 control + disease에서 HVG(top 5,000)를 뽑아 OOR marker가 포함됐기 때문일 수 있다. HVG를 atlas만 / control만 / control + disease에서 뽑아 비교했다.
    • 모든 design에서 latent model을 학습한 그 data에서 HVG를 뽑을 때 가장 좋았다.
    • CR scVI만 disease를 빼고 HVG를 뽑으면 성능이 크게 떨어졌다. Control + disease HVG와의 겹침은 control-only 평균 81%, atlas-only 평균 68%였다.
    • CR joint embedding은 disease를 feature selection에 넣느냐에 특히 민감하다.
  • d–f · Mixed OOR states (더 현실적인 상황)
    • Fixed OOR: classical monocyte를 atlas와 control에서 모두 제거.
    • Shifted OOR: 한 cell type을 발현으로 두 group으로 나누고 하나만 atlas와 control에서 제거. 같은 cell type 안에서 일부만 reference에 없는 상태다.
    • 전체 mixed OOR 검출은 ACR이 가장 좋았다 (e). Single OOR에서 CR scVI가 ACR보다 나았던 simulation에서도, mixed로 바꾸면 ACR이 shifted state를 더 잘 잡았다 (f 오른쪽, 빨간 점선 상자). 예외로 CD4+ Tcm을 shifted OOR로 쓴 경우 ACR 성능이 떨어졌다.
    • f · 막대 = AUPRC, error bar = bootstrap 1,000회 95% CI.

Takeaway · Control로 DA를 하면 false discovery가 크게 줄고, ACR이 single과 mixed OOR 모두에서 가장 안정적이다. CR scVI는 HVG 선택에 민감하고 복잡한 상황에서 덜 robust하다.

Figure 4 · Robustness of the ACR design

Context · Atlas가 커도 matched control이 적으면 inference는 약해질 수 있다. Control 수와 atlas 구성을 각각 바꾸어 robustness를 확인한다.

Panel reading guide

  • 목적: Sample 수 변화에 design 성능이 얼마나 민감한지 본다.
  • Data & method: Control donor subsampling 및 atlas-study subsampling을 반복한다. 2023 Dann - Healthy Reference Design (Pipeline) › Step 4 · Validation
  • 그림 읽기: A는 control 수, B는 atlas 규모별 AUPRC 변화다.
  • 결과와 의미: ACR도 control 부족의 영향을 받으므로 atlas가 biological replication을 대신하지 않는다.

Panel observations

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0

  • a · Control 수 · Control donor를 3–11명으로 바꿔 봤다. Control이 작아지면 모든 design의 sensitivity가 떨어지지만, ACR이 항상 CR 두 가지보다 AUPRC가 높았다 (t-test P < 0.01). Disease cohort까지 작으면 CR이 더 나빠졌다 (Supplementary Fig. 1). Matched control을 많이 모으기 어려운 현실에서 ACR이 유리하다.
  • b · Atlas 크기 · Atlas에 넣는 study 수를 늘려 가며 비교했다. Study 하나를 빼도 크게 무너지지 않았다 (Supplementary Note 2.2.1). Atlas가 10,000 cells 이상이면 ACR의 AUPRC는 거의 안정적이었다. AR은 atlas 크기에 훨씬 크게 의존했다 (AUPRC vs atlas cell 수: AR R² = 0.69, P = 7.2×10⁻⁷, ACR R² = 0.4, P = 0.0017). Atlas가 작을수록 AR의 FPR이 늘었다 (Supplementary Fig. 2).
  • Tissue-specific atlas가 없을 때 cross-tissue atlas를 쓰는 대안도 검토했다 (Supplementary Note 2.2.2).
  • Extended Data Fig. 4 · 어느 방법이든 OOR cell이 cell type당 약 250개 이상은 있어야 안정적으로 잡혔다.

Figure 5 · COVID-19 cell states with a healthy atlas

Context · Simulation의 제거된 label은 실제 disease의 다양성을 완전히 재현하지 않는다. COVID-19에서 알려진 IFN response와 severity 연관 state를 확인한다.

  • 목적: 실제 disease-associated state의 biological coherence를 평가한다.
  • Data & method: 실측 COVID/control RNA에서 Milo DA와 계산한 IFN score 및 monocyte pseudobulk를 비교한다. 2023 Dann - Healthy Reference Design (Pipeline) › Step 4 · Validation
  • 그림 읽기: B–D는 score와 DA의 agreement, E–G는 monocyte state와 severity별 fraction이다.
  • 결과와 의미: IFN signature는 평가 proxy이며 IFN-low disease state도 존재한다.

Panel observations

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0

  • Data · COVID-19 PBMC 90명(여러 중증도), 같은 연구의 matched healthy control 23명, healthy PBMC atlas 12개 study 1,219명 (513k cells).
  • CR(COVID + control joint scVI) vs ACR(atlas로 학습, COVID와 control mapping, COVID vs control로 Milo).
  • 평가 · COVID-19의 대표 반응인 interferon(IFN) signature가 높은 neighborhood를 정답으로 보고, Milo가 COVID-enriched로 고른 neighborhood와 얼마나 맞는지 봤다.
  • b–d · Neighborhood DA logFC와 평균 IFN signature의 상관: ACR R = 0.63, CR R = 0.52 (Fisher z P < 2.2×10⁻¹⁶). Embedding 전략을 바꿔도 ACR의 AUPRC가 항상 높았다 (d).
    • Cell type별로는 IFN이 가장 높은 myeloid에서 상관이 강했다. ACR은 NK와 CD8+ T의 IFN-high 상위 10% neighborhood를 CR보다 잘 잡았고, CD4+ T와 B cell에서는 두 design 모두 뚜렷이 못 나눴다 (Extended Data Fig. 5).
    • CR은 IFN-high NK subset보다 IFN-low naive B cell을 DA로 우선시했다. COVID-19의 lymphopenia(특히 naive B 감소)와 맞지 않는 결과다.
  • e–g · CD14+ monocyte · IFN signature는 낮은데 COVID에서 유의하게 늘어난 neighborhood도 있었다. 그래서 세 phenotype으로 나눴다: normal classical, COVID-associated IFN-low, COVID-associated IFN-high.
    • f · IFN score: IFN-high > IFN-low > normal.
    • g · 환자별 비율. Healthy 23, asymptomatic 9, mild 23, moderate 30, critical 15, severe 13. IFN-high CD14+는 mild/asymptomatic에서 가장 뚜렷하게 늘었고 (Wilcoxon P = 1.19×10⁻⁷), IFN-low CD14+는 moderate–critical에서 두드러졌다.
    • 해석: 초기·경증에서는 IFN 자극이 보호적으로 작용하고, 중증에서는 다른 병적 경로가 우세해진다는 기존 가설과 맞다.
  • Extended Data Fig. 6 · ACR의 IFN-high monocyte는 HLA(HLA-DR 등), CCL8, CXCL10, CXCL11, FCGR3A ↑ (활성화·항바이러스·면역 동원형). IFN-low는 S100A8/9 ↑로, 중증 COVID-19에서 보고된 HLA-DRlo S100Ahi 기능저하 monocyte와 같다. CR로 나누면 healthy와 asymptomatic에서도 IFN-low COVID-enriched 비율이 높게 나와 정상 monocyte와 병적 monocyte를 구분하지 못했고, IFN-high 비율도 mild/moderate vs severe에서 차이가 없었다 (P = 0.326).

Figure 6 · Cell states in idiopathic pulmonary fibrosis (IPF)

Context · PBMC에서 유리한 design이 다른 tissue에서도 유용한지 확인한다. IPF에서는 atlas와 cohort-matched comparison이 rare aberrant basal state를 분리하는지 본다.

  • 목적: IPF-specific state의 분리와 해석을 평가한다.
  • Data & method: HLCA mapping과 IPF/control Milo, 외부 fibrosis signature, donor-level pseudobulk를 사용한다. 2023 Dann - Healthy Reference Design (Pipeline) › Step 4 · Validation
  • 그림 읽기: B–C는 signature recovery, D는 marker heatmap, E–F는 basal states와 DE다.
  • 결과와 의미: KRT17-high aberrant basal과 basaloid는 동일한 state가 아니며 ACR가 이를 구분한다.

Panel observations

Figure: Dann et al., Nature Genetics (2023) · CC BY 4.0

  • Data · IPF 32명 (144k cells), control 28명, COPD 18명. Atlas = Human Lung Cell Atlas (HLCA) core (약 58만 cells).
  • b · SPP1+ profibrotic macrophage · Macrophage에서 profibrotic signature의 neighborhood 평균을 정답으로, Milo logFC를 score로 AUPRC. ACR이 AR, CR보다 가장 높았다. CR은 진짜 profibrotic state보다 donor 수가 적은 neighborhood를 우선시했다. Batch나 sample 구성의 잔여 효과로 보인다 (Supplementary Fig. 3).
  • c · IPF 진단 signature · IPF explant RNA-seq의 진단 signature를 stromal, epithelial cell에 투영. 거의 모든 cell type에서 ACR이 가장 높았고, 특히 basal cell에서 차이가 컸다. ACR은 정상 basal neighborhood(IPF와 control이 섞임)와 IPF-enriched aberrant basal neighborhood를 분명히 나눴다. 후자는 bronchial brushing에서 보고된 KRT5+ KRT17hi aberrant basal cell의 marker를 강하게 발현했다. CR과 AR은 이 phenotype을 따로 분리하지 못했다.
  • d · Basal neighborhood를 IPF vs control logFC 순으로 정렬하고, KRT17hi marker(Jaeger et al.)의 평균 발현을 heatmap으로 (min–max scaling). 위의 점: 색 = DA logFC, 크기 = spatial FDR. ACR(왼쪽)에서만 logFC가 높은 쪽에 KRT17hi signature가 몰렸다.

Limitations

  • Atlas에 control states가 포함되고 disease에서 일부 population만 변한다는 가정이 중요하다. 이를 벗어나는 tissue/cell loss에는 재검증이 필요하다.
  • Integration은 demographic/protocol confounding을 완전히 없애지 않는다; matched controls와 sample-level covariates가 필요하다.
  • Simulation은 annotation 제거로 만든 OOR이고 실제 disease는 continuous·multifactorial 변화다. IFN/fibrosis signatures도 절대적인 ground truth가 아니다.
  • 많은 neighborhood가 같은 cells를 공유하므로 test 수를 independent biological replicate 수로 해석하지 않는다.
