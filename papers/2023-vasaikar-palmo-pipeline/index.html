Step 1 · Input and preprocessing

Action · Feature matrix와 donor/time/sample metadata를 맞춘다.

Input → Output · Bulk feature × sample matrix 또는 Seurat object + annotation → PALMO S4 object와 분석 가능한 subsets.

Intuition · 사람·날짜·검사항목이 뒤섞인 장부를 먼저 같은 칸에 정리한다. Cell은 donor의 독립 replicate가 아니다.

Details

createPALMOobject(anndata, data)에서 anndata는 sample annotations이며 bulk data는 feature rows/sample columns, single-cell data는 Seurat object다. Matrix만 있으면 createPALMOfromsinglecellmatrix()를 사용한다. annotateMetadata()로 sample_column, donor_column, time_column을 지정하고 mergePALMOdata()는 이 essential annotation이 없는 data를 제거한다. checkReplicates()는 같은 donor-time의 replicate를 median으로 합치며 avgExpCalc()는 single-cell pseudobulk를 생성한다. naFilter()의 na_cutoff default는 0.4다.

Supplementary 3 caption은 RNA에서도 label score 0.5 filter를 명시하므로 기본 nFeature/mitochondrial filtering만으로 final data를 재현했다고 주장하지 않는다. Pseudobulk의 정확한 averaging slot·log transform은 software version/source를 실행 전에 확인한다; raw-count summation과 자동으로 동일시하지 않는다.

TCR input · 논문은 CDR3 peptide를 clonotype으로 정의하고 sample별 peptide reads / all peptide reads를 continuous 값으로 쓴다. 이는 binary presence보다 frequency 정보를 유지하지만 sequencing depth와 composition 영향을 제거한 것은 아니다.

Toy example

숫자는 설명용. Donor A day 1에서 technical replicates가 8,10,30이면 median=10이다. 같은 sample의 TCR CDR3 read가 20/100이면 frequency=0.2, 다음 timepoint가 30/200이면 0.15다. Raw reads는 늘어도 relative abundance는 줄어든다. NA fraction이 2/5=0.4라면 문서의 “above cutoff”를 엄격히 따르면 제거 대상은 아니지만 실제 equality 처리는 version-specific code로 확인한다.

Step 2 · VDA

Action · Feature별 variance를 random factors와 residual로 분리한다.

Input → Output · Continuous feature vector + covariates → factor별 variance/ICC.

Intuition · 관찰된 흔들림을 사람별 차이·cell type별 차이·설명되지 않은 차이로 나눈다.

Details

Y∼X1+⋯+Xm+(1∣F1)+⋯+(1∣Fn).Y\sim X_1+\cdots+X_m+(1\mid F_1)+\cdots+(1\mid F_n). Y∼X1​+⋯+Xm​+(1∣F1​)+⋯+(1∣Fn​).

YYY는 한 feature의 measurements, XjX_jXj​는 조정할 fixed effects, FiF_iFi​는 variance를 평가할 random grouping factor다. Fixed effects 없이 random terms만 사용할 수도 있다. lmeVariance()는 lme4로 variance components를 추정한다.

σtotal2=∑i=1nσi2+σR2,ICCi=σi2σtotal2.\sigma_{total}^{2}=\sum_{i=1}^{n}\sigma_i^2+\sigma_R^2,\qquad ICC_i=\frac{\sigma_i^2}{\sigma_{total}^{2}}. σtotal2​=i=1∑n​σi2​+σR2​,ICCi​=σtotal2​σi2​​.

이는 명시한 random effects와 residual의 분모이며 fixed-effect explanatory power까지 자동 포함한 R2R^2R2와 다르다. Donor/week/celltype를 random intercept로 넣는 것과 time을 continuous slope로 넣는 TCA는 다른 모델이다. Formula를 annotation의 실제 variable names로 구성하고 rank deficiency·confounding·singular fit을 점검한다(실행 점검은 일반적 권고).

Toy example

숫자는 설명용. Estimated variances가 donor=1, week=0.2, celltype=7, residual=1.8이면 total=10, ICC는 10%, 2%, 70%, 18%다. Celltype ICC 70%는 이 dataset·model에서의 variance fraction이지 70%의 cells가 해당 type이라는 뜻이 아니다.

Related figures · Figure 2, Supplementary 4–6. Missing values를 제거한 comparison에서 variancePartition과 거의 일치했다.

Step 3 · CVP

Action · 각 donor 안의 repeated bulk measurements에서 relative variability를 계산한다.

Input → Output · Donor-time protein/feature matrix → CV profiles와 consistently stable/variable sets.

Intuition · 평균 높이가 다른 signal의 흔들림을 평균 대비 비율로 비교한다.

Details

일반적 CV 정의를 설명용으로 쓰면

CVgd=100sgdxˉgd,sgd=∑t(xgdt−xˉgd)2Td−1.CV_{gd}=100\frac{s_{gd}}{\bar x_{gd}},\qquad s_{gd}=\sqrt{\frac{\sum_t(x_{gdt}-\bar x_{gd})^2}{T_d-1}}. CVgd​=100xˉgd​sgd​​,sgd​=Td​−1∑t​(xgdt​−xˉgd​)2​​.

g,d,tg,d,tg,d,t는 feature, donor, time이다. Sample SD 표기를 사용한 교육용 식이며 실제 함수의 missing handling을 실행 전 확인한다. Mean이 0 근처이면 CV는 불안정하고 negative/log-scale values에는 해석 주의가 필요하다.

Function / parameter Value / role
cvCalcBulkProfile() 전체 CV profile
cvCalcBulk() Stable/variable selection
cvThreshold Default 5%; CV < cutoff stable, > cutoff variable
donorThreshold Default total donors; 최소 일관된 donor 수
Paper Figure 3 Median across donors의 5% cutoff로 413 variable /629 stable 보고

Default donor-count rule과 Results의 median rule은 같은 criterion으로 단정하지 않는다. Dataset 재현 시 figure-specific code를 확인해야 한다.

Toy example

숫자는 설명용. [9,10,11]은 mean=10, sample SD=1, CV=10%. [99,100,101]은 같은 SD=1이지만 CV=1%. 같은 절대 변화가 다른 상대 stability로 분류된다. 첫 signal의 CV=10%는 threshold 5%에서는 variable이다.

설명 그림 (직접 작성). 왼쪽은 같은 SD·다른 mean의 CV, 오른쪽은 10시점 중 1개 outlier의 z-score 예다.

Related figures · Figure 3A–C, Supplementary 7.

Step 4 · SPECT

Action · Donor-cell type 조합마다 CV를 구하고 stability pattern을 분류한다.

Input → Output · Pseudobulk gene expression by donor/time/celltype → SUV/SUS/VATIC/STATIC sets.

Intuition · 누구에게나 조용한 gene과 특정 cell type에서만 조용한 gene을 나눈다.

Details

cvCalcSCProfile()는 donor-cell type별 CV, cvSCsampleprofile()은 cell types를 구별하지 않은 donor별 CV, cvCalcSC()는 cutoff-based state를 계산한다. VarFeatures() 및 StableFeatures()가 counts와 consistency를 이용해 class를 정한다.

Ngstable=∑d,c1[CVgdc<τ],Ngvariable=∑d,c1[CVgdc>τ].N^{stable}_{g}=\sum_{d,c}\mathbf1[CV_{gdc}<\tau],\qquad N^{variable}_{g}=\sum_{d,c}\mathbf1[CV_{gdc}>\tau]. Ngstable​=d,c∑​1[CVgdc​<τ],Ngvariable​=d,c∑​1[CVgdc​>τ].

Setting Paper analysis Generic default / caveat
CV threshold τ\tauτ 10%; ACTB/GAPDH의 observed CV 참고 Data-specific choice
Donor × celltype 4×19=76 Missing combination은 실제 사용 data 확인
SUV/SUS ≥40 combinations variable/stable Methods default groupThreshold=4×19/2=38와 구별
VATIC/STATIC <40 combinations이나 ≥1 cell type에서 모든 donors에 일관 서로 overlap 가능
Marker selection Cell type당 up to 25 top STATIC genes PBMC 220, mouse brain 304 unique genes

Toy example

숫자는 설명용. Donor 2명×cell type 3개에서 CV matrix가 [[4,20,30],[6,25,35]]%라고 하자. Cutoff 10%라면 type 1은 두 donor 모두 stable, type 2/3는 둘 모두 variable이다. Strict super-class cutoff를 예시용으로 5조합이라 두면 stable count=2, variable count=4라서 한 gene이 STATIC이면서 VATIC일 수 있다. 이 cutoff 5는 paper 값이 아니다.

Mouse brain은 time series가 아닌 age-group 내 replicate를 사용했다. SPECT는 time ordering을 쓰지 않기 때문에 계산은 가능하지만 within-mouse longitudinal inference는 아니다.

Step 5 · ODA

Action · 특정 timepoint에 outlier features가 예상보다 많은지 검사한다.

Input → Output · Donor별 feature trajectories → z-score/count/sample-level adjusted p.

Intuition · 검사 하나의 이상치보다 여러 검사가 같은 날 동시에 튀는지를 묻는다.

Details

sample_correlation()은 sample-pair correlation heatmap을 만든다. outlierDetect()는 donor 내 모든 timepoints로 feature별 mean/SD를 계산한다.

zgdt=xgdt−xˉgdsgd,Kdt=∑g1(∣zgdt∣>z0).z_{gdt}=\frac{x_{gdt}-\bar{x}_{gd}}{s_{gd}},\quad K_{dt}=\sum_g\mathbf1(|z_{gdt}|>z_0). zgdt​=sgd​xgdt​−xˉgd​​,Kdt​=g∑​1(∣zgdt​∣>z0​).

r=2{1−Φ(z0)},K∼Binomial⁡(G,r).r=2\{1-\Phi(z_0)\},\qquad K\sim\operatorname{Binomial}(G,r). r=2{1−Φ(z0​)},K∼Binomial(G,r).

outlierDetectP()는 binomial test와 BH correction을 수행하며 adjusted p<0.05를 abnormal timepoint로 표시한다. Paper z0=2.5z_0=2.5z0​=2.5, two-sided normal tail r≈1.24%r\approx1.24\%r≈1.24%; directional tail은 0.62%다. Count-tail의 exact two-sided p 구현은 코드 확인 없이 one-sided survival probability와 같다고 가정하지 않는다. Three timepoints에도 계산은 가능하나 논문은 작은 n에서 Dixon test 대안을 언급한다.

Toy example

숫자는 설명용. [10,10,10,10,10,10,10,10,10,20]의 mean=11, sample SD=10\sqrt{10}10​≈3.1623이다. 마지막 z≈2.8460으로 2.5를 넘는다. r=erfc⁡(2.5/2)=0.0124193r=\operatorname{erfc}(2.5/\sqrt2)=0.0124193r=erfc(2.5/2​)=0.0124193이면 G=1,042에서 기대 count=12.9409다. 원문 “19 proteins expected”와 다른 이유를 알 수 없으므로 실제 denominator를 확인해야 한다.

Related figures · Figure 3D–E, Supplementary 7B–D.

Step 6 · TCA

Action · Donor-cell type별 gene expression을 time으로 모델링한다.

Input → Output · Cell-level normalized expression + time + optional confounders → slope/logFC, LRT p, BH q.

Intuition · 시간순 곡선에 전체적으로 오르는 방향이 있는지 묻되, 발현 유무와 발현량을 나눈다.

Details

sclongitudinalDEG()는 MAST hurdle model을 사용한다. 일반적 hurdle 모델을 교육용으로 쓰면

logit⁡Pr⁡(Y>0)=αD+βDt+γDTz,\operatorname{logit}\Pr(Y>0)=\alpha_D+\beta_Dt+\gamma_D^Tz, logitPr(Y>0)=αD​+βD​t+γDT​z,

E[Y∣Y>0]=αC+βCt+γCTz.E[Y\mid Y>0]=\alpha_C+\beta_Ct+\gamma_C^Tz. E[Y∣Y>0]=αC​+βC​t+γCT​z.

zzz는 confounders, D/CD/CD/C는 detection/continuous components다. 이 두 식은 MAST 개념 설명이며 PALMO output의 단일 slope가 두 coefficient 중 무엇인지 논문이 별도로 명확히 쓰지 않았으므로 software output을 확인한다.

Setting Value
Analysis subsets 각 donor 및 cell type별 독립 분석
≥3 timepoints Time continuous; normalized expression linear time trend; LRT
2 timepoints MAST two-group DEG; fold change
adjfac Batch/sex/age 등 지정 confounders

한 donor 내 sex/age가 상수라면 조정 가능성은 design matrix에 달려 있다(일반적 모델 진단). Time unit을 day→week로 바꾸면 coefficient magnitude도 바뀌므로 0.1 threshold를 그대로 이동하지 않는다.

Toy example

숫자는 설명용. Days [0,2,4], expression [1,2,3]의 OLS slope는 0.5/day이고 week 단위라면 3.5/week다. 이는 slope 단위를 보이는 예일 뿐 MAST p-value를 재현하지 않는다. Detection 5/10→8/10의 변화는 positive expression 평균이 같아도 hurdle의 detection component가 포착할 수 있다.

Related figures · Figure 7, Supplementary 12.

Step 7 · Validation and visualization

Action · Stability-selected features를 다른 dataset·modality와 비교한다.

Input → Output · Gene set/CV/correlation → sUMAP, circos, enrichment, cross-modality concordance.

Intuition · Feature를 고른 같은 자료에서만 좋아 보이는지, 다른 측정에서도 정보가 남는지 묻는다.

Details

  • dimUMAPPlot()는 selected features를 이용한다. genecircosPlot()는 한 modality, multimodalView()는 두 modality의 CV를 표시한다.
  • RNA expression–ATAC gene score Pearson correlation은 14 celltypes×18 samples=252 observations에 대해 계산했다. Random gene pairing을 1,000회 shuffle하여 upper 95% bound 0.399를 얻었다. 이 bound는 dataset-specific null이지 universal cutoff가 아니다.
  • External DEGs는 Seurat FindMarkers, reported average log2FC >0.1 및 adjusted p<0.05로 선택했다. Gene-set enrichment는 MSigDB GO/KEGG/Hallmark v7.2, fgsea, Fisher ORA 및 GSVA v1.40 ssGSEA를 이용했다.

Toy example

숫자는 설명용. 모든 donor에서 type A의 RNA/ATAC가 (1,2), type B가 (10,20)이면 pooled Pearson r=1이 가능하지만 같은 type 안의 시간 변화가 없으므로 longitudinal coupling의 증거는 없다. Across-group correlation과 within-group correlation을 분리한다.

Related figures · Figure 4G–I, Figure 6, Supplementary 10–11.

Reproducibility

PALMO code and vignettes, publication archive, processed GSE190992에서 시작한다. R package와 dependency versions를 고정하고 sample IDs/metadata joins, missing fraction, donor-time replicate counts를 출력한 뒤 한 module씩 실행한다. Restricted dbGaP raw data는 authorized access가 있어야 한다. 이 페이지의 toy arithmetic만 실행했으며 package-level reproduction이나 원문 p-value 재계산 완료를 뜻하지 않는다.

Notation and source discrepancies

  1. 1,042/1,156과 “68%”, 1.24% expected rate와 “19” expected proteins는 산술적으로 일치하지 않는다.
  2. SPECT Methods default groupThreshold=half combinations와 Results의 40를 구분한다.
  3. Figure 6 caption의 five families와 A–F six groups가 다르다.
  4. Supplementary 12 legend는 comparator Wilcoxon, Methods는 test.use="MAST"라 쓴다.
  5. CVP default donor consistency와 Results median-CV selection을 동일시하지 않는다.
