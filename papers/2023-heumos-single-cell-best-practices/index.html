Single-cell Best Practices (Heumos 2023)

Best practices for single-cell analysis across modalities — Heumos et al.

scRNA-seq를 비롯한 single-cell modality별 분석 단계마다 어떤 방법을 고르면 좋은지 benchmark 근거로 정리한 review. 온라인 책 Single-cell Best Practices의 논문판이다.

논문 정리 보기
원문 (DOI) License · unknown
Single-cell Analysis

Background

  • Single-cell 분석 도구가 수백 개로 늘어나 단계마다 무엇을 써야 할지 고르기 어렵다.
  • 이 review는 preprocessing → cell-level 분석 → gene-level 분석 → multimodal 분석 순서로, 각 단계의 권장 방법과 근거(benchmark)를 정리한다.

핵심 내용 (옛 노트에 정리된 부분)

Filtering low-quality cells and noise correction

  • 대부분의 분석은 "droplet 하나 = 온전한 cell 하나"라고 가정한다. 이 가정은 low-quality cell, cell-free RNA 오염(ambient RNA), 여러 cell이 한 droplet에 들어간 doublet 때문에 자주 깨진다 (Fig. 2a).
  • Detected gene 수가 적고, count depth가 낮고, mitochondrial count 비율이 높은 cell은 low-quality cell로 본다. 세포막이 깨진 dying cell일 수 있기 때문이다.
  • 세 지표를 따로 보지 말고 함께 봐야 한다. 예를 들어 MT 비율이 높은 cell이 실제로는 호흡이 활발한 cell일 수도 있다.
  • 자세한 방법은 Cell Quality Control, CellBender에 정리했다.
✎정리 범위

옛 노트에는 QC 부분만 있었다. 나머지 단계(normalization, integration, annotation, DE, compositional analysis 등)의 권장 사항은 scRNA-seq Workflow와 각 개념 페이지에 이미 나뉘어 들어가 있다.
