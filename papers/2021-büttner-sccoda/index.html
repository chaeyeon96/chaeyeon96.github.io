scCODA (2021 Büttner)

scCODA is a Bayesian model for compositional single-cell data analysis — Büttner et al.

Sample별 cell-type counts를 함께 모델링해 reference 대비 compositional changes를 추정하고 posterior expected FDR로 credible effects를 선택한다.

Background

한 cell type의 absolute abundance만 줄어도 나머지 비율은 함께 증가한다. 따라서 cell type마다 독립적인 검정을 하면 compositional closure를 실제 변화로 오해할 수 있다. scCODA는 Dirichlet-multinomial likelihood와 sparse Bayesian effects를 사용하되, 결과를 reference cell type에 대한 상대 변화로 해석한다.

Figure 1 · Why composition requires a joint model

Context · 세포를 많이 측정해도 biological replicate 수가 늘어나는 것은 아니다. 먼저 compositional effect와 small-sample inference를 동시에 다뤄야 하는 이유를 본다.

Figure: Büttner et al., Nature Communications (2021) · CC BY 4.0

A · Compositional sampling

  • 목적: Absolute change와 measured proportion은 왜 다른가?
  • Data & method: Control/disease tissue의 개념적 sampling을 비교한다 (Pipeline).
  • 그림 읽기: 한 type의 변화와 전체 합이 고정된 비율을 구분한다.
  • 결과와 의미: 나머지 type의 비율 증가는 그 type의 absolute expansion을 뜻하지 않는다.

B · False differential calls

  • 목적: Replicate가 적을 때 어떤 false calls가 생기는가?
  • Data & method: 큰 simulated log-fold change와 n=2/group example에서 방법별 검정을 비교한다 (Pipeline).
  • 그림 읽기: Horizontal colored bars는 검출, error bars는 평균의 95% CI이다.
  • 결과와 의미: 독립적인 univariate tests는 indirect compositional shifts를 differential로 판단할 수 있다.

C · Hierarchical model

  • 목적: 관측 counts와 effect selection을 어떻게 연결하는가?
  • Data & method: Dirichlet-multinomial과 logit-normal relaxed spike-and-slab를 결합한다 (Pipeline).
  • 그림 읽기: Blue nodes는 observed variables이며 prior 계층을 따라간다.
  • 결과와 의미: Joint likelihood와 reference constraint가 effect의 상대적 의미를 정한다.

Takeaway · scCODA는 absolute cell counts를 복원하는 도구가 아니다.

Figure 2 · Synthetic benchmark

Context · 개념도에서 보인 bias가 다양한 replicate·effect 조건에서도 반복되는지 확인한다. Threshold-free metrics와 fixed-FDR 결과를 함께 본다.

Figure: Büttner et al., Nature Communications (2021) · CC BY 4.0

A · ROC

  • 목적: True/false effects의 ranking을 얼마나 잘 구분하는가?
  • Data & method: n>1/group synthetic scenarios에서 inclusion probability 등을 threshold sweep한다 (Pipeline).
  • 그림 읽기: x축 FPR, y축 TPR이며 methods의 score 종류는 S Table 1에 다르다.
  • 결과와 의미: scCODA ROC AUC는 0.99로 보고되며 해당 simulation design 안에서의 성능이다.

B · Precision–recall

  • 목적: Positive effects가 적을 때도 precision을 유지하는가?
  • Data & method: 같은 synthetic benchmark에서 precision–recall curves를 만든다 (Pipeline).
  • 그림 읽기: Recall 증가에 따른 precision 저하를 비교한다.
  • 결과와 의미: Average precision 0.94로 보고되며 AUC와 다른 평가량이다.

C · Overall recovery

  • 목적: Replicate 수가 늘면 전체 recovery가 좋아지는가?
  • Data & method: Nominal FDR 0.05에서 MCC를 replicate 수별 집계한다 (Pipeline).
  • 그림 읽기: n=1에서는 non-Bayesian methods의 no-discovery 처리에 주의한다.
  • 결과와 의미: scCODA 평균 MCC 0.64; small-n에서 Bayesian methods가 유리했지만 one-replicate 결과는 prior에 민감하다.

D · Sensitivity

  • 목적: 효과를 얼마나 놓치지 않는가?
  • Data & method: 같은 scenario들의 TPR를 replicate 수별 집계한다 (Pipeline).
  • 그림 읽기: Shading은 95% CI이며 높을수록 sensitivity가 좋다.
  • 결과와 의미: Replicate 증가는 detection을 개선하지만 rare populations의 작은 effect에는 더 많은 samples가 필요하다.

E · False discovery rate

  • 목적: Detection 증가가 false positives 증가 때문은 아닌가?
  • Data & method: Known truth로 empirical FDR를 계산한다 (Pipeline).
  • 그림 읽기: Nominal FDR와 실제 FDR를 비교하며 낮다고 power가 높은 것은 아니다.
  • 결과와 의미: Non-compositional methods는 replicate 증가에도 false discovery가 커질 수 있어 joint modeling이 중요하다.

Takeaway · Benchmark 우위는 모든 실제 data에서 FDR가 정확히 보장된다는 뜻이 아니다.

Figure 3 · Real datasets and independent biological evidence

Context · Simulation의 정답을 넘어 기존 실험 검증이 있는 data에 적용한다. Tissue별 reference와 replicate 구조가 다르므로 각 panel의 통계 조건을 따로 읽는다.

Figure: Büttner et al., Nature Communications (2021) · CC BY 4.0

A · Supercentenarian PBMC

  • 목적: FACS로 확인한 B-cell 감소를 회복하는가?
  • Data & method: 7 versus 5 PBMC samples; CD16+ monocytes reference, HMC 20,000/burn-in 5,000 (Pipeline).
  • 그림 읽기: Dark/light blue는 supercentenarian/control, red는 scCODA credible result이다.
  • 결과와 의미: FDR 0.2에서 B cells만 credible decrease이며 기존 FACS 결과와 일치한다.

B · Microglia

  • 목적: AD-associated changes가 cortex에 선택적인가?
  • Data & method: AD/WT mouse cortex·cerebellum n=2/group; microglia 1 reference (Pipeline).
  • 그림 읽기: 지역별 boxplots와 detected-change bars를 따로 비교한다.
  • 결과와 의미: Cortex에서 microglia 2와 DAM이 상대적으로 증가하고 cerebellum에서는 credible change를 찾지 못했다.

C · Colon compartments

  • 목적: 왜 epithelium과 lamina propria를 나누는가?
  • Data & method: UC study의 tissue sampling 구조를 제시한다 (Pipeline).
  • 그림 읽기: C는 조직 개념도이며 differential-effect estimate가 아니다.
  • 결과와 의미: 서로 다른 compartments를 섞지 않고 epithelial/non-epithelial contamination groups를 따로 묶는다.

D · Epithelium

  • 목적: UC에서 epithelial composition이 어떻게 달라지는가?
  • Data & method: 61 samples, 16 types; immature goblet reference; 150,000/10,000 HMC (Pipeline).
  • 그림 읽기: Healthy·non-inflamed·inflamed와 scCODA/Dirichlet regression bars를 구분한다.
  • 결과와 의미: Absorptive·secretory 변화 외에 enteroendocrine 증가를 포착했고, 희귀 M cells는 responder subset에 민감했다.

E · Lamina propria

  • 목적: Immune-rich compartment에서 rare changes도 보이는가?
  • Data & method: 72 samples, 37 types; CD8+ IEL reference; 400,000/10,000 HMC (Pipeline).
  • 그림 읽기: Median·IQR와 outliers를 보되 samples와 donors를 동일시하지 않는다.
  • 결과와 의미: Plasma B 감소·follicular B 증가 및 Treg 증가를 포착; 일부 donor에만 있는 IAF response는 놓칠 수 있다.

F · COVID-19 BALF

  • 목적: Severity-associated cell-type changes가 있는가?
  • Data & method: Healthy/moderate/severe counts; plasma reference; HMC 80,000/10,000; FDR 0.2 (Pipeline).
  • 그림 읽기: 원 figure의 mild 표기와 본문의 moderate가 같은 중간 group임을 유의한다.
  • 결과와 의미: Severe에서 T-cell 상대 감소·neutrophil 상대 증가와 healthy 대비 intermediate group의 NK 증가가 credible했다.

Takeaway · 외부 staining/FACS의 일치는 근거를 강화하지만 reference choice와 donor-level uncertainty를 없애지는 않는다.

Limitations

  • Reference는 자동으로 선택해도 truly unchanged라는 증명이 아니다; 다른 안정적인 reference로 sensitivity analysis가 필요하다.
  • ANCOM이 cortex의 세 type을 검출했다는 사실만으로 모두 false positive라고 단정하지 않는다. Methods별 reference·null hypothesis가 다르다.
  • Input cell labels가 잘못되면 count table도 잘못된다; continuous state의 cluster 경계에 민감하다.
  • Model은 covariate의 log-linear effect를 가정하고 별도의 donor random effect나 response-mixture를 포함하지 않는다. UC의 여러 samples를 독립으로 처리한 원 분석은 within-donor dependence의 한계가 있다.
  • S9의 ‘절반 이상 responder’는 그 simulation의 관찰이며 모든 dataset의 보편적 cutoff가 아니다.
  • One sample/group도 수학적으로 fit할 수 있으나 biological replication을 대체하지 않는다.
  • Original Methods의 threshold 식, simulation 총수, power sample-size 표기에 불일치가 있어 Notation audit에 기록했다.
