CS-CORE Pipeline

Raw UMI count로 latent expression의 covariance를 추정한다. Log-normalized matrix를 넣는 correlation 분석과 다르다. 근거: Methods / Algorithm 1, Supplementary Methods pp. 2–5와 Discussion pp. 6–7.

Workflow

Step 1 · Input and measurement model

Task · 같은 cell type만 모아 counts와 depth를 준비한다.

Input → Output · X∈Nn×pX\in\mathbb N^{n\times p}X∈Nn×p, sis_isi​ → latent ziz_izi​의 mean μ\muμ, covariance Σ\SigmaΣ를 정의한다.

Intuition · 같은 물을 서로 다른 크기의 컵으로 떠서 측정한 값은 컵 크기를 함께 알아야 비교할 수 있다. 그러나 작은 컵의 sampling noise는 크기를 나누는 것만으로 사라지지 않는다.

Details · zi∼Fp(μ,Σ)z_i\sim F_p(\mu,\Sigma)zi​∼Fp​(μ,Σ), xij∣zij∼Poisson(sizij)x_{ij}\mid z_{ij}\sim\mathrm{Poisson}(s_i z_{ij})xij​∣zij​∼Poisson(si​zij​). FpF_pFp​에 특정 parametric distribution을 강제하지 않는다. sis_isi​는 cell의 전체 UMI 합이며 분석 subset gene의 합으로 임의 교체하지 않는다. 서로 다른 cell types를 섞으면 mean 차이가 가짜 correlation을 만든다 (Supplementary Discussion).

Toy example · 숫자는 설명용. s=100s=100s=100, μ=0.02\mu=0.02μ=0.02, σ=0.0001\sigma=0.0001σ=0.0001이면 expected count 222, variance 2+1=32+1=32+1=3이다. s=200s=200s=200이면 mean 444, variance 4+4=84+4=84+4=8: depth에 따라 mean뿐 아니라 variance도 바뀐다.

Step 2 · Moment equations and OLS initialization

Task · Poisson noise와 biological variability를 구분한다.

Input → Output · X,sX,sX,s → 초기 μ^j,σ^jj\hat\mu_j,\hat\sigma_{jj}μ^​j​,σ^jj​.

Intuition · 흔들림 전체에서 측정기의 흔들림을 빼고 생물학적 흔들림을 남긴다.

Details · rij=xij−siμjr_{ij}=x_{ij}-s_i\mu_jrij​=xij​−si​μj​라 두면

E(xij)=siμj,E(rij2)=siμj+si2σjj,E(rijrik)=si2σjk.E(x_{ij})=s_i\mu_j,\quad E(r_{ij}^2)=s_i\mu_j+s_i^2\sigma_{jj},\quad E(r_{ij}r_{ik})=s_i^2\sigma_{jk}. E(xij​)=si​μj​,E(rij2​)=si​μj​+si2​σjj​,E(rij​rik​)=si2​σjk​.

Supplementary Methods의 weighted least-squares operators는

μ^j=∑iwijsixij∑iwijsi2,σ^jj=∑ihijsi2(rij2−siμ^j)∑ihijsi4,\hat\mu_j=\frac{\sum_i w_{ij}s_ix_{ij}}{\sum_i w_{ij}s_i^2},\qquad \hat\sigma_{jj}=\frac{\sum_i h_{ij}s_i^2(r_{ij}^2-s_i\hat\mu_j)}{\sum_i h_{ij}s_i^4},μ^​j​=∑i​wij​si2​∑i​wij​si​xij​​,σ^jj​=∑i​hij​si4​∑i​hij​si2​(rij2​−si​μ^​j​)​,

σ^jk=∑igijksi2rijrik∑igijksi4.\hat\sigma_{jk}=\frac{\sum_i g_{ijk}s_i^2r_{ij}r_{ik}}{\sum_i g_{ijk}s_i^4}. σ^jk​=∑i​gijk​si4​∑i​gijk​si2​rij​rik​​.

처음에는 weight 1로 OLS를 계산한다. Finite-sample variance가 음수이면 log convergence나 correlation이 정의되지 않을 수 있으므로 구현의 safeguard를 확인해야 한다; 아래 Pinned implementation audit에 확인한 safeguard를 별도로 기록했다; 논문 pseudocode와 구별한다.

Toy example · 숫자는 설명용. s=(1,2)s=(1,2)s=(1,2), x=(2,5)x=(2,5)x=(2,5), weight 1이면 μ^=(2+10)/(1+4)=2.4\hat\mu=(2+10)/(1+4)=2.4μ^​=(2+10)/(1+4)=2.4. Residual은 (−0.4,0.2)(-0.4,0.2)(−0.4,0.2)이다. 이 극소 표본은 variance estimate가 음수여서 안정적인 covariance 추론에 부적합하다; 계산식 예시이지 분석 권장 표본 수가 아니다.

Step 3 · IRLS and covariance

Task · Noisy cell의 weight를 줄이면서 moments를 반복 추정한다.

Input → Output · 초기 moments → 안정화된 mean/variance, pairwise covariance/correlation.

Intuition · 불확실한 저울의 측정에는 작은 표를 주고, 저울의 불확실성을 새 추정치로 다시 평가한다.

Details · Algorithm 1의 common dispersion regularization:

θ^=median⁡j(σ^jj/μ^j2),Vij=siμ^j+si2μ^j2θ^.\hat\theta=\operatorname{median}_j\left(\hat\sigma_{jj}/\hat\mu_j^2\right),\quad V_{ij}=s_i\hat\mu_j+s_i^2\hat\mu_j^2\hat\theta.θ^=medianj​(σ^jj​/μ^​j2​),Vij​=si​μ^​j​+si2​μ^​j2​θ^.

Mean update는 wij=1/Vijw_{ij}=1/V_{ij}wij​=1/Vij​, variance는 hij=1/Vij2h_{ij}=1/V_{ij}^2hij​=1/Vij2​, covariance는 gijk=1/(VijVik)g_{ijk}=1/(V_{ij}V_{ik})gijk​=1/(Vij​Vik​)를 쓴다. Mean과 variance를 갱신한 뒤

Δ(t)=max⁡j∣log⁡σ^jj(t)−log⁡σ^jj(t−1)∣<0.05\Delta^{(t)}=\max_j|\log\hat\sigma_{jj}^{(t)}-\log\hat\sigma_{jj}^{(t-1)}|<0.05 Δ(t)=jmax​∣logσ^jj(t)​−logσ^jj(t−1)​∣<0.05

이면 중단한다. 보통 5 iterations 안에 수렴했다는 설명은 고정 iteration 수가 아니다. 마지막 covariance를 구하고 ρ^jk=σ^jk/σ^jjσ^kk\hat\rho_{jk}=\hat\sigma_{jk}/\sqrt{\hat\sigma_{jj}\hat\sigma_{kk}}ρ^​jk​=σ^jk​/σ^jj​σ^kk​​로 나눈다. Variance/covariance weights는 distribution-free 상황의 엄밀한 universally optimal weights가 아니라 실용적 선택이다 (Supplementary Notes).

Toy example · 숫자는 설명용. Vj=(3,8)V_j=(3,8)Vj​=(3,8), Vk=(4,12)V_k=(4,12)Vk​=(4,12)이면 g=(1/12,1/96)g=(1/12,1/96)g=(1/12,1/96): 두 번째 cell의 raw covariance residual에는 첫 번째의 1/8 weight가 적용되지만 regression에는 si2s_i^2si2​도 들어가므로 최종 영향이 단순 1/8은 아니다. σjj=4,σkk=9,σjk=3\sigma_{jj}=4,\sigma_{kk}=9,\sigma_{jk}=3σjj​=4,σkk​=9,σjk​=3이면 correlation은 3/6=0.53/6=0.53/6=0.5.

Step 4 · Independence test and multiplicity

Task · 작은 estimated correlation이 noise와 구별되는지 평가한다.

Input → Output · Moments와 pairwise residuals → test statistic, p-value, adjusted p-value.

Intuition · 관계 크기를 그 추정의 불확실성과 비교한다. 큰 correlation과 강한 evidence는 같은 개념이 아니다.

Details · Vij=siμj+si2σjjV_{ij}=s_i\mu_j+s_i^2\sigma_{jj}Vij​=si​μj​+si2​σjj​라고 하면 논문 test는

Tjk=∑isi2rijrikgijk∑isi4VijVikgijk2.T_{jk}=\frac{\sum_i s_i^2 r_{ij}r_{ik}g_{ijk}}{\sqrt{\sum_i s_i^4 V_{ij}V_{ik}g_{ijk}^2}}. Tjk​=∑i​si4​Vij​Vik​gijk2​​∑i​si2​rij​rik​gijk​​.

Independence null에서 asymptotic standard normal을 사용한다. 추정 moments를 plug-in하고 two-sided p=2Φ(−∣T∣)p=2\Phi(-|T|)p=2Φ(−∣T∣)를 구한다. 일반적인 zero correlation은 모든 distribution에서 independence와 같지 않다. Module selection에는 BH-adjusted p<0.05p<0.05p<0.05; Fig. 5 reproduction curves는 nominal cutoff이므로 구별한다.

Toy example · 숫자는 설명용. T=1.96T=1.96T=1.96의 two-sided normal p는 약 0.049996이다. BH에서 두 p-values가 (0.01,0.04)(0.01,0.04)(0.01,0.04)이면 adjusted values는 (0.02,0.04)(0.02,0.04)(0.02,0.04)로 둘 다 0.05보다 작다.

Step 5 · Modules, replication and differential networks

Task · Edge를 기능 단위로 묶고 disease/control의 차이를 평가한다.

Input → Output · Significant edges → WGCNA modules → enrichment / differential modules.

Intuition · 대화하는 두 사람만 찾는 데서 멈추지 않고 같이 움직이는 팀을 찾는다.

Details · BH <0.05 edge에 WGCNA soft power 1. Enrichment background는 분석에 들어간 gene 전체이며 clusterProfiler 4.2.2 / ReactomePA 1.38.0를 사용했다. TRRUST overlap에는 top 5,000과 reference genes의 union, replication에는 두 dataset top 5,000의 intersection을 쓴다. Disease/control은 더 큰 그룹을 downsample해 cell 수를 맞추고 Djk=ρ^jkdisease−ρ^jkcontrolD_{jk}=\hat\rho^{disease}_{jk}-\hat\rho^{control}_{jk}Djk​=ρ^​jkdisease​−ρ^​jkcontrol​를 계산한다. Group labels 100 permutations의 null과 비교, BH <0.05 후 module을 추출한다. Cell-level permutations가 donor dependence를 해결하지는 않는다.

Toy example · 숫자는 설명용. Control correlation 0.2, disease 0.7이면 difference 0.5다. 동일 mean expression에서도 covariance는 달라질 수 있다. 반대로 mean fold change만으로 differential co-expression을 결론 내릴 수 없다.

Simulation settings

  • Null: normalized gene별 permutation 후 Poisson 재표집; 1,000 cells, 통상 500 genes, 100 repeats. baredSC 20 genes, locCSN 100 genes의 축소 조건을 구분한다.
  • Fig. 3B/C: 5,000 cells, 500 genes; significant truth edges 중 |correlation|<0.5 제거, off-diagonal scaling 3.1로 positive definite matrix 구성.
  • Fig. 4: degree-corrected stochastic block model; within/between ratio 1,000; degree power 4, mean 20; correlations 0.9–1 truncated normal, nearest positive-definite correction. 초기 100 genes에서 약하게 연결된 5 genes 제거 (Supplementary Methods).
  • Empirical p-value comparator: independent null datasets 100개; power 평가 100 data replicates, Supplementary Figs. 9/12는 1,000 replicates. 이 과정과 disease-label 100 permutations는 다르다.

Run and checks

Versioned code, R, Python. Raw counts, matching depth vector, homogeneous cell type, gene universe, package version을 저장한다. Bootstrap 또는 donor-aware sensitivity analysis는 연구 설계에 맞춰 추가 검토한다 (일반적 권고). 본 페이지는 실제 scRNA-seq 재분석 실행 기록이 아니다.

Safeguards and post-processing

  • post_process=TRUE가 default다. Negative estimated variances를 0으로 바꿔 correlation denominator를 구성한 뒤, correlation diagonal이 Inf/NA인 genes의 row/column을 0으로 만들고 최종 diagonal은 1로 둔다. ±1 밖 correlation은 각각 −1/1로 clip한다.
  • Mean-weight denominator w가 NA 또는 ≤0이면 1로 바꾸고, variance-weight denominator h가 ≤0이면 1로 바꾼다. 이는 모든 possible NaN을 해결하는 보장은 아니다.
  • Test statistics/p-values는 variance clipping과 correlation post-processing 이전에 계산된다. 따라서 correlation output의 범위가 정상이어도 p-values까지 finite/calibrated임을 보장하지 않는다. Negative variance flags와 nonfinite tests를 별도로 검사해야 한다.
  • Seurat wrapper는 RNA counts를 사용한다. seq_depth=NULL일 때 nCount_RNA가 있으면 그것을, 없으면 전체 count matrix row sums를 사용한 뒤 target genes를 subset한다. Low-level CSCORE_IRLS(X,NULL)은 전달받은 X의 합을 쓰므로 subset genes만 넣었다면 depth 의미가 달라진다.

Paper–code differences

Algorithm 1과 pinned implementation은 수치적으로 동일한 pseudocode가 아니다:

  1. Code의 theta=mu^2/sigma2는 논문 dispersion σjj/μj2\sigma_{jj}/\mu_j^2σjj​/μj2​의 역수다. Code는 positive theta의 median을 구해 V=M+s2μ2/θmedianV=M+s^2\mu^2/\theta_{median}V=M+s2μ2/θmedian​를 만든다. Median의 reciprocal 처리는 even gene count에서 interpolation 때문에 단순 동치라고 가정하지 않는다.
  2. Code convergence는 positive current/previous theta에 대한 max⁡∣log⁡(θnew/θold)∣\max|\log(\theta^{new}/\theta^{old})|max∣log(θnew/θold)∣이며, 논문의 log variance 변화와 다르다.
  3. Loop condition은 delta > 0.05 & j <= 10, initial j=0이라 최대 11 updates가 가능하다. Warning은 j == 10 & delta > 0.05로 검사하므로 message만으로 convergence를 신뢰하면 안 된다. 이것은 source inspection 결과이며 실제 실패 dataset 재현 실험은 아니다.
  4. Test statistic은 regularized covariance weights 대신 최종 unregularized variance로 만든 Sigma=M+s^2 sigma2를 다시 사용한다. Correlation estimation과 hypothesis test의 denominator를 구분한다.

Toy (숫자는 설명용): μ=2,σ2=4\mu=2,\sigma^2=4μ=2,σ2=4면 inverse theta=1, s=3s=3s=3에서 V=6+9⋅4/1=42V=6+9·4/1=42V=6+9⋅4/1=42다. Invalid variance gene과의 off-diagonal estimate가 0으로 처리돼도 이는 독립성이 실험적으로 입증됐다는 뜻이 아니라 numerical post-processing 결과다.
