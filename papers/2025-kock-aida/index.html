AIDA (Kock 2025)

Asian diversity in human immune cells — Kock et al.

아시아 5개국 7개 population group의 healthy donor 619명 PBMC로 만든 single-cell reference atlas(Asian Immune Diversity Atlas). Age, sex, self-reported ethnicity가 immune cell 구성과 발현에 주는 영향과, 아시아인 특이 eQTL을 보여 준다.

Takeaway · Age, sex, ethnicity가 각각 cell 구성에 영향을 준다. Cell type 수준보다 neighborhood 수준에서 보면 어느 subset이 변하는지 더 정확히 보인다.

Method

1. Cell neighbourhood enrichment analysis

  1. Single dimension · Cell마다 nearest neighbor 500개 안에서 각 group의 비율을 구한다.
  2. Multiple dimensions · MiloR(v1.5)로 differential neighborhood abundance를 검정한다.

2. Context-dependent eQTL

  • KNN 기반 smoothing으로 sparse한 gene–cell matrix를 보완한다.
  • WGCNA로 gene–gene correlation matrix를 구하고 module을 찾는다.
  • Memory B cell마다 module score(module gene 발현 평균)를 계산한다.
  • Donor genotype × module score interaction term을 검정한다.

3. Annotation 방법 (프로젝트 참고)

Figure: Kock et al., Cell (2025) · CC BY-NC-ND 4.0

  • Population별로 QC, feature selection, integration, sub-clustering, annotation을 따로 한다: (1) B cell, (2) pDC + myeloid, (3) ILC + NK + T. (3)은 다시 (3a) CD4+ T + dnT, (3b) 나머지 ILC, NK, T로 나눠 한 번 더 통합하고 clustering한다.
  • Gene 선택 · 각 cell type에서 0.1% 이상의 cell이 발현하는 gene만 쓰고, 남은 gene의 총 발현으로 다시 normalization한다.
  • Platelet QC · Platelet marker 4개(ITGA2B, PF4, PPBP, TUBB1)의 발현 합이 0이 아닌 cell 중 상위 30%를 첫 번째 sub-clustering에서 뺀다.
  • Integration · Seurat RPCA. Library마다 log-normalize, VST로 HVG 2000개, cell 수가 가장 많은 library를 reference로, PC 30개, k.weight = 100. Control 분석으로 Harmony도 돌렸다.
  • Annotation · Wilcoxon(Seurat FindMarkers)으로 marker를 찾고, 4단계 hierarchy(Level 1–4)로 이름을 붙인다 (Fig. S2A, B). "hi" 기준은 log2FC > 0.5이면서 cluster의 50% 넘게 발현. T cell은 high-confidence TCR barcode 비율도 본다. 근거가 약하면 CD4+_T_unknown처럼 거친 수준에 둔다.
  • 주의 표시 · (1) platelet gene이 높은 cluster, (2) detected gene 수가 낮고 canonical marker가 약하면서 MALAT1, NEAT1이 높은 cluster, (3) 다른 lineage marker가 높은 cluster는 해석에 주의하도록 표시한다.
