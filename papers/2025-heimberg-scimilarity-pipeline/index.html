1. Input and split

Task

Raw count를 공통 gene 순서로 맞추고 study 전체를 분리한다.

Input → Output

Human 10x sc/snRNA-seq counts + annotation → normalized expression, ontology label, study split.

Intuition

같은 교과서의 다른 쪽을 test로 삼지 않고, 다른 학교의 시험지를 남겨 두는 것과 같다.

Details

Cell별 total을 10,000으로 맞춘 뒤 natural log1p를 적용한다. Doublet, mitochondrial UMI >20%, detected genes <500인 cell을 제거한다. Cell Ontology로 해석 불가능한 label은 training에서 제외한다. 56 training studies와 15 test studies를 분리하고, 두 study 이상에서 관찰되는 203 ontology terms를 사용한다. 한 study에만 있는 세부 term은 조건을 만족하는 parent term으로 올릴 수 있다.

xcg=log⁡(1+104ncg/∑hnch).x_{cg}=\log(1+10^4 n_{cg}/\sum_h n_{ch}). xcg​=log(1+104ncg​/h∑​nch​).

Toy example

숫자는 설명용: counts (1,3)의 total은 4이므로 normalized values는 (2500,7500), log1p는 약 (7.8244,8.9228)이다. Counts를 이미 log-normalized된 값으로 착각해 한 번 더 normalize하면 다른 입력이 된다.

2. Ontology-aware triplets

Task

Anchor와 positive는 동일 type·다른 study, negative는 명확히 다른 type으로 구성한다.

Input → Output

Expression + ontology → 학습에 informative한 triplet.

Intuition

‘T cell’과 ‘CD4 T cell’은 상하위 명칭이므로 서로 다른 종류라는 오답을 학습시키지 않는다.

Details

Ancestor–descendant 관계는 ambiguous로 제외한다. Batch는 1,000 cells를 study/type 가중 sampling하고 semi-hard negative를 사용한다. Distance는 unit-normalized embedding의 squared Euclidean distance다.

d(a,p)=∥f(a)−f(p)∥22,LT=1N∑imax⁡(d(ai,pi)−d(ai,ni)+α,0).d(a,p)=\|f(a)-f(p)\|_2^2,\qquad L_T={1\over N}\sum_i\max(d(a_i,p_i)-d(a_i,n_i)+\alpha,0). d(a,p)=∥f(a)−f(p)∥22​,LT​=N1​i∑​max(d(ai​,pi​)−d(ai​,ni​)+α,0).

Loss 자체에서 도출한 semi-hard 영역은 d(a,p)<d(a,n)<d(a,p)+αd(a,p)<d(a,n)<d(a,p)+\alphad(a,p)<d(a,n)<d(a,p)+α다 (원문 식의 불일치는 아래 참조).

Toy example

숫자는 설명용: d(a,p)=0.02,d(a,n)=0.04,α=0.05d(a,p)=0.02,d(a,n)=0.04,\alpha=0.05d(a,p)=0.02,d(a,n)=0.04,α=0.05이면 loss는 0.03이다. Negative distance가 0.10이면 loss는 0이다.

3. Encoder and combined objective

Task

Cell identity와 세밀한 expression 정보를 동시에 보존한다.

Input → Output

28,231-dimensional profile → 128-dimensional unit vector와 reconstructed profile.

Intuition

분류에 필요한 공통점만 외우지 않도록 원래 expression도 다시 그려 보게 한다.

Details

Setting Value
Encoder layers 28,231 → 1,024 → 1,024 → 1,024 → 128
Input dropout 40%
Hidden dropout 50%
Embedding Unit-length normalization
Reconstruction Anchor cells only
Query model β=0.001, margin α=0.05
Pure integration comparison β=1

LR=1N∑i∥xi−g(f(xi))∥22,L=(1−β)LR+βLT.L_R={1\over N}\sum_i\|x_i-g(f(x_i))\|_2^2,\qquad L=(1-\beta)L_R+\beta L_T. LR​=N1​i∑​∥xi​−g(f(xi​))∥22​,L=(1−β)LR​+βLT​.

β만 보고 두 항의 실제 gradient 크기가 999:1이라고 해석하지 않는다; loss의 scale도 함께 작용한다 (일반 지식).

4. Annotation and query

Task

학습된 encoder를 고정한 채 새 cell 또는 centroid의 이웃을 찾는다.

Input → Output

Query counts → embedding → neighbor labels / metadata / similarity.

Intuition

검색할 때마다 도서관 전체를 다시 분류하지 않고 이미 만든 색인을 조회한다.

Details

s(i,j)=11−ci⊤cj,∥ci∥=∥cj∥=1.s(i,j)={1\over1-c_i^\top c_j},\quad \|c_i\|=\|c_j\|=1. s(i,j)=1−ci⊤​cj​1​,∥ci​∥=∥cj​∥=1.

Index Construction Search
Annotation · 7.9M cells HNSW ef_construction=1000, M=80 k=50, ef=100
Query · 23.4M cells ef_construction=400, M=50 default k=1000, ef=k

Annotation은 이웃의 동일 가중 vote 또는 distance inverse-weighted vote를 쓴다. Safelist/blocklist는 가능한 type 범위를 제한한다. FM query는 GSE136831의 six-gene signature 상위 50 cells의 expression 평균을 먼저 구한 뒤 encode한다; embedding 평균과 동일한 연산이라고 가정하지 않는다.

Query 안정성은 입력 cells를 k=10으로 subcluster한 centroid 검색 결과와 parent centroid 결과(default 100 neighbors)의 평균 overlap으로 점검한다.

Toy example

숫자는 설명용: cosine similarity 0.98이면 score=50, 0.96이면 25다. Score 50은 ‘50% 확률’이 아니다. 50 neighbors 중 30이 macrophage이면 단순 vote는 macrophage지만 낮은 confidence를 별도로 확인해야 한다.

5. Attribution and validation

Task

Query-like cells와 background 사이 거리 차이에 기여하는 gene을 찾는다.

Input → Output

Foreground/background pairs → gene attribution → signature/pathway comparison.

Intuition

검색 결과의 이름만 읽지 않고, 무엇이 두 profile을 다르게 만들었는지 살펴본다.

Details

Ii(x,y)=∣max⁡(xi−yi,0)∫01∂d(y+t(x−y),y)∂xi dt∣.I_i(x,y)=\left|\max(x_i-y_i,0)\int_0^1 {\partial d(y+t(x-y),y)\over\partial x_i}\,dt\right|. Ii​(x,y)=​max(xi​−yi​,0)∫01​∂xi​∂d(y+t(x−y),y)​dt​.

Pair별 attribution을 평균한다. xi<yix_i<y_ixi​<yi​인 gene을 버리고 절댓값을 쓰므로 표준 signed IG와 동일한 해석이 아니다. Notation discrepancies

  • Methods/Supplementary Eq. 5는 zero-loss 조건과 맞지 않는 부등식을 인쇄한다. 실제 loss Eq. 2에서 zero loss는 d(a,n)≥d(a,p)+αd(a,n)\ge d(a,p)+\alphad(a,n)≥d(a,p)+α다; 여기서는 loss에 맞는 교육용 영역을 사용했다.

  • Model selection 문장은 ‘3 margins/18 combinations’라 쓰지만 margin 목록에 0, 0.01, 0.05, 0.1 네 값을 열거한다. 실제 exhaustive grid는 code snapshot과 대조해야 한다.

  • Supplementary Note 1에 Figure 6A 등 최종 5개 main figure와 맞지 않는 번호와 query accession GSE159354가 남아 있다; 최종 Methods는 main FM query GSE136831을 명시한다.

  • Attribution enrichment 절의 background는 top 10,000 밖에서 sampling하지만 다른 Methods 절/Supplementary에는 전체 macrophage pool로 쓴다. 어느 분석을 재현하는지 고정하고 code를 확인해야 한다.

  • Figure 2C legend는 score<50, 실제 source image의 x-axis label은 score<33으로 다르다. Methods의 outlier filtering 약 33, Figure 5 FM cutoff 25와 구분하고 code 확인 전 하나의 값으로 정정하지 않는다.

  • Figure 4B legend는 1,041 samples라고 하지만 source image의 Samples axis는 약 3,500까지 표시된다. 이 노트의 sample 수는 legend를 따른 것이며 axis와의 차이는 미해결이다.
