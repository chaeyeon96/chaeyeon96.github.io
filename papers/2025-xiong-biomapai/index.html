Background

ME/CFS는 fatigue, pain, cognitive impairment, sleep disturbance, orthostatic intolerance, gastrointestinal symptoms가 사람마다 다르게 조합되는 질환이다. Disease/control 하나만 예측하면 어떤 생물학적 feature가 어느 symptom과 연결되는지 놓치기 쉽다.

BioMapAI는 omics matrix XXX에서 symptom matrix YYY를 먼저 예측한다. Shared layer는 여러 symptom에 공통된 pattern을, symptom별 branch는 각 outcome에 특화된 pattern을 학습한다. 이어 예측된 symptom score를 disease classification으로 연결하고, SHAP과 별도의 WGCNA network로 생물학적 가설을 만든다. 이는 Multi-task Learning과 Multi-omics Integration의 사례다.

Data

대상은 249명이며, 515개 visit를 서로 다른 515명으로 세면 안 된다. ME/CFS 153명(short-term <4년 75명, long-term >10년 78명)과 control 96명을 추적했다. Methods의 visit 구성은 baseline 249, 1년 뒤 168, 2년 뒤 94, 4년 뒤 4개다. 모든 participant에게 모든 modality·모든 visit가 있는 것은 아니다 (Figure 1, Extended Data Fig. 1a; PDF pp. 2, 12, 20).

  • 결과와 의미: Microbiome, metabolome, immune profiling과 symptom을 연결할 수 있는 cohort를 만들었지만, modality별 결측과 반복측정 구조를 함께 다뤄야 한다.

B · Within-person and between-person heterogeneity

  • 목적: 환자 간 차이와 같은 환자의 시간에 따른 변화가 일정한지 본다.
  • Data & method: 3–4개 visit가 있는 대표 환자 20명의 12개 symptom score와 integrated omics ordination을 표시했다 → Longitudinal structure.
  • 그림 읽기: 위는 symptom별 평균·범위이고 아래 같은 색 점들은 같은 사람의 여러 visit이며, 회색 점은 전체 cohort다.
  • 결과와 의미: 사람마다 symptom 조합과 trajectory가 달라 공통된 단순 시간 추세로 요약하기 어렵다. 시간 추세가 약하다는 사실이 visit 간 통계적 독립성을 증명하지는 않는다 → Limitations.

Takeaway · 질환의 heterogeneity를 담기 위해 disease label 하나뿐 아니라 symptom matrix를 예측한다.

A · Shared representation and symptom-specific heads

  • 목적: 여러 clinical outcome을 하나의 모델에서 학습하는 구조를 보여 준다.
  • Data & method: 개별 omics 또는 selected 154-feature matrix를 BatchNormalization → shared 64/32 nodes → outcome별 8-node branch → 12개 score로 연결한다 → Architecture.
  • 그림 읽기: Shared layer 두 개와 여러 갈래로 나뉜 세 번째 layer를 구분하며, 그림의 입력별 row 수는 서로 다르다.
  • 결과와 의미: 공통 pattern과 outcome별 pattern을 함께 학습하는 설계이며, BioMapAI는 framework, DeepMECFS는 이 cohort에서 학습한 모델 이름이다.

B · Reconstructed clinical score distributions

  • 목적: 예측 score가 실제 symptom의 분포와 group 차이를 어느 정도 복원하는지 본다.
  • Data & method: Physical health, social functioning, pain의 실측 score와 omics별 예측 score를 비교한다 → Loss and training.
  • 그림 읽기: 첫 열의 실제 분포를 뒤의 모델별 분포와 비교하고, 색 밀도와 mean/IQR 표시를 본다.
  • 결과와 의미: 건강군과 환자군의 차이는 상당 부분 복원되지만 예측값의 분산은 압축된다. 분포가 비슷하다는 것과 개인별 prediction이 정확하다는 것은 구분한다.

C · Omics-specific strengths across symptoms

  • 목적: 어떤 modality가 어떤 symptom prediction에 유리한지 비교한다.
  • Data & method: 12개 실측·예측 score 사이의 normalized MSE를 계산했다 → Evaluation metrics.
  • 그림 읽기: 반지름은 1−normalized MSE1-\mathrm{normalized\ MSE}1−normalized MSE이며 바깥쪽일수록 error가 작고, accuracy나 R2R^2R2로 읽지 않는다.
  • 결과와 의미: Immune profile은 여러 symptom, microbiome은 gastrointestinal·일부 emotional/sleep symptom에서 비교적 유리했다. Feature 수와 sample 구성이 다른 modality 간 순위라 assay 자체의 절대 우열로 일반화하지 않는다.

D · In-cohort classification

  • 목적: 예측 symptom score로 ME/CFS와 control을 구분할 수 있는지 평가한다.
  • Data & method: 예측된 12개 score를 보조 binary ScoreLayer에 넣어 10-fold CV와 별도 10% held-out에서 ROC를 평가했다 → ScoreLayer.
  • 그림 읽기: 왼쪽 CV와 오른쪽 held-out ROC를 나누어 보고, 축은 FPR/TPR이며 범례의 수치는 AUROC다.
  • 결과와 의미: Integrated Omics의 AUROC는 그림에서 CV 약 0.91, held-out 약 0.82다. 이는 91%의 환자를 맞혔다는 accuracy 표현과 다르다.

E · External disease classification

  • 목적: 다른 연구에서 수집된 data에도 모델이 적용되는지 확인한다.
  • Data & method: 외부 4개 cohort의 species·KEGG·metabolome feature를 맞추고 없는 feature는 0으로 채워 pretrained 모델을 평가했다 → External validation.
  • 그림 읽기: 각 행은 특정 cohort와 특정 입력 모델의 조합이며, integrated 154-feature 모델 전체의 외부 성능표가 아니다.
  • 결과와 의미: 내부 CV보다 AUROC가 낮아 cohort·assay·feature coverage 차이의 영향을 보여 준다. 외부 cohort에서 12개 symptom prediction 전체를 검증한 것은 아니다.

A · Species contributions across twelve symptoms

  • 목적: 여러 symptom에 공통된 feature와 symptom마다 다른 feature를 구분한다.
  • Data & method: Symptom별 submodel에 Kernel SHAP을 적용하고 top contributor가 75% 이상의 output에서 반복되면 shared biomarker로 분류했다 → SHAP categories.
  • 그림 읽기: 원형의 각 구간은 symptom, 구간 안 x축은 sample이며 여러 ring은 SHAP·cohort/demography·실측/예측 score를 보여 준다.
  • 결과와 의미: 공통 feature만으로 설명되지 않는 symptom별 contribution이 있다. 이 그림의 biomarker는 held-out에서 별도로 검증하지 않았다고 legend에 명시돼 있다.

B · Pain-specific contributions

  • 목적: Pain prediction에서 species와 immune feature가 어떻게 다르게 기여하는지 비교한다.
  • Data & method: Pain output의 sample별 SHAP과 실측·예측 score를 species/immune model별로 정리했다 → Sample-level attribution.
  • 그림 읽기: 보라색 symptom-specific contribution과 회색 shared contribution을 구분하고, SHAP의 양수는 더 높은 predicted severity를 뜻한다.
  • 결과와 의미: CD4 memory, CD1c+ DC와 F. prausnitzii 등의 contribution이 사람마다 달랐다. 모델의 contribution을 실험적 effect size로 해석하지 않는다.

C · Monotonic, biphasic and dispersed patterns

  • 목적: Feature와 symptom의 관계가 단순한 일방향 association인지 확인한다.
  • Data & method: Feature abundance와 pain score의 관계를 그리고 sample을 SHAP 값으로 색칠했다 → Response patterns.
  • 그림 읽기: x축은 feature abundance, y축은 pain severity, 파랑/빨강은 negative/positive SHAP이며, 점들의 분포와 추세선을 함께 본다.
  • 결과와 의미: Immune feature는 monotonic, F. prausnitzii·일부 metabolite는 biphasic, KEGG는 sparse/dispersed pattern을 보인다. 그림의 모든 예가 유의한 monotonic correlation을 가진 것은 아니다.

D · Individual species attribution

  • 목적: 같은 species가 사람마다 예측을 다른 방향으로 움직이는지 보여 준다.
  • Data & method: 두 sample의 species model pain prediction을 SHAP waterfall로 분해했다 → Additive decomposition.
  • 그림 읽기: Expected baseline에서 시작해 positive/negative contribution을 누적하면 해당 sample의 prediction f(x)f(x)f(x)에 도달한다.
  • 결과와 의미: F. prausnitzii의 contribution 방향이 sample context에 따라 달라 단일한 beneficial/harmful label로 요약하기 어렵다.

E · Individual immune attribution

  • 목적: Pain prediction을 바꾸는 immune feature의 sample별 조합을 보여 준다.
  • Data & method: Immune model의 두 sample에 대해 상위 feature contribution을 분해했다 → Immune attribution.
  • 그림 읽기: 빨강은 predicted pain을 높이고 파랑은 낮추며, 비교하는 두 model의 baseline은 다를 수 있다.
  • 결과와 의미: Prediction은 여러 immune feature contribution의 합이며 특정 cell 하나의 인과적 역할이나 drug target 타당성을 입증하지 않는다.

Takeaway · ‘Disease-specific’은 여기서 여러 symptom output에 공통된 모델 feature라는 operational definition이다. 다른 질환과 구분되는 임상적 specificity를 뜻하지 않는다.

A · Healthy reference network

  • 목적: Healthy cohort의 microbiome–blood association을 기준으로 정한다.
  • Data & method: Modality별 WGCNA module eigengene 사이의 adjusted Spearman correlation로 network를 만들었다 → WGCNA · Cross-omics network.
  • 그림 읽기: Node는 species·KEGG·immune·metabolite module이며 크기는 구성 feature 수, 빨강/파랑 edge는 positive/negative correlation이다.
  • 결과와 의미: Pyruvate, microbial community, Th17-related immune 및 plasma metabolite module 사이의 association이 건강군의 비교 기준이 된다.

B · Patient subgroup network changes

  • 목적: Age, sex, weight, IBS/infection 상태에 따라 association 변화가 다른지 본다.
  • Data & method: 각 patient subgroup를 대응하는 healthy subgroup와 비교해 correlation difference를 표시했다 → Matched subgroup comparison.
  • 그림 읽기: 이 panel의 빨강/파랑은 healthy 대비 correlation 증가/감소이며, A의 positive/negative correlation 부호와 동일한 뜻이 아니다.
  • 결과와 의미: Pyruvate 관련 연결의 약화와 inflammatory/mucosal immune module 관련 변화가 subgroup에 따라 달랐다. 여기서 network edge는 물질 이동이나 세포 간 직접 신호전달의 증거가 아니다.

C · Pathway–host associations and symptom contribution

  • 목적: 특정 microbial metabolic pathway 변화가 어떤 host feature 및 symptom prediction과 연결되는지 본다.
  • Data & method: KEGG gene abundance의 group 차이, host feature association, symptom별 aggregated SHAP을 결합하고 일부 microbial 변화는 외부 cohort와 비교했다 → Pathway integration.
  • 그림 읽기: 왼쪽은 control 대비 gene abundance, 중앙 Sankey는 correlation, 오른쪽은 host feature 변화와 symptom별 SHAP contribution이며 화살표로 된 causal flow가 아니다.
  • 결과와 의미: Butyrate/BCAA-related potential 감소와 tryptophan/benzoate 관련 변화가 immune·plasma feature 및 symptom과 연결되는 가설을 제시한다. 외부 microbial 변화 확인이 전체 cross-omics network의 외부 검증을 대신하지 않는다.
Pathway 이 그림과 본문에서 강조한 association
Tryptophan Th22-related negative association 소실과 γδT·IFN-γ/GzA-associated immune feature 연결 변화
Butyrate 여러 synthesis route와 Th17/Treg/MAIT association이 control·short-term·long-term에서 다름

Takeaway · 질병 여부뿐 아니라 covariate context에 따라 cross-omics association이 달라진다는 관찰이다. Cross-sectional duration group 차이를 같은 사람의 disease progression으로 읽으면 안 된다.

  • 목적: Microbial metabolism, plasma metabolome, immune activation과 symptom 사이의 종합 가설을 제시한다.
  • Data & method: 새 실험이 아니라 Figure 1–4의 관찰, SHAP과 network association을 기존 biological knowledge와 함께 종합했다 → Interpretation boundary.
  • 그림 읽기: Healthy/ME/CFS 두 영역에서 pathway·cell·metabolite를 비교하고, 실제 biochemical conversion을 그린 화살표와 단순 association line을 구분한다.
  • 결과와 의미: Altered microbial functional potential과 inflammatory MAIT/γδT-related feature가 heterogeneous symptom과 연결된다는 검증 가능한 가설이다. 이 그림만으로 butyrate·probiotic·immune intervention의 치료 효과를 결론내릴 수 없다.

Takeaway · BioMapAI의 최종 산출물은 prediction과 mechanism 후보이며, causal mechanism이나 치료 효과의 확정이 아니다.

Limitations

  • Population and controls · 단일 geographic center, 주로 white population, 여성과 고연령 참가자 비중이라는 한계가 있다. Healthy와의 구분은 fibromyalgia 등 symptom이 겹치는 disease control과의 구분보다 쉬울 수 있다 (Discussion/PDF pp. 8–10).
  • Repeated measures and data leakage · 저자는 각 visit를 독립 data point로 사용했다 (Methods/PDF p. 18). Participant 단위로 CV/held-out을 분리했는지는 해당 서술에서 명확하지 않다. 같은 사람의 visit가 train/test에 나뉘면 성능이 높아질 수 있다는 방법론적 점검 사항이며, 실제 leakage가 발생했다고 단정하지 않는다 → Grouped validation.
  • Feature selection and preprocessing · SHAP-selected 154-feature integration과 confounder/feature filtering이 각 training fold 안에서만 수행됐는지 전체 분석 script로 확인해야 한다. CV 전에 전체 cohort의 outcome을 보고 feature를 고르면 selection leakage 위험이 있다 (일반 지식).
  • Independent biomarker validation · Figure 3와 Extended Data Fig. 4는 biomarkers가 held-out에서 검증되지 않았다고 명시한다. 일부 외부 microbial/metabolite signal 확인, classifier의 외부 평가, symptom-specific marker 전체의 독립 검증은 서로 다른 주장이다.
  • External transportability · 외부 AUROC는 0.591–0.719이며, metabolite feature coverage가 약 79% 또는 19%인 cohort도 있다. Missing feature의 zero fill과 assay 차이가 영향을 줄 수 있다 (Results/PDF p. 5, Methods/PDF p. 16).
  • Association and functional potential · KEGG는 microbial DNA 기반 functional potential이며 실제 metabolite 생산 flux가 아니다. WGCNA/Spearman/SHAP은 직접적 molecular interaction이나 인과관계를 입증하지 않는다.
  • Time and disease duration · 추적 기간은 수십 년의 질환 진행을 포괄하지 못하며, short-term과 long-term군은 동일 사람을 4년에서 10년 이상까지 추적한 비교가 아니다.
  • Reporting and implementation · Learning rate, layer formula, continuous output activation, normalization 등 논문과 공개 코드의 차이는 Reporting and implementation notes에 구분했다. 별도 Supplementary Tables workbook은 첨부되지 않아 그 표 전체를 확인했다고 주장하지 않는다.
