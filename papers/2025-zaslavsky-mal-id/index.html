Mal-ID (Zaslavsky 2025)

Disease diagnostics using machine learning of B cell and T cell receptor sequences — Zaslavsky et al.

Bulk BCR/TCR repertoires의 composition, convergent sequence, language-model representation을 결합해 immune states를 분류하는 연구용 framework.

Background

두 사람의 receptor sequences가 정확히 겹치는 경우는 드물고, 환자의 모든 clone이 disease-specific하지도 않다. Mal-ID는 repertoire 전체의 통계, 비슷한 CDR3 clusters, learned sequence representation을 나누어 학습한 뒤 sample-level evidence를 합친다.

Primary groups는 COVID-19, HIV, SLE, T1D, influenza vaccination, healthy다. Six states에 vaccination/healthy도 포함되므로 ‘여섯 질병’이라고 부르지 않는다. Donor, sample, clone, read 수는 서로 다른 분모다.

A–B · Inputs and representations

  • 목적: 서열에서 어떤 정보를 추출하는가?
  • Data & method: Blood bulk IgH/TRB에 세 representation을 적용한다; Step 2.
  • 그림 읽기: Composition, sequence cluster, ESM-2 embedding의 가지를 구분한다.
  • 결과와 의미: 각 representation은 서로 다른 repertoire 특성을 제공한다.

C–E · Ensemble and validation

  • 목적: 어떻게 sample prediction과 해석을 연결하는가?
  • Data & method: 세 BCR·세 TCR models의 probabilities를 ensemble한다; Step 4.
  • 그림 읽기: Held-out participants, feature interpretation, threshold tuning을 별도 단계로 읽는다.
  • 결과와 의미: 여러 immune states를 구분하거나 한 condition의 operating point를 선택할 수 있는 proof of concept다.

Takeaway · Sequence-level weak labels와 patient-level diagnosis는 다른 supervision 단위다.

A–C · Held-out classification

  • 목적: BCR/TCR와 세 모델을 합치면 성능이 개선되는가?
  • Data & method: 542 individuals의 550 paired samples에 participant-level CV를 적용했다; Step 4.
  • 그림 읽기: A는 sample confusion counts, B는 architecture별 AUROC, C는 class-vs-rest다.
  • 결과와 의미: Combined model multiclass AUROC=0.986이며 combined signal이 유리하지만 임상 정확도 98.6%라는 뜻은 아니다.

D · Probability margin

  • 목적: 오류일 때 confidence도 달라지는가?
  • Data & method: Test sample의 top-two probability difference를 비교했다; Step 4.
  • 그림 읽기: Correct/incorrect groups의 margin 분포를 읽는다.
  • 결과와 의미: 오류에서 margin이 작지만 이것만으로 calibrated uncertainty가 증명되지는 않는다.

E · SLE activity

  • 목적: Healthy로 오분류된 SLE는 어떤 특징이 있는가?
  • Data & method: Adult SLE의 BCR-only prediction과 SLEDAI를 비교했다; Step 4.
  • 그림 읽기: Activity score가 있는 subset의 분포만 비교한다.
  • 결과와 의미: 낮은 activity와 misclassification이 연관되지만 오류를 임상적으로 올바른 판정이라고 바꾸어 부르지 않는다.

F · Operating points

  • 목적: Sensitivity와 specificity의 trade-off는 무엇인가?
  • Data & method: Pan-disease model에서 SLE binary decision threshold를 바꿨다; Step 4.
  • 그림 읽기: 두 강조 operating points를 비교한다.
  • 결과와 의미: 97%/86% 또는 84%/95% 등의 선택은 연구 cohort 기준이며 임상 적용에는 prevalence와 독립 검증이 필요하다.

Takeaway · AUROC, accuracy, abstention, clinical operating point를 함께 읽는다.

A–C · Viral response features

  • 목적: 감염·백신 상태별로 어떤 V/isotype feature가 기여하는가?
  • Data & method: Model 3 patient aggregation에 Tree SHAP을 적용했다; Step 3.
  • 그림 읽기: COVID-19, HIV, vaccination별 rescaled importance를 읽는다.
  • 결과와 의미: 알려진 IGHV와 isotype 맥락을 재현하지만 SHAP은 직접 binding measurement가 아니다.

D–E · Autoimmune features

  • 목적: SLE/T1D에서도 서로 다른 repertoire feature가 있는가?
  • Data & method: Positive samples의 category-level SHAP을 요약했다; Step 3.
  • 그림 읽기: Gene×isotype별 기여와 condition 간 차이를 비교한다.
  • 결과와 의미: SLE의 IGHV4-34 등과 일치하는 해석을 제공하되 모든 우선순위 gene이 validated mechanism은 아니다.

Takeaway · 모델이 알려진 지식과 일치한다는 근거와 새 mechanistic 가설을 분리한다.

A–D · Clustering specificity

  • 목적: Model 2가 어떤 binder를 찾고 놓치는가?
  • Data & method: CoV-AbDab SARS-CoV-2 binders와 healthy sequences를 fixed clusters에 매칭했다; Step 5.
  • 그림 읽기: V/J/length matching과 추가 85% identity 조건을 구분한다.
  • 결과와 의미: 높은 precision과 낮은 recall의 보수적인 detection을 보인다.

E–G · Language-model ranking

  • 목적: Model 3가 알려진 binder에 더 높은 score를 주는가?
  • Data & method: Fixed sequence-level classifiers에 external binders를 입력했다; Step 5.
  • 그림 읽기: Sequence score, AUPRC fold-change, gene별 AUROC는 다른 요약이다.
  • 결과와 의미: Binder enrichment를 보이지만 patient AUROC와 달리 sequence-level 성능은 제한적이다.

H–I · Complementarity

  • 목적: Cluster가 놓친 서열에서도 신호가 있는가?
  • Data & method: Model 2가 평가하지 못한 sequences와 matched-precision recall을 비교했다; Step 5.
  • 그림 읽기: No-cluster subset의 AUROC와 V gene별 recall 차이를 읽는다.
  • 결과와 의미: Language representation이 detection 범위를 넓히지만 false positives도 함께 증가할 수 있다.

Takeaway · Disease classification 성공을 antigen-binding predictor의 완성으로 해석하지 않는다.

Limitations

  • Disease class, treatment, age, sampling time와 protocol의 상관을 완전히 제거했다고 할 수 없다. kBET 결과만으로 batch confounding 부재를 증명하지 않는다.
  • External validation에는 threshold adaptation 또는 별도 retraining이 포함된 경우가 있으므로 모두 zero-shot validation으로 묶지 않는다.
  • TCR는 HLA context에 의존하고, receptor 하나의 sequence score는 paired receptor 구조나 실제 antigen-binding 실험을 대신하지 못한다.
  • Closed-set classes 밖의 disease, comorbidity, 낮은 activity, clinical prevalence 변화는 별도 검증이 필요하다.
  • Healthy count가 Results 220, Methods 217로 달리 기재돼 있다. Overall 593과 paired 542/550의 분모를 그대로 구분하고 Supplementary Table 1로 cohort accounting을 확정해야 한다.
