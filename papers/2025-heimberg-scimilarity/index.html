SCimilarity (Heimberg 2025)

A cell atlas foundation model for scalable search of similar human cells — Heimberg et al.

Reconstruction loss와 triplet loss를 결합한 metric learning으로 "같은 cell type은 가깝게, 다른 type은 멀게" 학습한 foundation model. 412개 study, 2,340만 cell의 reference에서 query cell과 비슷한 cell을 몇 초 만에 찾고, 재학습 없이 annotation과 integration을 한다.

Background

  • scRNA-seq이 쌓여 장기, disease, 발달 전반의 cell profile이 수억 개가 됐다. 이 atlas를 검색하면 cell과 disease의 연관, in vivo와 in vitro model의 연결을 찾을 수 있다.
  • 그런데 기존 model은 이렇게 큰 corpus에서 비슷한 cell profile을 검색하도록 설계되지 않았다. 여러 dataset을 함께 보려면 매번 integration model을 다시 학습해야 했다.

Figure 1 · Metric learning enables cell search in large atlases

Context · 서로 다른 studies의 cells를 같은 공간에서 검색하려면 공통 distance가 필요하다. Query workflow와 training 설계를 먼저 연결한다.

Figure: Heimberg et al., Nature (2025) · CC BY-NC-ND 4.0

A · Query workflow

  • 목적: 새 cell과 비슷한 reference cells를 빠르게 찾을 수 있는가?
  • Data & method: 412 studies/23.4M-cell reference와 query embedding을 비교한다; Step 4.
  • 그림 읽기: Query와 reference에서 반환되는 neighbors·metadata를 구분한다.
  • 결과와 의미: 새 dataset마다 model을 다시 학습하지 않는 retrieval framework를 제시한다.

B · Training

  • 목적: Study 차이를 넘어 cell similarity를 학습하는가?
  • Data & method: 56 training studies의 ontology-aware cross-study triplets와 reconstruction을 사용한다; Step 2.
  • 그림 읽기: Anchor/positive/negative와 shared encoder를 읽는다.
  • 결과와 의미: 같은 cell type을 가깝게 하면서 expression reconstruction으로 state 정보를 유지한다.

Takeaway · Cell identity와 expression detail을 함께 학습한 거리 공간이다.

Figure 2 · A universal representation that generalizes

Context · 공통 공간이 처음 보는 study에서도 유효한지 확인한다. Biological coherence와 batch mixing, outlier를 서로 다른 축으로 평가한다.

Figure: Heimberg et al., Nature (2025) · CC BY-NC-ND 4.0

A · Reference composition

  • 목적: Training/test/search corpus는 어떻게 다른가?
  • Data & method: Public atlas의 study·tissue·disease metadata를 정리했다; Step 1.
  • 그림 읽기: 원은 tissue/disease/study hierarchy, 크기는 cell 수다.
  • 결과와 의미: 전체 reference를 training sample 수로 오해하지 않도록 split을 구분한다.

B · Integration benchmark

  • 목적: Unseen studies에서도 biology를 보존하는가?
  • Data & method: 15 holdout studies와 kidney/lung/PBMC tasks에서 integration baselines를 비교했다; Step 3.
  • 그림 읽기: Cell-type coherence와 study mixing 지표를 따로 읽는다.
  • 결과와 의미: 강한 mixing만으로 좋은 integration이라 할 수 없고 다른 type의 over-mixing도 점검해야 한다.

C · Low-confidence cells

  • 목적: Training에 잘 대표되지 않는 cells를 찾을 수 있는가?
  • Data & method: Training nearest-neighbor score가 낮은 in vivo test cells를 요약했다; Step 4.
  • 그림 읽기: Study별 low-confidence fraction을 비교하되 legend의 score<50과 image의 score<33 표기가 다르다.
  • 결과와 의미: 부족하게 대표된 tissue는 낮은 confidence가 많아 적용 범위를 판단하는 단서를 준다.

Takeaway · Batch mixing을 극대화하는 것과 biology를 보존하는 것은 다르다.

Figure 3 · Accurate cell type annotation across the body

Context · 검색 거리의 품질을 annotation으로 확인한다. 이 task는 cell state 탐색과 연결되지만 동일한 평가는 아니다.

Figure: Heimberg et al., Nature (2025) · CC BY-NC-ND 4.0

A · Neighbor annotation

  • 목적: Embedding에서 cell identity를 전달할 수 있는가?
  • Data & method: Labeled-reference kNN vote를 사용한다; Step 4.
  • 그림 읽기: Query→neighbor labels→predicted type의 단계를 읽는다.
  • 결과와 의미: Fine-tuning 없는 annotation이 가능하지만 reference coverage에 의존한다.

B–D · Kidney holdout

  • 목적: 저자 label과 어느 정도 일치하는가?
  • Data & method: Held-out kidney dataset의 author/predicted labels를 비교했다; Step 4.
  • 그림 읽기: 두 UMAP과 confusion matrix를 함께 읽는다.
  • 결과와 의미: 86.5% label agreement는 해당 benchmark의 결과이며 모든 tissue의 보장값이 아니다.

E · Comparison

  • 목적: 다른 annotation methods와 비교하면 어떤가?
  • Data & method: 15 holdout datasets의 cell-type F1을 scANVI/CellTypist/TOSICA와 비교했다; Step 4.
  • 그림 읽기: Task별 F1 분포와 comparator training 조건을 확인한다.
  • 결과와 의미: 같은 pretrained model로 경쟁력 있는 annotation을 보인다.

Takeaway · Reference 범위와 holdout 조건 안에서 annotation 성능을 평가한다.

Figure 4 · Cell search reveals fibrosis-associated macrophages across diseases

Context · 기본 identity 보존을 확인한 뒤 더 세밀한 FM-like state를 검색한다. Lung query가 다른 tissue/disease에서도 의미 있는 결과를 돌려주는지 묻는다.

Figure: Heimberg et al., Nature (2025) · CC BY-NC-ND 4.0

A–B · FM query

  • 목적: 폐에서 정의한 state가 다른 samples에도 있는가?
  • Data & method: GSE136831 signature 상위 50 cells의 query로 143 studies/1,041 in vivo samples의 monocyte/macrophage를 검색했다; Step 4.
  • 그림 읽기: 점은 cell, x는 평균 FM score로 정렬한 sample, y는 score다.
  • 결과와 의미: 일부 disease samples에 높은-similarity cells가 집중된다.

C–E · Cross-context retrieval

  • 목적: 유사 state가 어떤 조직·질환에 분포하는가?
  • Data & method: FM score 상위 1%의 metadata와 ILD/PDAC UMAP을 표시했다; Step 4.
  • 그림 읽기: Hierarchy별 fraction과 UMAP의 score 집중 위치를 읽는다.
  • 결과와 의미: 서로 다른 tissue에서 FM-like profiles를 찾지만 동일 기능을 직접 증명한 것은 아니다.

F · Attribution

  • 목적: 어떤 gene이 FM-like state를 구분하는가?
  • Data & method: Foreground/background 500 pairs의 distance attribution과 published signatures를 비교했다; Step 5.
  • 그림 읽기: 상위 attribution과 signature membership/enrichment를 함께 읽는다.
  • 결과와 의미: Query에 포함되지 않은 gene까지 prioritization하지만 attribution은 causal perturbation 결과가 아니다.

Takeaway · Similar profile은 새로운 biological hypothesis의 출발점이다.

Figure 5 · Finding an in vitro model of the in vivo FM state

Context · Atlas 검색을 실제 실험계 선택으로 이어 간다. In vitro 후보를 찾고 독립 배양의 expression으로 재현성을 평가한다.

Figure: Heimberg et al., Nature (2025) · CC BY-NC-ND 4.0

A · In vitro search

  • 목적: 실험실에서 FM-like state를 만들 후보 조건이 있는가?
  • Data & method: 17 studies/40 in vitro samples의 myeloid cells를 query했다; Step 4.
  • 그림 읽기: Culture condition별 score를 비교하고 in vivo와 cutoff 목적을 구분한다.
  • 결과와 의미: HSC expansion용 3D hydrogel system이 candidate model로 떠오른다.

B–F · Experimental replication

  • 목적: 후보 배양 조건에서 해당 state가 재현되는가?
  • Data & method: Public Day 5와 연구진 Day 8 scRNA를 Day 0과 비교했다; Step 5.
  • 그림 읽기: Score fraction, marker expression, UMAP을 함께 읽는다.
  • 결과와 의미: 독립 배양에서 FM-like expression을 재현하지만 in vivo fibrosis의 모든 기능이 같다는 뜻은 아니다.

G · Culture purpose

  • 목적: FM-like cells 형성과 원래 배양 목적이 공존하는가?
  • Data & method: 3D culture의 HSC expansion을 확인했다; Step 5.
  • 그림 읽기: HSC abundance/expansion readout을 FM score와 구분한다.
  • 결과와 의미: 기존 culture system을 새로운 cell-state model로 재해석할 수 있다.

Takeaway · Retrieval → culture nomination → independent expression validation의 흐름이다.

Limitations

  • 높은 similarity는 같은 기능·기원·causal disease mechanism의 증명이 아니다. FM query를 만든 signature와 검색 결과를 설명하는 attribution도 독립적 치료 검증은 아니다.
  • Training에서 드문 tissue/state와 cell line의 거리는 불확실하다. Low-confidence flag는 정답 확률로 calibration된 값이 아니다.
  • Annotation용 index와 전체 검색용 index는 다르며, 0.02/0.05초 runtime은 논문 hardware·작업 단위의 값이다.
  • Figure 2C legend는 score<50이지만 실제 image axis는 score<33이다; Methods의 outlier filter도 약 33이다. Figure 5 FM score 25와 합치지 말고 재현 code의 cutoff를 확인한다.
