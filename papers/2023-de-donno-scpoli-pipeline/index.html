Step 1 · Inputs and split

Action

Counts와 condition labels를 정렬하고 reference/query split 및 annotation harmonization을 고정한다.

Input → Output

Cells × genes raw counts, sample/condition IDs, cell-type annotations → minibatches (xi,ci,ai)(x_i,c_i,a_i)(xi​,ci​,ai​).

Intuition

여러 실험실의 같은 종류 세포에 같은 이름표를 붙이고, 일부 실험실 data는 학습이 끝난 뒤 시험문제로 남긴다.

Details

xi∈RGx_i\in\mathbb R^Gxi​∈RG는 cell iii의 gene counts, cic_ici​는 sample/condition, aia_iai​는 cell label이다. 여러 condition covariates와 여러 annotation resolutions를 제공할 수 있다. 각각의 condition에 별도 embedding table을 두고 vectors를 concatenate한다.

Reference와 query는 같은 input features와 순서를 써야 한다(모델의 dimension consistency). Query를 보고 reference split이나 unknown threshold를 뒤늦게 최적화하면 평가가 낙관적일 수 있다(일반 evaluation 원칙).

Step 2 · Conditional generative model

Action

Expression을 설명하는 cell latent와 sample differences를 설명하는 learnable condition vectors를 함께 학습한다.

Input → Output

(xi,ci)(x_i,c_i)(xi​,ci​) → latent posterior qφ(zi∣xi,sci)q_\varphi(z_i\mid x_i,s_{c_i})qφ​(zi​∣xi​,sci​​), count likelihood, trainable sample embeddings.

Intuition

세포 identity를 설명하는 좌표와 실험 조건을 설명하는 작은 메모를 따로 만들고 둘을 합쳐 원래 counts를 설명한다.

Details

S∈RNc×ES\in\mathbb R^{N_c\times E}S∈RNc​×E는 NcN_cNc​ conditions의 learnable embedding matrix이며 torch.nn.Embedding으로 구현한다. Random initialization 후 network parameters와 같이 backpropagation으로 학습한다. OHE vector의 dimension NcN_cNc​ 대신 고정 dimension EEE가 들어간다.

pθ(x∣c)=∫pθ(x∣z,c)pθ(z∣c) dz,p_\theta(x\mid c)=\int p_\theta(x\mid z,c)p_\theta(z\mid c)\,dz, pθ​(x∣c)=∫pθ​(x∣z,c)pθ​(z∣c)dz,

LCVAE=−Eqφ,S(z∣x,c)[log⁡pθ,S(x∣z,c)]+DKL(qφ,S(z∣x,c)∥p(z)).\mathcal L_{CVAE}=-E_{q_{\varphi,S}(z\mid x,c)}[\log p_{\theta,S}(x\mid z,c)]+D_{KL}(q_{\varphi,S}(z\mid x,c)\Vert p(z)). LCVAE​=−Eqφ,S​(z∣x,c)​[logpθ,S​(x∣z,c)]+DKL​(qφ,S​(z∣x,c)∥p(z)).

첫 항은 negative log-likelihood reconstruction, 두 번째는 latent regularization이다. Gene counts는 negative-binomial likelihood, ATAC는 Poisson likelihood를 쓴다. Loss는 maximize하는 ELBO 자체가 아니라 minimize하는 negative-ELBO 형태다. Encoder는 φ\varphiφ, decoder는 θ\thetaθ로 일관되게 표기한다.

Parameter scalability (bias 제외, first-layer comparison):

PscPoli=NcE+(G+E)Henc+(D+E)Hdec,P_{scPoli}=N_cE+(G+E)H_{enc}+(D+E)H_{dec}, PscPoli​=Nc​E+(G+E)Henc​+(D+E)Hdec​,

POHE=(G+Nc)Henc+(D+Nc)Hdec.P_{OHE}=(G+N_c)H_{enc}+(D+N_c)H_{dec}. POHE​=(G+Nc​)Henc​+(D+Nc​)Hdec​.

DDD는 cell latent dimension, H=Henc+HdecH=H_{enc}+H_{dec}H=Henc​+Hdec​라 하면 PscPoli<POHEP_{scPoli}<P_{OHE}PscPoli​<POHE​의 조건은

E<NcHNc+H.E<\frac{N_cH}{N_c+H}. E<Nc​+HNc​H​.

Embedding이 언제나 parameter를 줄이는 것은 아니다. Sample이 적을 때는 embedding dimension 선택에 따라 이득이 작거나 없다.

Step 3 · Prototypes and training

Action

같은 cell type의 평균 latent prototype을 만들고 cells를 그 prototype 쪽으로 당기는 supervised loss를 더한다.

Input → Output

Pretrained cell embeddings + labels → prototypes pkp_kpk​, fine-tuned reference model and two embedding spaces.

Intuition

각 cell type의 대표 위치를 지도에 표시하고 같은 이름표의 cells가 그 주변에 모이도록 돕는다. 대표 위치를 잘못 정하면 잘못된 annotation도 강화될 수 있다.

Details

Kk={i:ai=k},pk=1∣Kk∣∑i∈Kkzi,\mathcal K_k=\{i:a_i=k\},\quad p_k=\frac1{|\mathcal K_k|}\sum_{i\in\mathcal K_k}z_i, Kk​={i:ai​=k},pk​=∣Kk​∣1​i∈Kk​∑​zi​,

dp(z,p)=(∑d=1D∣zd−pd∣p)1/p,Lprototype=1Ncell∑i  labeleddp(zi,pai),d_p(z,p)=\left(\sum_{d=1}^{D}|z_d-p_d|^p\right)^{1/p},\quad \mathcal L_{prototype}=\frac1{N_{cell}}\sum_{i\;\mathrm{labeled}}d_p(z_i,p_{a_i}),dp​(z,p)=(d=1∑D​∣zd​−pd​∣p)1/p,Lprototype​=Ncell​1​ilabeled∑​dp​(zi​,pai​​),

Ltotal=LCVAE+ηLprototype.\mathcal L_{total}=\mathcal L_{CVAE}+\eta\mathcal L_{prototype}. Ltotal​=LCVAE​+ηLprototype​.

p=2p=2p=2는 Euclidean, p=1p=1p=1은 Manhattan distance다. 원문 Eq.12의 vector notation을 여기서는 component sum까지 풀어 썼다. Multiple annotation levels이면 각 level의 prototype distance term을 더한다. η\etaη는 supervised attraction의 강도다.

Training sequence:

  1. Reference condition embeddings를 초기화하고 CVAE-only pretraining을 한다.
  2. Labeled cells의 latent means로 prototypes를 만든다.
  3. CVAE+η·prototype loss로 fine-tuning한다.
  4. Weights·condition embeddings·cell-type prototypes를 함께 저장한다.

Partially unlabeled data는 Louvain clusters로 unlabeled prototypes도 만든다. Unlabeled prototypes는 supervised prototype loss에 넣지 않고 downstream annotation용으로 둔다.

Verified parameters

Main Methods: Adam, learning rate .001; pretraining/fine-tuning ratio 표현은 .9. 단 이를 모든 run의 exact epochs라고 일반화하지 않는다. S15 cost analysis는 명시적으로 100 epochs 중 80 pretraining이다.

Step 4 · Query mapping

Action

Reference network를 고정하고 query의 새 condition embeddings를 학습한 뒤 nearest prototype으로 labels와 uncertainty를 계산한다.

Input → Output

Stored reference model/prototypes + aligned query counts → query cell embeddings, predicted labels, distance-based uncertainty, optional unknown labels.

Intuition

기존 도시 지도를 다시 그리지 않고 새 sample이 들어오는 입구의 변환만 학습한다. 가장 가까운 대표 장소에 이름을 붙이되 너무 멀면 억지로 이름 붙이지 않는다.

Details

Reference encoder/decoder weights를 freeze하고 query conditions McM_cMc​개의 새 embedding rows만 trainable하게 만든다. Query도 reference와 같은 condition-covariate 개수를 제공해야 한다. Pretraining은 CVAE loss, labeled query가 있으면 fine-tuning에서 supervised prototype term을 쓸 수 있다. All-unlabeled query면 loss는 CVAE-only이며 Louvain-derived unlabeled prototypes는 loss에 쓰지 않는다.

a^i=arg⁡min⁡k∈Krefd(zi,pk),ui=min⁡k∈Krefd(zi,pk).\hat a_i=\arg\min_{k\in\mathcal K_{ref}}d(z_i,p_k),\qquad u_i=\min_{k\in\mathcal K_{ref}}d(z_i,p_k).a^i​=argk∈Kref​min​d(zi​,pk​),ui​=k∈Kref​min​d(zi​,pk​).

νi\nu_iνi​가 크면 known prototypes로 설명하기 어려운 cell이다. Upper bound가 없으며 옵션으로 [0,1] scaling을 하더라도 calibrated posterior error probability가 되지는 않는다. Universal default unknown cutoff는 없다. 원문은 uncertainty distribution을 보고 quantile을 정했다: healthy HLCA query는 90% quantile, cancer query는 더 많은 unknown을 예상하여 낮은 quantile을 쓴다고 설명하지만 공개 figure notebook에서는 80% quantile을 확인했다(아래 code audit). 다만 같은 notebook이 앞부분에서 fixed threshold .5를 사용하므로 하나의 일관된 threshold로 모든 reported metrics가 계산되었다고 단정하지 않는다. Validation-held-out query ROC로 cutoff를 정하는 대안도 언급한다.

Step 5 · Evaluation and sample analysis

Action

Cell-level integration, cell-label transfer, sample-level associations를 서로 다른 endpoints로 평가한다.

Input → Output

Cell embeddings / predictions / sample embeddings / metadata → scIB metrics, F1, sample classifiers, PCs·gene associations.

Intuition

‘같은 cell type이 잘 섞였나’, ‘새 cell 이름이 맞나’, ‘sample끼리 어떤 차이가 남나’는 세 개의 시험이다.

Details

Integration (scIB 1.0.0):

  • Biological conservation: cell-type ASW, isolated-label F1, isolated-label silhouette, NMI, ARI.
  • Batch mixing: PC regression, graph connectivity, batch ASW.
  • Overall score = .6×mean biological conservation + .4×mean batch mixing.

Classification:

F1k=2 precisionk recallkprecisionk+recallk,F1macro=1K∑kF1k,F1weighted=∑knk∑lnlF1k.F1_k=\frac{2\,precision_k\,recall_k}{precision_k+recall_k},\quad F1_{macro}=\frac1K\sum_kF1_k,\quad F1_{weighted}=\sum_k\frac{n_k}{\sum_ln_l}F1_k.F1k​=precisionk​+recallk​2precisionk​recallk​​,F1macro​=K1​k∑​F1k​,F1weighted​=k∑​∑l​nl​nk​​F1k​.

Macro score는 rare types에도 같은 비중을 준다. SVM처럼 classification-only methods를 integration score가 없다고 무조건 열등하다고 평가하지 않는다.

Original benchmark versions: scArches scVI/scANVI .5.3 defaults; Seurat v3 workflow implemented in Seurat 4.0.3 with supervised PCA dimension 50; Symphony .1.0 defaults; MARS defaults; LinearSVC from scikit-learn .24.2. Defaults는 사용한 version에 귀속된다.

Sample analysis:

  1. Learned sample vectors의 PCA를 계산한다.
  2. Metadata–PC association은 covariates를 predictors, PC scores를 outcomes로 한 regression에서 adjusted R2R^2R2를 보고한다:

Radj2=1−(1−R2)n−1n−p−1.R^2_{adj}=1-(1-R^2)\frac{n-1}{n-p-1}. Radj2​=1−(1−R2)n−p−1n−1​.

nnn은 samples, ppp는 predictors 수다. Su severity analysis의 main Results는 ordinal regression이라고 별도 설명하므로 모두 같은 ordinary linear model이라고 섞지 않는다. 3. Su dataset에서 30/270 samples를 unlabeled로 두고 kNN disease classification; comparison은 five-fold CV로 sample embeddings vs sample mean expression vs mean scVI latent vectors를 비교한다. Published text에는 k가 없지만 공개 FigureSu notebook의 multiclass classifier는 k=4다; coarse binary grouping은 k=3이며 아래 code audit의 version/context를 구분한다. 4. PBMC atlas: sample mean gene expression과 sample-embedding PCs의 Pearson rrr를 계산, P<.01P<.01P<.01과 ∣r∣>.3|r|>.3∣r∣>.3로 filter한다. Figure caption의 rrr를 따른다; 본문의 ‘coefficient of determination’은 부호 있는 correlation과 맞지 않는다. 5. PC-associated gene sets로 pathway analysis; Supplement S13은 hypergeometric test와 BH correction을 명시한다. Metadata correlation은 confounding을 제거한 causal effect가 아니다.

Notation audit

  • Main text는 pancreas nine studies, Methods는 eight batches라고 적는다. Study/batch definitions의 차이인지 reproduce config 확인 전 하나로 정정하지 않는다.
  • CVAE notation prose는 처음 θ=model/decoder, φ=encoder처럼 쓰다가 Eq.2 아래 encoder/decoder 설명을 뒤집는다. 본 페이지는 qφq_\varphiqφ​ encoder, pθp_\thetapθ​ decoder convention을 일관되게 사용한다.
  • Prototype indicator는 원문에 label aia_iai​를 index set K(k)\mathcal K(k)K(k)의 원소인지 검사하는 형태로 적혀 있다. 여기서는 {i:ai=k}\{i:a_i=k\}{i:ai​=k}로 의미를 명확하게 풀어 쓴다.
  • Main Results의 ‘coefficients of determination’와 Fig6 caption의 signed rrr cutoff가 다르므로 ∣r∣>.3|r|>.3∣r∣>.3를 따른다.
  • Main Results의 TS LPY2/TSLPY2 spelling과 S13의 TSPYL2가 다르다. Supplement label은 TSPYL2이다.
  • Default pretraining ratio prose .9와 cost benchmark 80/100은 서로 다른 설정이다. 모든 study를 90 epochs pretraining으로 채우지 않는다.
  • Main figures는 publisher HTML의 caption-free PNG를 사용했다. New publication figures를 PDF crop으로 새로 저장했다고 주장하지 않는다.

Run it yourself

scArches와 scPoli reproduction repository에서 논문 당시 configs와 data references를 확보한다.

순서: same-gene counts 정렬 → sample/label harmonization → held-out study split → Table S2 model별 config → pretrain/fine-tune → stored prototypes/weights 보관 → freeze-and-map query → validation data로 unknown rule 결정 → integration/label metrics를 둘 다 보고 → sample PCA confounders를 inspection한다.

Source-code training run과 GPU benchmark는 이번 reconstruction에서 실행하지 않았다. 일부 public notebooks를 아래처럼 확인했지만 전체 training configs와 published output의 일대일 provenance를 검증한 것은 아니다. Batch size·모든 model seeds·exact KL schedule은 여전히 전체 run별로 확인이 필요하다.

  • Revision benchmark config:100/80 epochs, embedding5, latent10, hidden layers1, η10, alpha100; p search1/2.
  • Stability script: runs1…5를 NumPy·torch seed로 쓰고 data subsampling은 random_state42; 해당 실험 config100/80 epochs. 다른 모든 experiments의 seed도 같다고 일반화하지 않는다.
  • Legacy disease-query notebook: labeled_indices=[]; train50/pre40, alpha1000, η0, clustering_res2, weight_decay0, stratified sampling=False, best_reload=False. Early-stopping kwargs는 val_landmark_loss/min, threshold0, patience20, reduce_lr=True, lr_patience13, lr_factor.1이다. Revised model과 legacy mapping class를 한 run으로 합치지 않는다.

Notebook column명 log_probs만으로 이 값이 calibrated probability라고 해석하지 않는다. 원 method의 uncertainty 정의는 nearest-prototype distance이며, actual saved AnnData의 column 생성 provenance까지 확인해야 한다.
