1. QC and participant split

Task

Reads를 clone 단위로 정리하고 같은 사람의 정보가 test로 새지 않게 한다.

Input → Output

cDNA IgH/TRB reads → productive clonotypes와 train-1/train-2/validation/test sets.

Intuition

한 사람의 문장 절반을 학습한 뒤 나머지를 ‘새 사람’이라고 평가하지 않는다.

Details

IgBLAST v1.3.0 productive rearrangements, V-match score IgH≥200/TRB≥80, CDR3 length≥8 amino acids를 사용한다. Within-person clone grouping은 V/J/length 일치와 BCR 90%/TCR 95% identity다. 각 replicate/isotype에서 clone 대표 한 개를 유지한다; 대표는 RNA reads가 가장 많은 sequence다. Public-cluster threshold와 혼동하지 않는다.

IgG/IgA와 SHM≥1%의 IgM/D를 사용한다. 3-fold stratified CV의 split unit은 participant이며 모든 timepoints/replicates를 묶는다. Base-model selection은 validation, two-stage sequence fit은 train-1, aggregation fit은 train-2, metamodel fit은 validation, 최종 평가는 test다.

Toy example

숫자는 설명용: donor A의 day0/day7이 있으면 둘 다 같은 fold에 둔다. A의 sequence 10,000개를 나누어 8,000 train/2,000 test로 넣는 것은 새로운 사람에 대한 generalization test가 아니다.

2. Three representations

Task

각 repertoire를 서로 보완적인 feature로 바꾼다.

Input → Output

Clones → composition vector, disease-cluster vector, sequence embedding.

Intuition

전체 gene usage 분포, 공유되는 sequence family, 더 넓은 learned similarity를 각각 보는 세 관찰자다.

Details

Model Features / primary-cohort choice
1 BCR V–J count→proportion→log/Z-score→15 PCs per isotype + median SHM + SHM≥1% fraction; 51 features; elastic net ratio 0.25
1 TCR 15 PCs; lasso logistic regression
2 Same V/J/length, single-linkage identity BCR≥85%, TCR≥90%; Fisher enrichment threshold grid 0.0005–0.05; train-2 MCC selection
2 classifier Disease-enriched cluster membership counts; BCR ridge, TCR lasso; no match→abstain
3 embedding ESM-2 30 layers/150M parameters; mean-pool sequence-length axis to 640 dimensions; BCR additionally SHM
3 sequence models Per IGHV×isotype or TRBV; primary BCR random forest, TCR one-vs-rest ridge

Model 1 rare-V filtering과PCA 등은 training만으로 fit한다. Model 2의 Fisher table은 read 수가 아니라 cluster를 갖는 사람 수다. Cluster consensus는 clone size로 position별 weighted vote를 한다.

교육용 identity 식은 같은 길이 L에서 I=1−m/LI=1-m/LI=1−m/L이며 m은 substitutions 수다. 동일 V/J/length 조건을 생략하고 identity만 적용하지 않는다.

Toy example

숫자는 설명용: 길이 20에서 3 substitutions이면 identity=85%로 BCR public-cluster 기준을 만족하지만 90% TCR 기준은 만족하지 못한다. Counts (3,1)을 비율로 바꾸면 (0.75,0.25)이며 reads (300,1)로 바꿔 계산하면 다른 model이다.

3. Sequence aggregation

Task

Noisy sequence predictions를 category별로 요약해 sample-level prediction으로 바꾼다.

Input → Output

Sequence class probability vectors → V/isotype category features → sample predictions.

Intuition

환자의 모든 receptor가 질병 표지는 아니므로 하나의 sequence를 확정 진단처럼 읽지 않고 여러 신호를 모은다.

Details

Weak label은 sequence의 실제 binding label이 아니라 donor의 immune state다. 서로 다른 sequence-category model의 probability calibration이 같다고 가정하지 않아 category 안에서 먼저 평균한다. Second-stage model은 one-vs-rest이며 해당 class probabilities만 feature로 넣고, gene-frequency weighting을 적용한다. Top 50% prevalent V genes를 사용한다.

Primary BCR는 mean aggregation; primary TCR는 maximum entropy보다 20% 낮은 cutoff를 쓴다:

H(p)=−∑k=1Kpklog⁡pk,Hmax=log⁡K,H(p)≤0.8Hmax.H(p)=-\sum_{k=1}^Kp_k\log p_k,\qquad H_{max}=\log K,\qquad H(p)\le0.8H_{max}. H(p)=−k=1∑K​pk​logpk​,Hmax​=logK,H(p)≤0.8Hmax​.

이는 entropy가 큰 sequence의 상위 20%를 순위로 제거하는 것과 다르다. Median, bottom-10%-trimmed mean, 10%/20%-below-max entropy alternatives를 validation에서 비교했다. Second stage는 random forest이며 sequence stage와 다른 train-2에서 fit한다.

Toy example

숫자는 설명용: K=2이면 cutoff=0.8 log2≈0.5545; p=(0.5,0.5)의 entropy≈0.6931은 제외하고 (0.9,0.1)의 entropy≈0.3251은 유지한다. 남은 probabilities (0.9,0.8)의 mean은 0.85다.

4. Ensemble and evaluation

Task

3 BCR+3 TCR model의 class probabilities를 합친다.

Input → Output

Validation-set base predictions → ridge multinomial metamodel → test probabilities.

Intuition

여러 전문가의 답을 합치는 규칙을, 그 전문가가 외운 training 답안이 아니라 별도 validation 예제에서 배운다.

Details

zi=[piB1,piB2,piB3,piT1,piT2,piT3],p^i=softmax(Wzi+b).z_i=[p_i^{B1},p_i^{B2},p_i^{B3},p_i^{T1},p_i^{T2},p_i^{T3}],\qquad \hat p_i=\mathrm{softmax}(Wz_i+b). zi​=[piB1​,piB2​,piB3​,piT1​,piT2​,piT3​],p^​i​=softmax(Wzi​+b).

위 식은 logistic metamodel의 교육용 표기다. Ridge regularization과 inverse-class-frequency weights를 사용한다. Model 2 abstention은 ensemble에도 전달한다. AUROC/AP는 probability scale이 fold별로 다를 수 있어 fold별 계산 후 요약하고, accuracy용 labels는 concatenate한다. Multiclass overall metric은 class-size-weighted one-vs-one이며 disease별은 one-vs-rest다.

Toy example

숫자는 설명용: 100 samples 중 3개 abstention이면 나머지의 accuracy가 90/97이어도 전체 accuracy는 90/100이다. AUROC는 abstention probabilities가 없어 그 3개를 제외하므로 accuracy와 분모가 다르다.

5. External and sequence validation

Task

새 cohort generalization과 known-binder detection을 별도 시험한다.

Input → Output

Independent repertoires / binder databases → sample predictions / sequence enrichment.

Intuition

환자 진단 시험과 항체 하나의 결합 시험은 서로 다른 시험지다.

Details

External cDNA cohorts는 nomenclature를 재처리하고 일부 held-out external samples로 class decision thresholds를 MCC에 맞춰 조절했다. gDNA TCR analysis는 retraining을 포함한다.

CoV-AbDab 2023-06-13 snapshot의 known human binders를 igblastp로 annotation하고 BCR 95% identity로 deduplicate한다. Isotype이 없으므로 IgG sequence models를 적용한다. Model 2와 3는 global fold에서 고정된 모델이며 external binder에 새 classifier를 fit한 것이 아니다. Healthy-donor sequences를 donor 단위로 유지한 1,000 permutations와 AUPRC/prevalence fold-change를 사용한다.

Toy example

숫자는 설명용: binder prevalence=0.1, AUPRC=0.3이면 baseline 대비 3배지만 precision 100%라는 뜻은 아니다. 같은 AUROC여도 prevalence가 바뀌면 precision은 달라질 수 있다.

Related figures

Implementation checks and discrepancies

  • 550은 patient가 아니라 paired sample 수이며 paired participants는 542명이다.
  • Entropy cutoff는 순위 상위 20% 제거가 아니고, primary-cohort TCR branch의 maximum-entropy-relative cutoff다. Primary BCR는 mean이다.
  • ESM-2 embedding은 구조/결합을 직접 측정하거나 검증한 좌표가 아니다.
  • Results healthy n=220과 Methods n=217의 cohort-accounting 차이는 Supplementary Table 1 audit가 필요하다.
  • kBET 평균 rejection 18.2%가 confounding 부재의 증명은 아니며 COVID BCR의 rejection은 더 높다.

Reproduction and sources

Final-paper Methods, official code, processed data.

Main Methods의 sequencing, split, Models 1–3, ensemble, external evaluation을 확인했다. Supplementary PDF 접근은 browser challenge로 막혔으며, code 전체를 실행하거나 Supplementary Tables를 재검증한 것은 아니다. 환경·classifier 선택은 primary cohort와 재학습 cohort를 구분한다.
