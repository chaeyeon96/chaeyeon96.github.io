Step 1 · Inputs and molecular classification

Action · 동일 cell barcode·UMI의 alignment evidence를 합쳐 IgH molecule을 분류한다.

Input → Output · 5′ scRNA-seq BAM + transcriptome count object + genome-specific sterile TSS annotation → 2S×N2S\times N2S×N isotype count matrix.

Intuition · 편지 조각의 위치로 완성된 BCR 설계도인지, 다음 constant region 사용을 준비하는 짧은 transcript인지 구별한다. 조각이 부족하면 “모름”으로 둔다.

Details

SSS는 species의 IgH C-gene categories, NNN은 cells다. Barcode CB, molecule UB가 기본 tag다. BAM을 세 번 scan하여 (1) V/D/J exons, (2) C exons, (3) sterile TSS에서 첫 C exon 직전까지의 5′ C region에 실제로 aligned bases가 있는 reads를 얻는다. Splicing gap이 region을 가로지르는 것만으로는 evidence가 아니며 CB/UB가 없는 reads는 제외한다.

Evidence for one CB–UB Classification
≥1 VDJ read 및 ≥1 C-exon read Productive; 최소 2 reads
≥1 5′ C read, VDJ read 없음; C read optional Sterile
그 외 insufficient evidence Uninformative; isotype matrix에서 제외

Counts는 reads 수가 아니라 해당 조합의 molecules 수다. Germline sterile TSS는 문헌 sequences를 BLAT v36×4로 hg38/mm10에 mapping해 구성했고 IgD의 sterile TSS는 잘 정의되지 않아 별도 추정하지 않았다. Both loci는 minus strand다. Supplementary Table 1의 좌표를 package annotation으로 사용하며 다른 genome build에 그대로 재사용하지 않는다.

Step 2 · NMF and CSR potential

Action · Reference isotype signatures로 새 cells의 naive-like weight를 계산한다.

Input → Output · Reference/target isotype matrices → signature matrix, cell weights, CSR potential in [0,1].

Intuition · 여러 isotype transcript를 naive-like / switched-like 패턴의 혼합으로 요약한다. 한 transcript의 dropout보다 여러 transcript의 공통 pattern을 이용한다.

Details

T≈PC,T∈R+2S×N,P∈R+2S×H,C∈R+H×N.T\approx PC,\quad T\in\mathbb R_+^{2S\times N},\quad P\in\mathbb R_+^{2S\times H},\quad C\in\mathbb R_+^{H\times N}. T≈PC,T∈R+2S×N​,P∈R+2S×H​,C∈R+H×N​.

NMF는 non-negative P,CP,CP,C를 함께 추정한다. 새로운 T′T'T′에는 이미 학습한 PPP를 고정하고 NNLS로 C′C'C′를 추정한다. 일반적 least-squares 표현은 min⁡C′≥0∥T′−PC′∥F2\min_{C'\ge0}\|T'-PC'\|_F^2minC′≥0​∥T′−PC′∥F2​다.

Mouse H=3→2는 Supplementary Methods가 명확히 설명하는 단계다. Main Methods의 “two-signature matrix”만 보고 처음부터 H=2로 학습하면 다르다.

Naive-associated row vvv의 weights에 대해

cvj′′=cvj′−min⁡jcvj′max⁡jcvj′−min⁡jcvj′,CSRj=1−cvj′′.c''_{vj}=\frac{c'_{vj}-\min_jc'_{vj}}{\max_jc'_{vj}-\min_jc'_{vj}},\qquad CSR_j=1-c''_{vj}. cvj′′​=maxj​cvj′​−minj​cvj′​cvj′​−minj​cvj′​​,CSRj​=1−cvj′′​.

높은 값은 less naive-like / more switched-like다. 미래에 switching할 여력이 더 크다는 뜻으로 읽지 않는다. Min–max normalization은 dataset 범위에 의존하므로 같은 numerical value가 모든 cohort에서 absolute biological time을 뜻하지 않는다. 모든 weight가 같아 분모 0이면 정보 없는 ordering이므로 임의 숫자를 채우지 않고 software handling을 확인한다.

Naive weights [8,5,2]를 min–max scale하면 [1,0.5,0], CSR potential은 [0,0.5,1]이다. 이는 정확한 분해가 가능한 장난감 예이며 실제 signatures에는 더 많은 productive/sterile rows가 있다.

Step 3 · SHM alternative

Action · Matched BCR V-gene sequence의 germline divergence를 ordering으로 사용한다.

Input → Output · scBCR heavy-chain annotation + germline identity → scaled SHM in [0,1].

Intuition · Isotype profile 대신 sequence가 germline에서 얼마나 달라졌는지를 maturation의 다른 자로 쓴다.

Details

SHM=1−IV,SHM=1-I_V, SHM=1−IV​,

IVI_VIV​는 assigned germline V gene에 대한 nucleotide identity를 0–1 fraction으로 표현한 값이다. 원문은 identity 뒤에 (%)라 적으므로 입력이 98%면 0.98로 바꿔야 한다. 이후 CSR와 유사한 [0,1] rescaling을 수행하되 mutation가 많을수록 높은 방향을 유지한다.

filtered_contig_annotations.csv를 cell별 metadata에 결합한다. Heavy/light chain이 여러 개면 chain당 maximal UMI sequence를 대표로 선택한다(Supplementary Methods). 이는 genuine dual-chain biology와 doublet 구분을 완전히 해결한 것이 아니다. Hong data는 IMGT/HighV-Quest AIRR output을 merge하여 germline identity를 얻었다.

Toy example

숫자는 설명용. Identities [1.00,0.98,0.94] → raw SHM [0,0.02,0.06] → min–max SHM [0,1/3,1]. CSR ordering과 SHM ordering이 달라도 계산 오류라고 단정하지 않는다; 두 processes는 다르다.

Related figures · Figure 1B, Figure 6D–F.

Step 4 · CellRank transition matrix

Action · Transcriptomic neighbors에 CSR 또는 SHM 방향성을 추가한다.

Input → Output · kNN graph + one biological ordering → row-stochastic cell-by-cell matrix MMM.

Intuition · 가까운 cell states 사이를 이동하되 biological maturation 방향에 조금 더 무게를 둔다.

Details

논문의 CellRank 1.5.1 및 scanpy 1.9.1 setting은

M=0.8MkNN+0.2MPseudotime.M=0.8M_{kNN}+0.2M_{Pseudotime}. M=0.8MkNN​+0.2MPseudotime​.

MkNNM_{kNN}MkNN​은 ConnectivityKernel, MPseudotimeM_{Pseudotime}MPseudotime​은 CSR/SHM 기반 PseudotimeKernel이다. MijM_{ij}Mij​는 현재 cell-state iii에서 jjj로 갈 model probability다. 두 kernels는 각각 row-stochastic이므로 mixture도 row sum 1을 유지한다. 이 비율은 publication-specific이며 최신 default를 소급 적용하지 않는다. CSR와 SHM을 모두 한꺼번에 합친 식이 아니다.

Toy example

숫자는 설명용. 한 cell에서 connectivity row [0.5,0.5], pseudotime row [0.1,0.9]라면 mixture는 [0.42,0.58]이다. Directional evidence를 넣어도 모든 backward transition을 여기서 0으로 만드는 것은 아니다. Biological impossibility를 반영한 CSR backward-flux exclusion은 다음 pruning 단계다.

Step 5 · TPT and uncertainty

Action · Source→target의 가능한 경로 ensemble을 요약하고 significance를 평가한다.

Input → Output · N×NN\times NN×N transition matrix + source/target cell sets + grouping → coarse-grained flux, stationary distribution, MFPT, paths, null/bootstrap estimates.

Intuition · 지도에서 한 개의 “최적 경로”만 고르지 않고 많은 가능한 이동이 어떤 연결을 얼마나 거치는지 센다.

Details

Python deeptime 0.4.2의 ReactiveFlux와 coarse_grain()을 사용한다. 먼저 single-cell matrix에 TPT를 fit하고 사용자 celltype/isotype grouping으로 flux를 합친다. 단순히 cluster 평균 expression으로 시작하는 것과 다르다.

Relative flux Fij′=Fij/∑i,jFijF'_{ij}=F_{ij}/\sum_{i,j}F_{ij}Fij′​=Fij​/∑i,j​Fij​ 전체 reactive flux 중 해당 edge의 몫 실제 cells의 switch percentage

Stationary distribution의 정의 (일반적 Markov 설명):

πM=π,∑iπi=1,πi≥0.\pi M=\pi,\quad \sum_i\pi_i=1,\quad\pi_i\ge0. πM=π,i∑​πi​=1,πi​≥0.

Ergodicity 같은 조건이 있으면 초기 distribution p0p_0p0​에서 pk=p0Mkp_k=p_0M^kpk​=p0​Mk가 π\piπ로 수렴한다. 이 조건이 없는 chain에는 uniqueness/convergence가 보장되지 않는다. Paper는 full CSR biology가 실제 equilibrium을 이룬다고 실험적으로 증명한 것이 아니라 모델의 stationary occupancy를 비교한다.

Source/target은 실제 관측된 states 중 process의 양끝에 가까운 것을 고른다. Human CSR 예는 IgM→IgA2, mouse는 IgM→IgA이지만 dataset에 없는 target을 만들면 안 된다. Kim vaccination은 IgE/IgA2가 없어 IgM→IgG4; Aicda KO는 IgM→IgG2b를 사용했다. Celltype transitions는 naive-like→plasma/plasmablast 등이 가능하다.

Null shuffle은 biological null을 완벽히 대표한다는 보장이 없고 source/target 선택에 flux가 민감하다. Bootstrap은 sampled-cell variability를 반영하며 독립 donor replication을 대체하지 않는다.

Step 6 · Experimental and predictive validation

Action · Inferred quantity에 맞는 실측 counterpart를 선택한다.

Input → Output · Earlier snapshot / perturbed cells → later BCR composition 또는 observed perturbed distribution과 comparison.

Intuition · 예측한 대상과 실제 비교하는 대상이 같은지 먼저 확인한다.

Details

In vitro assay는 donor 3명 naive B cells, 250,000 cells/well, anti-IgM 1 μg/ml + CD40L 1 μg/ml + IFNγ 50 ng/ml, 37°C/5% CO₂, D0/D3/D6다. Day 2에 medium을 refresh했다. D3 flow는 cell availability 때문에 donors pooled sample이며 independent donor flow replicate 세 개로 계산하지 않는다. Library는 10x 5′ v2, expected recovery 5,000 cells/lane, target GEX 50,000 reads 및 BCR/feature barcode 5,000 reads로 보고되었다. 표기는 논문 그대로이며 depth별 achieved reads를 뜻하지 않는다.

Kim validation은 각 isotype으로 들어오는 total inward flux uj=∑iFiju_j=\sum_i F_{ij}uj​=∑i​Fij​와 다음 시점 BCR fraction bjb_jbj​를 비교한다.

cosine⁡(u,b)=u⋅b∥u∥2∥b∥2.\operatorname{cosine}(u,b)=\frac{u\cdot b}{\|u\|_2\|b\|_2}. cosine(u,b)=∥u∥2​∥b∥2​u⋅b​.

W7→W15, W15→W29를 donor별로 평가했다. Knockout Figure 6은 대신 stationary distribution과 measured BCR composition을 비교한다. 두 validation에서 같은 output을 썼다고 서술하면 안 된다.

Toy example

숫자는 설명용. Predicted [2,1], observed [0.6,0.4]의 cosine은 1.6/(50.52)≈0.99231.6/(\sqrt5\sqrt{0.52})\approx0.99231.6/(5​0.52​)≈0.9923이다. 높은 cosine은 composition 방향의 유사성이지 count calibration, lineage accuracy, exact transition rate를 보장하지 않는다.

Supplementary Note 1은 dominant isotype >95%일 때 prediction 저하를 보였다. Note 2는 2,000 genes·3 states·state당 10,000 cells simulation에서 downsampling을 수행해 10 cells/state까지 robustness를 보였다. Real rare populations의 보편적 sample-size guarantee로 사용하지 않는다.

Reproducibility

Official sciCSR repository, processed data와 paper의 accessions에서 시작한다. prepare_sciCSR가 R reticulate용 conda environment를 준비한다. Publication stack은 R 4.2.2, Seurat 4.2.2, Python 3.9.12, CellRank 1.5.1, deeptime 0.4.2, scVelo 0.2.4, SeuratDisk 0.0.0.9020이다. In vitro preprocessing versions는 위 표처럼 별도다.

실행 전 species/build, 5′ protocol, CB/UB tags, matched cell IDs, isotype composition, source/target 존재를 확인한다. Main figure 재현 시 version-pinned script를 사용하고 current package defaults로 소급하지 않는다. 본 정리에서는 toy arithmetic/plot만 실행했으며 full sciCSR fit·source-data workbook 재계산은 하지 않았다.

Notation and source discrepancies

  • Main text의 two-signature output과 Supplementary의 mouse H=3 training은 모순이라기보다 중간 단계 생략이다; H=3→merged 2를 명시해야 한다.
  • SHM 식의 identity “(%)”는 0–1 scale과 구분해야 한다.
  • “CSR potential”은 switched-like direction으로 정의되어 biological remaining potential이라는 일상적 의미와 반대일 수 있다.
  • General preprocessing Methods의 FindVariableMarkers 표기는 그대로 execution-ready API라고 가정하지 말고 pinned code의 actual function을 확인한다.
