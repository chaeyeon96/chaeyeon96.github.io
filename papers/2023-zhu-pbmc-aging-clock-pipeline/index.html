Step 1 · Inputs

하는 일 · Cohort·donor·cell subtype을 보존한 분석 입력을 만든다.

Input → Output · CellRanger count matrices → annotated cells, donor metadata.

쉽게 말하면 · 세포는 관찰 단위지만 나이의 독립 표본은 사람이라는 표지를 끝까지 붙인다.

Details · SE는 17명(28–77세), GM을 더한 training은 28명이다. GM의 72–100세 범위를 외부 CYCT/WHCT/JOCT에 잘못 적용하면 안 된다. External cohorts는 각각 5명이며 CYCT 29–58, WHCT 37–71, JOCT 50s–80s, SC는 >110세 7명이다.

Procedure Setting
Alignment CellRanger 3 / GRCh38
QC Methods Genes≥3 cells, cells 200–5,000 genes, MT≤15%
Normalization 10,000 counts/cell; HVG에서 mitochondrial/ribosomal genes 제외

Subclustering T/NK, B, myeloid resolution 0.1–0.9

Step 2 · Representation

하는 일 · Donor composition으로 age를 예측하고 chronological-age bias를 구분한다.

Input → Output · Donor×subtype proportion matrix XXX, age yyy → predicted age, AgeDiff/cAgeDiff.

쉽게 말하면 · 여러 세포 비율의 동시 변화를 몇 개의 요약축으로 압축해 나이를 추정한다.

Details · PLSR는 3 components를 사용하고 leave-one-out cross-validation(LOOCV)을 수행한다. VIP≥1을 important feature로 선택한다. Composition model의 top 7 features와 reported PCC=0.88/MAD=8.36은 외부 cohort 성능과 구분해야 한다. 비교 Elastic Net은 alpha=5×10−45\times10^{-4}5×10−4, L1 ratio=0.08이며 |weight|>50을 importance cutoff로 쓴다.

AgeDiffi=Age^i−AgeiAgeDiff_i=\widehat{Age}_i-Age_i AgeDiffi​=Age​i​−Agei​

cAgeDiffi=AgeDiffi−f^(Agei),cPredictedAgei=Age^i−f^(Agei)cAgeDiff_i=AgeDiff_i-\widehat f(Age_i),\quad cPredictedAge_i=\widehat{Age}_i-\widehat f(Age_i) cAgeDiffi​=AgeDiffi​−f​(Agei​),cPredictedAgei​=Age​i​−f​(Agei​)

f^\widehat ff​는 AgeDiff~Age의 LOESS(span 0.5, degree 2)다. Calibration fit에 어떤 donors가 들어갔는지 확인해야 하며 independent calibration이 입증되었다고 단정하지 않는다.

Toy example · 설명용 60세 donor의 prediction이 68세이고 LOESS bias가 +3세면 AgeDiff=8, cAgeDiff=5, corrected prediction=65세다(Python 검산). 좋은 correlation과 작은 absolute error는 별개다.

Step 3 · Testing

하는 일 · Composition과 subtype expression의 aging pattern을 분리한다.

Input → Output · Donor×cell-type summed counts → expression clocks, age trends, SC deviations.

쉽게 말하면 · 세포 종류가 바뀐 것과 같은 종류의 세포가 달라진 것을 따로 묻는다.

Details · Cell-type pseudobulk는 donor별 counts를 합한다. Linear regression으로 proportion 또는 median expression~age를 적합하고 age=110에서 기대값을 계산하여 SC 관찰값과 z-score로 비교한다. 이 값은 training age 범위 밖 extrapolation일 수 있다. Inflammation score는 HALLMARK_INFLAMMATORY_RESPONSE genes의 UMI 합/전체 UMI다. CellPhoneDB 1.1.0은 subtype 내 ≥10% cells에서 발현한 genes를 사용하고 individual별 interaction의 age association을 분석하여 top 100을 시각화한다.

Toy example · 설명용 donor 한 명의 동일 subtype 두 cells가 gene A에서 3,7 counts라면 pseudobulk A=10이다. Expected value 10, reference SD=2, observed 6이면 z=(6−10)/2=−2다(Python 검산); 이것만으로 생물학적 rejuvenation을 증명하지 않는다.

Step 4 · Validation

하는 일 · Observational network와 translation perturbation의 증거를 구분한다.

Input → Output · Age/ribosome/inflammation/clock deviations 및 CHX qPCR → association과 intervention response.

쉽게 말하면 · 함께 변한다는 관찰에, 한 요소를 건드리는 실험을 더하지만 실험 범위 밖 인과까지 확장하지 않는다.

Details · WinMine Bayesian network는 uncorrected SE counts에서 age, ribosome, inflammation, cAgeDiff를 사용한다. Edge는 PCC/slope P<0.05를 바탕으로 읽으며 causal proof가 아니다. Primary monocytes와 THP1에서 CHX 100 μg/ml vs DMSO, harvesting 전 15/30/60/180/360 min 처리를 사용했다. IL6/IL8 qPCR은 GAPDH-normalized 2−ΔΔCt2^{-\Delta\Delta Ct}2−ΔΔCt다.

Toy example · 설명용 treatment ΔCt=5, control ΔCt=3이면 ΔΔCt=2, relative expression=0.25다(Python 검산). 세포 생존율이나 global translation 변화 없이 cytokine-specific 효과라고 단정할 수 없다.

Notation discrepancies and gaps

  • MT cutoff는 Results에서 >10% 제외, Methods에서 >15% 제외다. 재현할 때 사용 코드 확인이 필요하다.
  • Ribosome level은 Results의 median gene expression과 Methods의 calculate_qc_metrics 기반 mean 설명을 혼합하지 않는다.
  • Figure 4H axis는 Time(s), Methods 처리는 minutes다. 임의로 하나를 정답으로 바꾸지 않는다.
  • Methods의 reversed-PLSR 표기 110 × [PLS1 + PLS2]^{-1}은 3-component model 설명과도 맞지 않고 일반적인 matrix inverse 정의가 불명확하다. 실행식으로 옮기지 않는다.
  • Feature selection과 LOESS가 CV fold 안에서 수행됐는지, supplementary 전체와 code가 필요하다.
