scPoli (2023 De Donno)

Population-level integration of single-cell datasets enables multi-scale analysis across samples — De Donno et al.

Cell embedding과 sample embedding을 동시에 학습하고 cell-type prototypes로 reference mapping·label transfer를 연결하는 population-level integration model.

원문 (DOI) Pipeline 따라가기 License · CC BY 4.0
Single-cell Analysis
✦Pipeline

모델식·설정값·손계산 예시는 2023 De Donno - scPoli (Pipeline)에 있다.

Background

기존 CVAE의 one-hot condition은 sample 수가 늘면 input dimension이 커지고 sample 간 관계를 직접 해석하기 어렵다. scPoli는 condition마다 작은 learnable vector를 두고 cell-type prototype loss를 더해 biological structure를 유지한다. Cell-level integration과 sample-level variation exploration은 서로 다른 결과물이다.

모두 기존 공개 실측 datasets의 재분석이다. Embeddings·predicted labels는 모델 출력이며 새로운 expression 측정이 아니다. Main Results의 pancreas ‘nine studies’와 Methods의 ‘eight batches’는 같은 단위인지 확인되지 않아 그대로 구분한다.

Figure 1 · Cell and condition representations

Context · Sample마다 차이가 있지만 같은 cell type은 연결하고 싶다. 먼저 두 종류의 embedding과 prototype을 분리한 뒤 pancreas reference/query 예제로 연결한다.

Figure: De Donno et al., Nature Methods (2023) · CC BY 4.0

A · Reference training

  • 목적: Cell과 sample을 어떻게 함께 표현하는가?
  • Data & method: Expression·sample labels·cell labels로 CVAE와 prototypes를 학습한다 (Pipeline).
  • 그림 읽기: Cell latent z, condition embedding s, prototype p의 위치를 구분한다.
  • 결과와 의미: Condition을 fixed one-hot 대신 learnable vector로 표현한다.

B · Reference mapping

  • 목적: Reference를 다시 학습하지 않고 query를 넣을 수 있는가?
  • Data & method: Encoder/decoder를 고정하고 query condition embeddings만 추가한다 (Pipeline).
  • 그림 읽기: Gray network weights는 frozen parameters이다.
  • 결과와 의미: Stored prototypes를 이용하므로 원 reference cells 없이도 label transfer가 가능하다.

C · Raw cell identities

  • 목적: Integration 전 biological groups는 어떤가?
  • Data & method: 13,093 reference pancreas cells의 raw representation을 UMAP으로 표시한다 (Pipeline).
  • 그림 읽기: 색은 cell type이며 D와 같은 좌표이다.
  • 결과와 의미: Cell-type 분리와 technical separation을 다음 panel과 함께 판단한다.

D · Raw studies

  • 목적: Study-specific separation이 있는가?
  • Data & method: 같은 reference UMAP을 study별로 색칠한다 (Pipeline).
  • 그림 읽기: C와 좌표를 바꾸지 않고 색만 비교한다.
  • 결과와 의미: Study 구조와 cell identity 구조가 겹쳐 integration 필요성을 보여 준다.

E · Integrated identities

  • 목적: Biological identity를 보존하는가?
  • Data & method: 학습된 reference cell embeddings를 UMAP에 투영한다 (Pipeline).
  • 그림 읽기: 색은 cell type이며 raw C와 비교한다.
  • 결과와 의미: Prototype supervision과 함께 known cell-type structure가 보존된다.

F · Integrated studies

  • 목적: 같은 identity 내 study mixing이 이루어지는가?
  • Data & method: 같은 integrated embedding을 study별로 표시한다 (Pipeline).
  • 그림 읽기: E의 type structure와 함께 study mixing을 읽는다.
  • 결과와 의미: 혼합 자체가 목표의 전부는 아니므로 label 보존과 함께 평가한다.

G · Mapped query

  • 목적: 새 query cells가 reference 어디에 놓이는가?
  • Data & method: celseq·celseq2의 3,289 cells를 map한다 (Pipeline).
  • 그림 읽기: Reference는 gray, 큰 원은 prototypes이며 unknown prototypes도 구별한다.
  • 결과와 의미: Query가 기존 공간에 연결되고 label-transfer accuracy는 80%였다.

H · Query study mixing

  • 목적: Mapping 후 query batch가 남는가?
  • Data & method: Mapped query/reference를 study origin으로 표시한다 (Pipeline).
  • 그림 읽기: G와 같은 mapping을 study 색으로 확인한다.
  • 결과와 의미: 평균 integration score는 0.86으로 보고되었다.

I · Prediction outcome

  • 목적: Reference에 없는 type을 무조건 known type으로 넣는가?
  • Data & method: Reference에서 beta cells를 제거한 unknown scenario의 classification을 표시한다 (Pipeline).
  • 그림 읽기: Correct/incorrect/unknown outcome을 별개로 본다.
  • 결과와 의미: Unknown-cell detection은 nearest-prototype distance threshold에 의존한다.

J · Condition embeddings

  • 목적: Sample 자체의 관계를 볼 수 있는가?
  • Data & method: Learned condition vectors를 PCA로 투영한다 (Pipeline).
  • 그림 읽기: 점은 cell이 아니라 condition이며 UMAP과 의미가 다르다.
  • 결과와 의미: Condition 유사성을 별도의 공간에서 탐색할 수 있다.

Takeaway · Integrated cells와 sample embeddings는 같은 좌표나 같은 biological 해석을 갖지 않는다.

Figure 2 · Benchmarking two tasks

Context · Mapping이 보기 좋다는 것만으로 좋은 모델은 아니다. Integration과 label transfer를 별개 지표로 평가하고 model ablation으로 개선 이유를 확인한다.

Figure: De Donno et al., Nature Methods (2023) · CC BY 4.0

A · Integration

  • 목적: 다양한 dataset에서 integration quality는 어떤가?
  • Data & method: Six datasets에 scPoli·scVI·scANVI·Seurat·Symphony를 비교한다 (Pipeline).
  • 그림 읽기: 오른쪽 평균 bar와 dataset별 scores를 함께 본다.
  • 결과와 의미: Next-best scANVI 대비 mean integration score가 5.06% 높다고 보고되었다.

B · Ablation

  • 목적: 개선은 embedding 때문인가 prototype 때문인가?
  • Data & method: OHE variant와 no-prototype variant를 포함해 batch mixing·biology 보존을 비교한다 (Pipeline).
  • 그림 읽기: 두 score 축을 분리해 단순 mixing 증가와 구별한다.
  • 결과와 의미: Biological conservation 개선의 주요 요인은 prototype loss였다.

C · Weighted F1

  • 목적: 많은 cells에 대한 분류 성능은 어떤가?
  • Data & method: Held-out query labels와 predictions로 support-weighted F1을 계산한다 (Pipeline).
  • 그림 읽기: Class abundance의 영향이 포함된 metric임을 기억한다.
  • 결과와 의미: SVM을 제외한 비교 방법보다 높아 classification-only baseline의 강점을 함께 보여 준다.

D · Joint-task trade-off

  • 목적: Integration과 classification을 동시에 잘하는가?
  • Data & method: 두 task를 수행하는 scPoli·scANVI·Seurat 결과를 비교한다 (Pipeline).
  • 그림 읽기: Integration score와 weighted F1의 두 축을 본다.
  • 결과와 의미: Joint-task comparison에서는 scPoli가 유리했다.

E · Macro F1

  • 목적: Rare types도 잘 분류하는가?
  • Data & method: Class별 F1을 같은 비중으로 평균한다 (Pipeline).
  • 그림 읽기: C와 다르게 abundant class가 점수를 지배하지 않는다.
  • 결과와 의미: scPoli는 Seurat와 비슷하고 scANVI보다 높았으며 SVM이 가장 좋았다.

F · Rare-type trade-off

  • 목적: Rare-type 성능과 integration을 함께 만족하는가?
  • Data & method: Macro F1과 integration score를 함께 배치한다 (Pipeline).
  • 그림 읽기: D와 y-axis metric의 차이를 구별한다.
  • 결과와 의미: 좋은 integrated representation과 최고 classification-only score는 같은 요구가 아니다.

Takeaway · 모든 task에서 모든 baseline을 이겼다는 주장은 원문 결과와 다르다.

Figure 3 · HLCA reference and healthy query

Context · Small benchmark를 넘어 sample metadata가 풍부한 lung atlas에 적용한다. Cell mixing과 sample differences가 두 공간에서 어떻게 공존하는지 확인한다.

Figure: De Donno et al., Nature Methods (2023) · CC BY 4.0

A · Integrated studies

  • 목적: HLCA의 studies가 연결되는가?
  • Data & method: HLCA core를 sample-level condition으로 통합한다 (Pipeline).
  • 그림 읽기: Cell UMAP의 색은 study이다.
  • 결과와 의미: 다양한 study의 cells가 통합된 공간에 연결된다.

B · Preserved identities

  • 목적: 58 cell-type prototypes가 biology를 보존하는가?
  • Data & method: 같은 HLCA UMAP을 fine cell labels로 표시한다 (Pipeline).
  • 그림 읽기: A와 같은 좌표에서 cell-type separation을 읽는다.
  • 결과와 의미: Study mixing과 함께 알려진 cell identities가 남는다.

C · Integration comparison

  • 목적: scANVI와 비교해 무엇이 개선되는가?
  • Data & method: 두 모델 모두 sample-level integration으로 맞추어 평가한다 (Pipeline).
  • 그림 읽기: Biology conservation과 batch correction을 분리한다.
  • 결과와 의미: Biological conservation은 높고 batch correction은 유사했다.

D · Study-level sample structure

  • 목적: Sample embeddings는 study 차이를 포착하는가?
  • Data & method: Sample vectors의 첫 두 PCs를 계산한다 (Pipeline).
  • 그림 읽기: 점은 sample이며 색은 study이다.
  • 결과와 의미: 같은 study의 samples가 모여 technical context가 남는다.

E · Sample provenance

  • 목적: Sample type과 embedding structure가 관련되는가?
  • Data & method: 같은 sample PCA를 sample type으로 표시한다 (Pipeline).
  • 그림 읽기: D와 동일 좌표에서 metadata label만 바뀐다.
  • 결과와 의미: Tissue provenance·processing과 연결된 variation을 탐색할 수 있으나 causal explanation은 아니다.

F · Healthy query mapping

  • 목적: Reference에 없는 identities도 구분되는가?
  • Data & method: Meyer healthy query 6 samples, 9 novel identities를 map한다 (Pipeline).
  • 그림 읽기: Reference gray·query predicted labels·unknown dark gray를 구분한다.
  • 결과와 의미: 90% uncertainty quantile cutoff에서 전체 accuracy 75%였고 original workflow는 69%였다.

G · Uncertainty landscape

  • 목적: 어떤 cells가 불확실한가?
  • Data & method: 각 query cell과 nearest prototype의 Euclidean distance를 표시한다 (Pipeline).
  • 그림 읽기: 색은 calibrated probability가 아니라 distance-based uncertainty이다.
  • 결과와 의미: Novel types와 transition regions에서 높지만 novel T-cell subtypes 일부는 known CD4/CD8로 분류되었다.

Takeaway · Unknown은 새로운 cell type의 확정이 아니라 검토해야 할 distance outlier이다.

Figure 4 · Sample-level disease classification

Context · 같은 모델이 cell identities뿐 아니라 sample phenotype에도 정보를 담는지 묻는다. 비교적 일관된 COVID-19 study에서 숨긴 labels를 복원해 본다.

Figure: De Donno et al., Nature Methods (2023) · CC BY 4.0

A · Cell predictions

  • 목적: 숨긴 sample의 cell labels를 전파할 수 있는가?
  • Data & method: Su dataset 270 samples 중 30 samples를 unlabeled로 둔다 (Pipeline).
  • 그림 읽기: 큰 점은 prototype, query cells는 predicted cell type 색이다.
  • 결과와 의미: Cell-level label transfer accuracy는 90%였다.

B · Patient mixing

  • 목적: Cell integration이 patient separation을 줄이는가?
  • Data & method: Integrated UMAP을 patient별로 표시한다 (Pipeline).
  • 그림 읽기: 시각화에는 270 중 30 samples만 표시했다.
  • 결과와 의미: Patient별 mixing을 점검하되 sample-level disease prediction과 혼동하지 않는다.

C · Disease representation

  • 목적: Known sample phenotype과 embedding이 관련되는가?
  • Data & method: Labeled sample vectors의 PCA와 severity metadata를 비교한다 (Pipeline).
  • 그림 읽기: Healthy·mild·moderate·severe 색의 분포를 읽는다.
  • 결과와 의미: Ordinal-regression adjusted R²는 PC1 0.41, PC2 0.16이었다.

D · Unlabeled samples

  • 목적: 새 sample의 disease class를 예측할 수 있는가?
  • Data & method: Reference sample embeddings에 학습한 kNN으로 query samples를 분류한다 (Pipeline).
  • 그림 읽기: Gray reference 위 query predicted severity를 본다.
  • 결과와 의미: Sample-class accuracy 73%는 A의 cell-label accuracy 90%와 다른 값이다.

E · Sample-feature comparison

  • 목적: Learned samples가 pseudobulk보다 나은가?
  • Data & method: Five-fold CV로 sample embedding·mean expression·mean scVI representation을 비교한다 (Pipeline).
  • 그림 읽기: 각 점은 fold이며 error bars는 SEM이다.
  • 결과와 의미: Weighted F1은 65.3±2.5%, 59.3±1.3%, 58.8±2.1% 순으로 보고되었다.

Takeaway · Sample phenotype prediction의 성능과 integrated cell labels의 성능을 분리해야 한다.

Figure 5 · Technical variation guides integration

Context · 더 이질적인 collection에서는 disease보다 기술 차이가 sample space를 지배할 수 있다. 이 경우 embedding은 disease biomarker보다 batch-covariate 선택에 유용하다.

Figure: De Donno et al., Nature Methods (2023) · CC BY 4.0

A · Cell identities

  • 목적: 이질적인 study에서도 cell types가 유지되는가?
  • Data & method: Schulte-Schrepping 99 samples를 sample-level integration한다 (Pipeline).
  • 그림 읽기: UMAP 색은 cell type이다.
  • 결과와 의미: Known immune identities가 유지되는지 B의 mixing과 함께 확인한다.

B · Experiment mixing

  • 목적: Experiment variation은 cell space에서 줄어드는가?
  • Data & method: 같은 cells를 experiment별로 표시한다 (Pipeline).
  • 그림 읽기: A와 같은 coordinates에서 색의 혼합을 본다.
  • 결과와 의미: Cell-level correction과 sample-level technical structure는 양립할 수 있다.

C · Experiment association

  • 목적: Sample PCs의 주된 요인은 무엇인가?
  • Data & method: Sample PCA에 experiment labels와 linear-model association을 표시한다 (Pipeline).
  • 그림 읽기: PC1·PC2의 adjusted R²를 읽는다.
  • 결과와 의미: Experiment가 PC1 0.94, PC2 0.97을 설명하여 strong technical association을 보였다.

D · Cohort association

  • 목적: Cohort도 같은 variation과 관련되는가?
  • Data & method: Sample PCA를 two cohorts로 색칠한다 (Pipeline).
  • 그림 읽기: 같은 PC axes에서 C와 비교한다.
  • 결과와 의미: Cohort의 PC1 adjusted R²는 0.73이었다.

E · Disease in leading PCs

  • 목적: Leading PC가 disease score인가?
  • Data & method: 같은 sample space를 disease state로 표시한다 (Pipeline).
  • 그림 읽기: Disease–PC1 association을 technical associations와 비교한다.
  • 결과와 의미: Disease PC1 adjusted R²는 0.00으로 sample embedding을 곧바로 disease axis로 읽으면 안 된다.

F · Disease in later PCs

  • 목적: Disease signal이 전혀 없는가?
  • Data & method: PC2–PC3 view로 sample embeddings를 다시 본다 (Pipeline).
  • 그림 읽기: E와 축이 달라진 점을 먼저 확인한다.
  • 결과와 의미: Disease association은 뒤 PCs에 나타나며 PC2 adjusted R²는 0.41이었다.

Takeaway · Sample condition 99개 대신 experiment 16개·cohort 2개를 쓰는 대안도 S7에서 검토했다.

Figure 6 · Population-scale PBMC atlas

Context · 수천 samples에서도 두 표현을 학습할 수 있는지 확인한다. 규모가 커질수록 technical confounding을 더 조심하며 gene patterns와 sample PCs를 연결한다.

Figure: De Donno et al., Nature Methods (2023) · CC BY 4.0

A · Atlas integration

  • 목적: 수백만 cells를 통합할 수 있는가?
  • Data & method: 7.8M-cell atlas 중 UMAP 표시용 1M cells를 dataset별로 표시한다 (Pipeline).
  • 그림 읽기: 학습 전체 규모와 그림에 표시한 subsample을 구별한다.
  • 결과와 의미: 25 datasets의 population-scale reference를 구성했다.

B · Cell-type structure

  • 목적: Large-scale integration이 identities를 보존하는가?
  • Data & method: 같은 1M-cell UMAP을 14 coarse types로 표시한다 (Pipeline).
  • 그림 읽기: A와 같은 좌표에서 type boundaries를 읽는다.
  • 결과와 의미: 큰 규모에서도 cell identities를 구분하는 representation을 얻었다.

C · Dataset variation

  • 목적: Sample space의 첫 PC는 무엇을 담는가?
  • Data & method: 2,375 sample embeddings의 PCA와 dataset metadata를 비교한다 (Pipeline).
  • 그림 읽기: 점은 sample이며 adjusted R²를 읽는다.
  • 결과와 의미: PC1은 dataset과 강하게 관련되었다(adjusted R²=0.97).

D · Assay variation

  • 목적: Sequencing assay도 PC1과 연결되는가?
  • Data & method: 같은 sample PCA를 assay로 표시한다 (Pipeline).
  • 그림 읽기: C와 구조의 중첩을 보며 독립 효과라고 가정하지 않는다.
  • 결과와 의미: Assay association은 adjusted R²=0.86이었다.

E · Disease variation

  • 목적: Phenotype association도 존재하는가?
  • Data & method: 같은 sample PCA를 disease metadata로 표시한다 (Pipeline).
  • 그림 읽기: Dataset·assay와 disease가 confounded될 수 있음을 기억한다.
  • 결과와 의미: Disease adjusted R²=0.59는 association이지 기술효과와 분리된 causal signal은 아니다.

F · PC-associated genes

  • 목적: Sample variation을 expression patterns와 연결할 수 있는가?
  • Data & method: Sample mean expression과 embedding PCs의 Pearson correlations를 계산한다 (Pipeline).
  • 그림 읽기: P<0.01, |r|>0.3를 만족하는 gene 수를 PC별 비교한다.
  • 결과와 의미: PC1뿐 아니라 PC2·4·5에도 gene-associated variation이 있었다.

G · Functional enrichment

  • 목적: PC1-associated genes는 어떤 기능을 갖는가?
  • Data & method: PC1-correlated genes에 pathway/biological-process enrichment를 수행한다 (Pipeline).
  • 그림 읽기: Term enrichment는 causal regulation이나 independent validation이 아니다.
  • 결과와 의미: Immune·stress·cytokine·neutrophil-degranulation 관련 terms가 관찰되었다.

H · RPL31

  • 목적: Ribosomal pattern은 두 공간에서 어떻게 보이는가?
  • Data & method: RPL31 expression을 sample PCA와 cell UMAP에 표시한다 (Pipeline).
  • 그림 읽기: 왼쪽 sample·오른쪽 cell의 단위 차이를 구별한다.
  • 결과와 의미: RPL31은 PC1과 r=−0.93으로 관련되며 corrected cell space에서 섞인 signal이 sample space에 남는다.

I · RHOA

  • 목적: Immune-related pattern도 남는가?
  • Data & method: RHOA expression을 같은 두 embedding spaces에 표시한다 (Pipeline).
  • 그림 읽기: H와 색 범위를 동일하다고 가정하지 말고 각 legend를 따른다.
  • 결과와 의미: RHOA는 PC1과 r=0.85로 관련되지만 이 관계가 disease causality를 입증하지 않는다.

Takeaway · Sample embeddings는 technical·biological sources가 함께 담긴 탐색 공간이다.

Limitations

  • Output은 integrated low-dimensional embedding이지 corrected count matrix가 아니다.
  • High-quality harmonized labels가 필요하며 잘못된 prototypes는 biology를 강제로 뭉칠 수 있다.
  • Prototype distance는 bounded probability가 아니며 universal unknown cutoff가 없다; healthy HLCA의 90% quantile을 다른 query에 자동 적용하지 않는다.
  • Sample embeddings는 technical·phenotypic confounding을 그대로 반영할 수 있다. Adjusted R²가 높아도 causal source separation이 성립하지 않는다.
  • Reference 없이 mapping할 수 있다는 것은 formal differential privacy guarantee와 다르다.
  • Main text의 pancreas study/batch 수, encoder/decoder symbol 설명, correlation/‘coefficient of determination’ 표현과 supplementary gene spelling 불일치는 Notation audit에 모았다.
